# 基本的な使い方：プラグイン

SSPには通常カレンダー等いくつか機能が装備されていますが、プラグインによってさらに機能を拡張することができます。<br>
メモリ開放・バッテリ状態監視等いくつか配布されていますので試してみてください。

## プラグインを追加する

プラグインも、「シェル」や｢ゴースト」と同じように配布されています。<br>
ダウンロードしてきたファイルを、そのままキャラクターに**ドロップ**してください。中身が壊れていなければ、すぐに使える状態になります。

## プラグインを設定・実行する

キャラクターを右クリックして出るメニューに「プラグイン」という項目があります。<br>
インストールされているプラグインはすべてここに表示されています。<br>
選択するとプラグインの設定画面が開いたり、機能を実行したりすることができます。
