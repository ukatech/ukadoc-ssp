# 资源管理器：右键菜单/功能菜单

本页介绍在资源管理器中右键点击所选项目，或在选中项目后打开「功能」菜单时显示的菜单。

菜单项如下。（**默认**项目会在双击鼠标左键时执行，资源管理器右下方的按钮也有相同效果。）

## 通用项目

- **删除**<br>
  卸载指定项目。
- **打开文件夹**<br>
  使用 Windows 资源管理器打开存放指定项目配置文件的文件夹。
- **移动文件夹（组）\[外壳除外\]**<br>
  移动指定项目所属的[加载文件夹（组）](../../config/folder.md)。<br>
  请注意，当前正在运行的项目无法执行此操作。<br>
  另外，如果只有一个文件夹，则无法选择此菜单项。
- **打开发布来源 URL**<br>
  显示发布指定项目的位置。<br>
  但是，如果找不到相关信息，则不会执行任何操作。
- **打开 README**<br>
  打开指定项目的 README。<br>
  但是，如果找不到 README，则不会执行任何操作。
- **在线更新**<br>
  如果是人格，则只执行在线更新，不会启动人格。<br>
  如果不是人格，通常通过此菜单执行在线更新。
- **创建更新文件**<br>
  创建用于在线更新的 updates2.dau/updates.txt 文件。<br>
  ※为确保兼容性，除了在人格根文件夹中创建外，也会在 ghost/master 下创建相同文件。
- **创建 NAR**<br>
  将所选项目打包为一个文件，以便通过网络发布。
- **同时创建更新文件和 NAR**<br>
  一次性创建更新文件和 NAR。

## 人格项目

- **切换：默认**<br>
  将当前人格切换为其他人格。
- **呼叫人格**<br>
  保留当前人格，同时让另一个人格显示出来。
- **创建启动快捷方式**<br>
  在桌面上创建一个快捷方式，用于启动已选人格对应的 SSP。
- **设为默认人格**<br>
  设置当前所选人格为默认启动人格，例如发生错误退出后重新启动时会启动该人格。<br>
  设置的人格在列表左侧会显示【![默认标记](../../assets/screenshots/functions/explorer/menu/5.png)】图标。
- **指定为优先发言人格**<br>
  将当前所选人格设为优先发言人格，以便在未指定发言人格的 SSTP 等情况下优先让其发言。<br>
  设置的人格在列表左侧会显示【![优先发言标记](../../assets/screenshots/functions/explorer/menu/6.png)】图标。<br>
  ※如果同时将某个人格设为默认人格和优先发言人格，则会显示为【![同时指定默认和优先发言](../../assets/screenshots/functions/explorer/menu/7.png)】。
- **使用 RSS 更新信息批量更新**<br>
  自动获取最新的更新信息，并自动批量更新有可用更新的角色。

## 对话框项目

- **切换：默认**<br>
  将当前对话框切换为其他对话框。
- **设为默认对话框**<br>
  当人格一侧未指定要使用的对话框（或指定的对话框不存在）时，设置默认使用的对话框。<br>
  设置的对话框在列表左侧会显示【![默认标记](../../assets/screenshots/functions/explorer/menu/5.png)】图标。

## 外壳项目

- **切换：默认**<br>
  将当前外壳切换为其他外壳。

## 在线新闻项目

- **朗读：默认**<br>
  开始在线新闻传感器并朗读内容。
- **显示网页**<br>
  在浏览器中打开提供 RSS/在线新闻的网站。

## 插件项目

- **设置/运行：默认**<br>
  设置或运行插件。具体执行什么操作因插件而异。
- **启用/禁用**<br>
  切换插件的启用或禁用状态。<br>
  禁用后，插件仍会被识别，但不会加载。
