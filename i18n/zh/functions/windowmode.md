# 窗口模式

这是一种不把人格直接放在桌面上，而是将其限制在一个窗口中显示的模式。<br>
窗口内部就像一个小小的桌面，人格只会在其中活动。

如果想用直播软件捕获整个窗口，或想把桌面留作其他用途，这种模式就很方便。<br>
人格不会再出现在其他应用程序前面，也不会影响整个桌面。

!!! tip "ヒント"

    窗口模式是一项实验性功能。使用体验和规格今后可能会有所变化。

!!! tip "ヒント"

    由于操作系统功能的限制，Windows 7 及更早版本无法使用此功能。请使用 Windows 8 或更高版本。

## 两种显示方式

- **将所有人格合并到一个窗口中**<br>
  将所有正在运行的人格合并显示在一个窗口中（默认值）。<br>
  使用起来就像把桌面缩小了一样。
- **每个人格一个窗口**<br>
  为每个人格分别准备一个窗口。<br>
  可以把人格分别摆放在不同位置，也可以只捕获其中一个人格。

## 切换到窗口模式

可以通过以下任意一种方式切换。从哪里更改都使用相同的设置，彼此始终保持一致。

- **[右键菜单](../howto/rclick.md) →“设置”**<br>
  从“窗口模式 - 关”“窗口模式 - 所有人格”“窗口模式 - 每个人格”这3个选项中选择。当前状态会显示勾选标记。<br>
  ⇒另请参阅“[设置](../config/index.md)”页面。
- **首选项中的“[直播](../config/streamingtool.md)”**<br>
  将“在一个窗口中显示人格”设为 ON，然后选择“将所有人格合并到一个窗口中”或“每个人格一个窗口”。
- **窗口的“操作”菜单**<br>
  也可以在窗口模式窗口自身的菜单中，通过相同的3个选项切换。选择“关”即可返回普通桌面显示。

所选状态会被记住，下次启动 SSP 时也会沿用该设置。<br>
也可以通过启动选项 `--windowmode` 指定后启动。⇒请参阅“[启动选项列表](option.md)”页面。

!!! tip "ヒント"

    人格正在加载时无法切换。此时菜单或勾选标记会恢复为原来的状态，请等待加载完成后再试一次。<br>
    切换前后，人格相对于屏幕的大致位置比例会保持不变。即使可显示的区域发生变化，也不会一下子跳到很远的位置。

## 打开“操作”菜单

所有针对窗口本身的操作都集中在“操作”菜单中。可以通过以下任意一种方式打开。

- **在窗口内单击右键**<br>
  在没有人格或对话框的地方单击右键即可打开。无论是否显示窗口边框，都可以使用。
- **标题栏菜单**<br>
  如果显示窗口边框，可以在标题栏上单击右键（或单击左上角的图标），然后在弹出的菜单中选择“操作”。
- **左上角的 `≡` 按钮**<br>
  隐藏窗口边框或处于全屏显示时，将鼠标移到窗口上，左上角会出现 `≡` 按钮。单击后即可打开“操作”菜单。<br>
  此时右上角也会出现 `×` 按钮，单击即可关闭窗口。

## “操作”菜单中的项目

- **窗口模式 - 关 / 所有人格 / 每个人格**<br>
  切换显示方式（如上所述）。
- **全屏显示\[F11\]**<br>
  将窗口扩大到整个显示器，并隐藏边框。此时屏幕上只显示人格。<br>
  按 ESC 键或再次按 F11，即可恢复到原来的大小。全屏显示时无法移动窗口。
- **显示窗口边框**<br>
  切换是否显示标题栏和边框（默认显示）。<br>
  隐藏边框后，外观会更加简洁，捕获画面时也不会拍到边框。即使没有边框，也可以拖动窗口边缘来调整大小。抓住角落附近即可斜向调整。<br>
  将鼠标移到边缘时，可拖动的位置会以细线标出。拖动窗口内的空白处还可以移动窗口位置。
- **同时整合历史记录/发言记录**<br>
  将历史记录（发言记录）窗口也整合到此窗口中（默认值为 ON）。⇒请参阅下文的“[整合历史记录](#バックログの統合)”。
- **背景 - 白色 / 灰色 / 黑色 / 桌面 / 图像...**<br>
  切换窗口背景（默认值为“桌面”）。<br>
  “桌面”会重现当前桌面壁纸及其显示方式（居中显示、平铺显示、适应屏幕等）。更换壁纸后，背景也会随之更新。<br>
  白色、灰色和黑色为纯色。适用于直播时抠除背景，或确认人格的显示效果。<br>
  选择“图像...”后会打开文件选择对话框，可以将任意图像设为背景。图像会在保持纵横比的情况下放大并铺满窗口，超出部分将被裁切。
- **屏幕截图...**<br>
  将窗口中的内容直接保存为 PNG 图像。在保存对话框中可以选择以下2种类型。<br>
  **PNG** … 保存当前所见画面，包括背景。<br>
  **PNG - 透明背景** … 将背景设为透明，只保存人格和对话框。<br>
  文件名会预先设为 `ssp_日付_時刻.png` 的格式。鼠标移到窗口上时出现的按钮和边缘线不会被拍入截图。
- **关闭\[Ctrl+W\]**<br>
  关闭窗口。“每个人格一个窗口”模式下，该窗口中的人格也会结束。

!!! tip "ヒント"

    边框、背景和全屏等外观设置会分别记忆在各个窗口中。“每个人格一个窗口”模式下，也可以为不同人格设置不同背景。

!!! tip "ヒント"

    **在全息设备上使用时**，推荐设置为“背景 - 黑色”、“关闭显示窗口边框”以及“同时整合历史记录/发言记录”。<br>
    全息设备是指能将影像投射出来，让角色看起来像是悬浮在空中的显示装置。许多设备通过投射电脑屏幕来显示画面，在这类设备上，黑色部分不会发光，因此看起来会是透明的。<br>
    因此，将背景设为黑色，并隐藏边框和其他窗口后，就能让人格和对话框看起来像是悬浮在空中。<br>
    如果想让画面尽量铺满设备可显示的范围，也可以同时启用全屏显示（F11）。

## 整合历史记录

启用“同时整合历史记录/发言记录”后，历史记录窗口会收纳在此窗口中。这样就不会有另一个窗口单独出现在桌面上，可以直接将它包含在捕获画面中。

整合后的历史记录看起来像一块没有边框的面板。将它移动到窗口边缘附近时，会自动吸附并对齐。<br>
文字大小会根据该人格对话框的缩放比例变化，以免对话框和发言记录中的文字大小不一致。<br>
背景颜色会根据窗口的背景设置变化。如果背景设置为图像，则会使用该图像中占比最大的颜色（主导色）。

!!! tip "ヒント"

    关闭此选项后，历史记录会像以前一样作为独立窗口显示在桌面上。<br>
    只有此设置是针对整个 SSP 的设置，而不是针对各个窗口；切换显示方式后也会沿用此设置。

## 任务栏和最小化

在窗口模式下，任务栏中只会显示此窗口。人格和对话框不会分别显示在任务栏中。<br>
最小化窗口时，人格也会一起隐藏；还原窗口时，人格也会一起显示。反过来，如果将所有人格都最小化，窗口也会随之最小化。

## 键盘快捷键

窗口处于前台时，可以使用以下按键。

| 按键 | 功能 |
|---|---|
| F11 | 切换全屏显示 |
| ESC | 退出全屏显示（仅限全屏显示时） |
| Ctrl+W | 关闭窗口 |
