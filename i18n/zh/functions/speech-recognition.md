# 语音识别

这是 SSP 内置的语音识别功能。<br>
它无法识别自由表达的句子，但可以通过语音命令让人格准确地听从指令，这是它的特点。

此外，还可以在首选项的「[语音识别/合成](../config/dictation.md)」中选择要使用的识别引擎，或进行提高识别准确度的训练。

!!! tip "ヒント"

    关于将人格的发言通过语音朗读的功能，请参阅「[语音合成](speech-synthesis.md)」页面。

## 开始使用

1. 将麦克风连接到电脑（也可以使用耳麦）。
2. 在右键菜单中选择「功能」→「语音识别」。此时会打开一个标有「语音识别」的小窗口（面板）。
3. 对着麦克风说话，确认面板上的音量计会随之变化。如果没有变化，请确认是否正确选择了麦克风，并检查首选项的「[语音识别/合成](../config/dictation.md)」中的「音频输入源」。
4. 然后按照下方「基本操作」中的顺序，对人格说话。

只有在面板打开时，语音识别才会运行。点击面板右上角的「×」或按 Esc 键关闭面板后，语音识别就会停止。<br>
如果在面板打开的状态下退出 SSP，下次启动时面板也会自动打开，并恢复识别。不再使用时，请先关闭面板再退出。<br>
面板的位置会被记住。

!!! tip "ヒント"

    如果电脑没有安装语音识别引擎等，导致无法使用语音识别，那么即使打开面板也不会识别任何内容。在这种情况下，首选项中的语音识别项目也会显示为灰色。

## 面板的查看方法

面板由「对话对象」「请求」「内容」三栏，以及下方的音量计和状态显示组成。<br>
当前应该说什么，可以通过有颜色的栏来判断。

- **对话对象**<br>
  显示正在与谁说话（格式为「角色名 | 人格名」）。
- **请求**<br>
  显示刚刚识别到的对话框中的选项文字。
- **内容**<br>
  显示从「菜单」中选择项目时的候选项列表。只有使用这一栏时，面板才会向下展开，以显示列表。
- **音量计**<br>
  显示麦克风收到的声音大小。如果说话时音量计没有变化，说明没有收到声音。
- **右下角的状态显示**<br>
  显示最后识别到的内容。听到的内容与预期不同时，可以用它来确认。<br>
  启动后会立即显示「\[Ready\]」；更新选项或切换栏的瞬间，会短暂显示「\[Update/Pause\]」「\[ModeChange/Pause\]」（这段时间不会接收语音，请不要着急，再说一次即可）。

## 基本操作

刚启动时，「对话对象」栏会显示颜色，其他栏则处于无效状态。<br>
首先，请清楚地说出要与谁交谈。

操作流程为「呼叫对话对象 → 提出请求（→ 如有需要，再选择内容）」。<br>
例如：呼叫「艾米丽」→ 说「菜单・外壳」→ 对显示的列表说「3」→ 艾米丽的外壳就会切换。

### 对话对象

这是要通过语音听从指令的对象名称。对**当前正在运行的人格**说出以下任意一种名称，就会被视为在与该对象交谈。

- 人格名称
- 主角色（`\0`）的名称
- 次要角色（`\1`）的名称……呼叫此名称时，会被视为在与该人格的**次要角色**交谈。

例如：Emily/Phase4.5 的「艾米丽」「泰迪」「艾米里奥」任意一个名称都可以。通常建议使用「艾米丽」。<br>
呼叫后，对话对象栏中会显示该对象，并进入「请求」栏。如果人格支持此功能，呼叫时对话框中还会显示菜单。<br>
启动或结束人格时，可呼叫名称的列表会自动更新。呼叫尚未启动的人格名称不会有任何反应。

### 请求

说出希望对方听从的请求。可以识别以下请求。

| 应说的内容 | 功能 |
|---|---|
| 对话框中显示的选项或锚点 | 可以识别所有显示中的选项和锚点。识别成功后，就相当于选择了相应的选项或锚点。选项显示或消失时，可识别的内容也会自动更新。 |
| 「菜单・外壳」 | 外壳切换功能⇒进入「内容」选择 |
| 「菜单・切换人格」 | 切换人格功能⇒进入「内容」选择 |
| 「菜单・呼叫其他人格」 | 呼叫人格功能⇒进入「内容」选择 |
| 「菜单・对话框」 | 对话框切换功能⇒进入「内容」选择 |
| 「取消」 | 取消请求并返回「对话对象」 |
| 其他对话对象的名称 | 将对话对象切换为该对象。 |

请连续说出「菜单」和项目名称。项目名称是右键菜单中显示的名称（例如「外壳」「对话框」）。<br>
说「取消」会取消请求并返回对话对象栏。想更换交谈对象时，也可以不说「取消」，直接呼叫要切换到的对象名称。

### 内容

选择「菜单・外壳」等项目时，如果还有多个选项，就会显示这一栏。<br>
请说出列表中显示的选项本身，或说出以下特殊命令。

- 列表每页最多显示10项，每项旁边会显示从1到10的数字图标。项目较多时会分页显示。
- 「切换人格」和「呼叫其他人格」的列表中会显示已安装的人格（不只是正在运行的人格）。除了人格名称，也可以使用主角色或次要角色的名称进行选择。
- 「外壳」列表中会显示对话对象所属人格的外壳。「对话框」列表中会显示已安装的对话框。
- 完成选择后，如果选择的是「切换人格」，就会返回对话对象栏；其他情况下则会返回「请求」栏。

| 应说的内容 | 功能 |
|---|---|
| 数字（日语读法） | 说出与选项前数字图标相同的数字，就能获得与选择该项目相同的效果。 |
| 「下一页」「上一页」 | 翻动选项页面。只有存在下一页时才会在列表中显示「下一页」，只有存在上一页时才会显示「上一页」。 |
| 「向后」「返回」 | 翻动选项页面（每次翻动10页）。只有后面还有10页以上时才会在列表中显示「向后」；只有位于第11页或之后时才会显示「返回」。 |
| 「取消」 | 取消选择并返回「请求」 |

## 无法正确识别时

- 请确认音量计是否会变化。如果没有变化，可能是未选择麦克风或麦克风已静音。请检查「音频输入源」，并在 Windows 声音设置中确认麦克风音量。
- 在安静的地方清晰地一口气说出内容，更容易被识别。较长的名称请不要拆开来说。
- 如果当前环境支持让识别引擎学习说话习惯的「训练」功能，请在首选项的「[语音识别/合成](../config/dictation.md)」中运行训练，这样会更容易识别。
- 请确认呼叫的名称是否正确。只能识别正在运行的人格的名称。
- 如果「选项显示出来了，但语音不生效」，可能是选项刚显示后仍在更新，暂时无法接收语音。请稍等片刻再说一次。
