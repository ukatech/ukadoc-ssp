# 压缩包查看器

这是一个查看器窗口，可以像使用资源管理器一样，列出并提取 zip 等压缩包（归档）文件中的内容。<br>
只查看内容时无需解压，只需通过拖放即可提取所需文件。您可以在多个压缩包之间切换标签页进行浏览。

反过来，您也可以将手头的文件和文件夹收集起来，创建（压缩）新的压缩包。

## 支持的压缩包格式

支持的主要压缩包格式如下。<br>
「创建」栏为○的格式，也可以使用此查看器创建新的压缩包。其他格式只能浏览和解压。

| 格式 | 扩展名 | 创建 | 注释 |
|---|---|---|---|
| ZIP | .zip / .zipx | ○ | 也支持带密码的压缩包（ZipCrypto / AES-128・192・256）。 |
| NAR | .nar | − | 用于分发人格等内容的压缩包，内容为 ZIP 格式。 |
| 7-Zip | .7z | ○ | 支持密码（AES-256）和隐藏文件名的头部加密。 |
| LZH | .lzh / .lha | − | 在日本长期使用的格式。 |
| CAB | .cab | − | Windows 柜式压缩包。也能识别分卷（多卷）压缩包。 |
| 自解压压缩包 | .exe | − | 搜索并打开嵌入在可执行文件中的压缩包。 |
| TAR | .tar / .tgz / .txz / .tbz2 / .tlz / .tzst 等 | − | UNIX 系的打包格式。与下方压缩方式组合的文件也可以直接打开。 |
| 单文件压缩格式 | .gz / .bz2 / .xz / .lzma / .zst / .br / .Z | − | gzip / bzip2 / XZ / LZMA / Zstandard / Brotli / UNIX compress。会作为只包含一个文件的压缩包打开。 |
| cpio | .cpio | − | UNIX 的 cpio 压缩包（newc / crc / odc / 旧版二进制格式）。 |
| ar / Debian 软件包 | .deb / .udeb | − | 实际格式为 ar 压缩包。 |
| RPM 软件包 | .rpm | − | Red Hat 系的软件包。 |
| CD/DVD 镜像 | .iso | − | ISO9660 / Joliet / Rock Ridge / UDF。可以提取其中的文件。 |
| 磁盘镜像 | .img | − | FAT12 / FAT16 / FAT32 软盘等磁盘镜像。 |

!!! tip "ヒント"

    格式判定依据是**文件内容**，而不是扩展名。即使只是修改了扩展名，或者压缩包没有扩展名，也能正确打开。<br>
    此外，对于 `.iso.gz` 这类“进一步压缩的镜像”，也会根据内容自动识别。

## 启动方法

可以通过以下任一方式打开压缩包查看器。

- **[右键菜单](../howto/rclick.md) →「功能」→「压缩包查看器」**<br>
  在未打开任何内容的空白状态下启动查看器。<br>
  ⇒另请参阅「[功能](index.md)」页面。
- **将压缩包文件拖放到人格上**<br>
  将压缩包文件拖放到人格上后，如果人格没有响应该文件，系统就会自动使用此查看器打开文件。<br>
  如果文件无法作为压缩包读取，则不会启动查看器。
- **将压缩包文件拖放到查看器中**<br>
  启动查看器后，将压缩包文件拖放到其中，文件就会作为新标签页打开。可以放到窗口中的任意位置（标题栏、标签页栏和列表上方的效果都相同）。<br>
  一次拖放多个文件时，只有能作为压缩包打开的文件会成为标签页，其余文件会被忽略。

## 窗口构成

- **菜单栏**<br>
  可执行所有操作（详情见下文）。
- **工具栏**<br>
  将常用操作排列为按钮。每个按钮对应一个菜单项，将鼠标悬停在按钮上会显示功能名称（工具提示）。<br>
  当前无法使用的操作按钮会以灰色虚线显示。最右侧的视图切换按钮每按一次，图标就会变为当前的视图方式。
- **标签页**<br>
  每个已打开的压缩包都会显示为一个标签页。点击标签页即可切换显示的压缩包。<br>
  可以通过标签页最左侧的图标，区分浏览用标签页和创建新压缩包用标签页。
- **列表**<br>
  显示压缩包内容的区域。在「详细信息」视图中，会显示**名称、大小、压缩后大小、方式、更新时间**等列。<br>
  「压缩后大小」列中的 `-` 表示此格式无法确定每个文件各自压缩后的大小（例如 7-Zip 或 tar 等整体压缩格式）。
- **状态栏**<br>
  窗口底部从左到右依次显示<strong>压缩包中的当前位置（文件夹）</strong>・**实际压缩包格式**・**此文件夹中的项目数**。<br>
  正在解压或压缩时，最左侧会显示进度条。

!!! tip "ヒント"

    「实际压缩包格式」会根据实际读取到的内容显示为 `Zip/Deflate/AES-256`、`7Zip/LZMA2/AES-256/Encrypted Header`、`GZip/Tar`、`UDF Image` 等。由于依据的是内容而不是扩展名，因此即使扩展名是 `.exe`，只要内容为 ZIP，就会显示为 `Zip`。

## 顶部菜单

### 浏览与解压

- **打开...\[Ctrl+O\]**<br>
  打开文件选择对话框，并在新标签页中打开选中的压缩包。可以多选。<br>
  如果已有标签页打开了相同的压缩包，则会选中该标签页。
- **解压...**<br>
  仅将列表中**选中的项目**提取到指定文件夹。选中文件夹时，会连同其中的内容一起提取。<br>
  解压时会以当前显示的文件夹为基准，保留目录层级。
- **全部解压...**<br>
  将压缩包中的**全部内容**提取到指定文件夹。此操作会原样还原从压缩包最顶层开始的目录层级。

!!! tip "ヒント"

    解压目标文件夹会被记住，并在下次解压时作为初始值显示。

### 创建压缩包

- **新建\[Ctrl+N\]**<br>
  创建一个空的“压缩标签页”。将要打包的内容收集到这里后，即可保存为压缩包。
- **添加文件...**<br>
  将文件添加到压缩标签页中。可以多选。
- **添加文件夹...**<br>
  将文件夹连同其内部的目录层级一起添加到压缩标签页中。文件夹选择对话框一次只能选择一个文件夹；如果要批量添加，请使用拖放。
- **删除\[Delete\]**<br>
  将选中的项目从待打包列表中移除。选中文件夹时，会连同其中的内容一起移除。<br>
  移除操作只会将项目从列表中移除，不会删除原始文件。
- **另存为压缩文件...\[Ctrl+S\]**<br>
  将收集的内容导出为一个压缩包文件。保存时选择的扩展名决定压缩格式（`.7z` 为 7-Zip，其他扩展名则为 ZIP）。<br>
  勾选保存对话框中的“密码”复选框即可设置密码（详见后文）。

!!! tip "ヒント"

    这些项目仅在压缩标签页中可用。在浏览压缩包的标签页中，这些项目会显示为灰色。反过来，“解压”和“全部解压”仅可在浏览标签页中使用。

### 选择与显示

- **全选\[Ctrl+A\]**<br>
  选中当前显示的文件夹中的所有项目。
- **大图标 / 小图标 / 列表 / 详细信息**<br>
  切换列表的显示方式（默认值为“详细信息”）。这些选项与资源管理器中的显示方式切换相同。<br>
  此设置在所有标签页间通用，并会在下次启动时保留。

## 鼠标与键盘操作

- **双击文件夹**<br>
  进入该文件夹。要返回上一级，请双击列表顶部的 `..`。
- **双击文件**<br>
  提取该文件，并模拟将其拖放到当前显示的人格上。<br>
  如果人格没有响应，就会像普通拖放一样，使用[图片查看器](pictureviewer.md)或媒体播放器等程序打开。无需解压压缩包即可查看其中的内容，非常方便。
- **将项目拖到资源管理器**<br>
  可以将选中的文件或文件夹直接拖到资源管理器中的文件夹或桌面上进行提取。可以在多选状态下拖动。文件夹会连同其内部的目录层级一起提取。<br>
  内容会直接提取到放置目标，而不必先解压到某处再复制。<br>
  提取操作会在放下后继续进行，因此即使压缩包很大，也能马上松开鼠标，并在等待期间继续操作查看器。<br>
  即使压缩包已设置密码，只要打开时已输入密码，就不会再要求输入。
- **拖放到查看器**<br>
  放入压缩包文件后，会在新标签页中打开。<br>
  但是，**显示压缩标签页期间**，放入的文件或文件夹会作为“待打包”内容添加进来。

常用键盘快捷键如下。

| 按键 | 功能 |
|---|---|
| Ctrl+N | 新建（压缩标签页） |
| Ctrl+O | 打开压缩包 |
| Ctrl+A | 全选 |
| Ctrl+S | 另存为压缩文件 |
| Delete | 从待打包列表中移除（仅限压缩标签页） |
| Ctrl+W | 关闭标签页 |
| Ctrl+Tab | 切换到下一个标签页 |
| Ctrl+Shift+Tab | 切换到上一个标签页 |

## 各项功能的详细说明

### 打开带密码的压缩包

尝试打开带密码的压缩包时，系统会要求输入密码。密码正确后，关闭该窗口之前无需再次输入。<br>
对于启用了 7-Zip“加密文件名”功能的压缩包，在显示文件名列表时就需要输入密码。

### 创建压缩包

通过“新建”打开压缩标签页，然后将文件或文件夹拖放到其中，或者使用“添加文件”和“添加文件夹”来收集内容。添加文件夹时，会原样保留其内部的目录层级。<br>
收集内容时，可以双击文件夹进入其中。在该状态下添加的内容也会放入压缩包中的对应目录层级。<br>
如果再次添加同名项目，新项目会替换旧项目。

收集完毕后，使用“另存为压缩文件”导出。保存后压缩标签页仍会保留，因此可以继续添加内容，并以其他名称再次保存。

### 压缩时设置密码

勾选保存对话框中的“密码”复选框后，会打开设置密码的对话框。

- **输入**<br>
  输入自己设置的密码。输入内容会以掩码形式显示。
- **生成**<br>
  自动生成随机密码。可以指定使用的字符类型（小写字母、大写字母、数字、符号）和字符数（4〜64个字符，初始值为16个字符）。<br>
  为方便记下生成的密码，密码会直接显示，不进行掩码处理。

!!! tip "ヒント"

    如果忘记密码，就无法取出压缩包中的内容。请务必记下生成的密码。<br>
    如果输出格式为 `.7z`，除文件内容外，文件名列表也会加密（加密文件头）。ZIP 无法隐藏文件名。

### 显示可疑项目警告

如果压缩包中包含展开后可能导致意外结果的项目，该项目名称会以**红色文字**显示。<br>
如果文件夹中包含此类项目，文件夹名称也会变红，因此无需逐层打开文件夹也能发现。

符合以下任意条件的项目会显示为红色。

| 类型 | 内容 |
|---|---|
| 压缩率异常 | 展开后的大小膨胀到压缩后大小的200倍以上的项目（俗称“zip 炸弹”）。 |
| 体积过大 | 单个文件超过64GB。 |
| 可疑路径 | 尝试写入压缩包外部的名称（包含 `..`、以驱动器名称开头等）。SSP 会自动将其处理为无害内容，但这也可能说明压缩包的来源有问题。 |
| 名称重复 | 存在仅大小写不同的同名文件。展开时，其中一个文件会被静默覆盖。 |
| 日期异常 | 修改日期早于1980年或晚于2100年的项目。 |
| 特殊项目 | 符号链接、设备等非普通文件或文件夹的项目。即使展开，也不会创建实际对象。 |
| 扩展名伪装 | 名称中嵌入了特殊控制字符，导致显示的扩展名与实际扩展名不同的项目。 |

!!! tip "ヒント"

    红色显示仅用于提醒，不会阻止展开。<br>
    另外，SSP 会自动将尝试写入压缩包外部的项目处理为无害内容，并跳过链接、设备等特殊项目，不会创建实际对象。即使展开红色项目，压缩包外部也不会遭到破坏。

### 展开大型压缩包

展开或压缩过程中，状态栏最左侧会显示进度条。处理完成后，进度条会自动消失。
