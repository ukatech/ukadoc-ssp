# SSP 即时通讯：添加收件人

通过 IP 地址和端口号指定收件人很麻烦，也经常容易出错。<br>
如果对方或自己通过拨号连接接入互联网来交换消息，每次连接时双方的 IP 地址都可能发生变化，设置起来也会很费劲。

这时就可以使用目录服务。

通过指定用户 ID（电子邮件地址），即可仅凭姓名查找登录了同一目录服务的用户。在 SSP 中，「SSP 和愉快的伙伴们」是默认服务器，可供大家自由使用，无需密码。<br>
※这项服务允许您公开自己的信息，以查询对方的信息。因此，即使您使用的是固定 IP，如果要查找使用动态 IP 的用户，也必须登录目录服务。<br>
※可公开和查询的信息只有两项：IP 地址，以及等待接收 SSTP 的端口号。

此外，虽然可能不常用，但如果双方（无论是通过互联网还是局域网连接）都使用固定 IP，也可以在本地保存姓名与 IP 的对应关系。这样可以省去查询步骤，更快地向对方发送消息。

## 注册目录服务用户

在「注册」菜单中点击「添加收件人」，在弹出的对话框中先选择「目录服务」。

接着输入对方的姓名和分组。（这两项用于识别 SSP 中注册的信息）

选择对方登录的目录服务。目录服务可以在[设置对话框](../../config/im.md)中注册。

用户 ID 通常填写对方的电子邮件地址，但必须是对方用于登录的用户 ID，因此请向对方确认。

完成以上步骤后，即注册成功。此后尝试发送消息时，系统会自动获取对方的地址并发送消息。

## 直接指定 IP 地址注册用户

在「注册」菜单中点击「添加收件人」，在弹出的对话框中选择「指定地址」。

接着输入对方的姓名和分组。（这两项用于识别 SSP 中注册的信息）

指定对方的 IP 地址，以及对方用于 SSP 即时通讯的端口号。

完成以上步骤后，即注册成功。
