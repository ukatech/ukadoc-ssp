# 语音合成

这是将人格在对话框中说的话直接读出来的功能。<br>
除了 Windows 自带的语音外，还可以使用 VOICEVOX 等外部语音合成软件，或云端语音合成服务提供的语音。<br>
可以为每个角色（`\0`、`\1`、`\2`及之后的角色）分配不同的语音。

!!! tip "ヒント"

    这是让人格发出声音的功能。若要通过语音与人格交谈，请参阅「[语音识别](speech-recognition.md)」页面。

## 开始使用

1. 在右键菜单中选择「功能」→「语音合成」。该项目会被勾选，并开始朗读。<br>
   再次选择即可关闭。下次启动时也会沿用开启／关闭状态。
2. 在首选项的「[语音识别/语音合成](../config/dictation.md)」中，为各角色选择语音。如果不选择任何语音，使用「(System Default)」时，将使用 Windows 的默认语音。
3. 根据需要调整语速、音量和音高（音调）。更改设置后，从下一次朗读开始生效（无需重启 SSP）。

开启功能时正好正在说的话不会被朗读。从下一句话开始朗读。

## 哪些内容会被朗读

对话框中显示的普通文本会随着显示同步朗读。<br>
以下内容不会被朗读。

- 选项和锚点（点击选择的文字）。
- 表情符号或「★」等符号。出现在句子中间时，会跳过而不朗读，并留出停顿。只有标点符号的发言也不会被朗读。
- 未设置等待时间、瞬间显示的文本。
- 人格指定为不朗读（或使用另一段文本进行朗读）的内容。有些人格读出来的话可能与对话框中显示的内容不同。

使用的语音会根据发言角色而变化。主角色（`\0`）、副角色（`\1`）以及其他角色（`\2`〜）分别使用为其设置的语音。<br>
音高的初始值为：主角色（`\0`）为 0，副角色（`\1`）为 +5（稍高），`\2`及之后的角色为 -5（稍低）。不同角色的音高会略有差异。可随时在首选项的「[语音识别/语音合成](../config/dictation.md)」中更改。

## 让声音与文字同步

以下说明首选项中的「按照语音合成的进度等待脚本播放」设置。

- **关闭（初始设置）**<br>
  对话框中的文字会按平常的速度继续显示，语音则会跟着朗读。<br>
  在语音合成耗时较长的环境中，文字会先显示，语音则会落后。如果在语音落后时开始了下一句话，前一句尚未读完的部分可能会被跳过。
- **开启**<br>
  等待语音读完后再继续播放人格的脚本。这样可以缩小对话框文字与语音之间的延迟，也不容易发生跳读。<br>
  但如果语音合成耗时较长，人格的动作也会相应变慢。

## 使用外部语音合成软件

「语音选择」列表中，除了 Windows 自带的语音，还会显示「LocalAPI-0〜9」和「CloudAPI-0〜9」等项目。<br>
这些是用于外部语音合成的接口。每个接口可以分别设置一组服务器、语音和风格等。可以为不同角色分配不同接口，也可以让多个角色共用同一个接口。

- **LocalAPI**<br>
  连接到在本机（或网络中的其他电脑）上运行的软件。支持 VOICEVOX、VOICEVOX Nemo、SHAREVOX、AivisSpeech、COEIROINK v2、Style-BERT-VITS2，以及兼容 OpenAI 的本地服务器。
- **CloudAPI**<br>
  连接到互联网服务。支持 Aivis Cloud API 和 OpenAI TTS（或兼容服务）。需要获取 API 密钥，使用费用以服务提供方的规定为准。

设置步骤如下。

1. 使用 LocalAPI 时，请先启动语音合成软件。
2. 打开首选项中的「[语音识别/语音合成](../config/dictation.md)」，然后在角色的「语音选择」中选择「LocalAPI-0」等项目。
3. 点击右侧的「设置...」，然后在「类型」中选择要使用的软件。
4. 点击「参照...」后，会显示软件中注册的语音列表。请选择要使用的语音（如果知道 ID，也可以直接输入）。
5. 点击「OK」关闭窗口，然后开启「功能」→「语音合成」。

各项的填写方法因软件而异。详情请参阅「[语音合成详细设置对话框](../config/dictation.md#音声合成の詳細設定ダイアログ-右側の設定ボタン)」。

## 没有声音时

- 请确认「功能」→「语音合成」是否已勾选。
- 请确认首选项中的「音频输出设备」、音量和 Windows 声音设置是否正确，以确保可以播放声音。
- 使用外部语音合成软件时，请确认软件是否正在运行，以及主机名和端口号是否正确。如果点击「参照...」后没有显示语音列表，说明无法连接到软件。
- 使用云端服务时，请确认 API 密钥是否填写正确。
- 如果声音需要等待一段时间才会播放，说明合成耗时较长。若要与人格的动作保持同步，请开启「同步」；若要优先保证动作流畅，请关闭此选项。
- 如果电脑无法使用语音合成功能，首选项中的语音合成项目会显示为灰色，无法选择。
