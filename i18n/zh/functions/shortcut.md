# 快捷键列表

SSP 为常用功能分配了快捷键。

以下标有<strong>【開発】</strong>的功能，在首选项「[常规](../config/ippan.md)」中未开启「启用开发者功能」时无法使用。

| 功能 | 快捷键 |
|---|---|
| 历史记录 | Ctrl - B (Backlog) |
| 日历 | Ctrl - D |
| 开发用面板 | <strong>【開発】</strong>Ctrl - Shift - D (Development) |
| 资源管理器 | Ctrl - E (Explorer) |
| 在资源管理器等中搜索 | Ctrl - F (Find) |
| 最小化 | Ctrl - I / Ctrl - Shift - Return\[无需焦点\] |
| 关闭对话框 | Ctrl - Shift - Delete\[无需焦点\] |
| 保留临时启动的人格 | Ctrl - K (Keep) |
| 脚本日志 | <strong>【開発】</strong>Ctrl - L (Log) |
| SSP 即时通讯 | Ctrl - M (Messenger) |
| 打开文件 | Ctrl - O (Open) |
| 选择文件夹 | Ctrl - F |
| 全部退出 | Ctrl - Q (Quit) |
| 输入脚本 | <strong>【開発】</strong>Ctrl - S (Script) / Ctrl - Shift - Insert |
| 表面测试 | <strong>【開発】</strong>Ctrl - T (Test) |
| 在线更新 | Ctrl - U (Update) |
| 地址栏 | Ctrl - Shift - U (URL) |
| 重置对话框位置 | Ctrl - Shift - F10 |
| 重置外壳位置 | Ctrl - Shift - F12 |
| 退出 | Ctrl - W / Ctrl - F4 |
