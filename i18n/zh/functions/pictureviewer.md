# 图片查看器

这是一个查看器窗口，可用于显示图像文件，并进行缩放、旋转、裁剪等简单操作，也可以转换格式后保存或复制。<br>
除了可以即时查看 SSP 支持的多种图像格式，还能在多个图像标签页之间切换浏览。

很适合用来查看或转换外壳、对话框的素材图片、拍摄的照片等图像。

## 支持的图像格式

主要支持以下图像格式。<br>
“支持范围”中的**SSP 全域**表示 SSP 本体默认可以读取的格式（也可用于外壳、对话框素材等）；**仅查看器**表示只能在此图片查看器中显示的格式（通过操作系统的 WIC 编解码器实现）。

| 格式 | 扩展名 | 支持范围 | 注释 |
|---|---|---|---|
| PNG / APNG | .png / .apng | SSP 全域 | 支持 Alpha（透明度）。可配合使用同名的 .pna 文件提供外部 Alpha。也支持 APNG（动画 PNG）。 |
| WebP | .webp | SSP 全域 | 支持动画和透明度。 |
| GIF | .gif | SSP 全域 | 支持动画和透明度。 |
| MAG | .mag | SSP 全域 | 复古格式（MAKICHAN GRAPHICS，PC-9801 时代）。 |
| Pi | .pi | SSP 全域 | 复古格式（PC-9801 时代的 Pi 格式）。 |
| JPEG | .jpg / .jpeg | SSP 全域 | 自动应用 EXIF Orientation（拍摄时的方向信息）。 |
| BMP | .bmp | SSP 全域 | Windows 位图。 |
| TIFF | .tif / .tiff | SSP 全域 | 支持多页（可通过上一页／下一页切换）。 |
| X BitMap / X PixMap | .xbm / .xpm | SSP 全域 | X Window 系列的文本格式图像。 |
| TGA | .tga | SSP 全域 | Truevision Targa。支持透明度。 |
| Netpbm（Portable anymap） | .pbm / .pgm / .ppm / .pam / .pnm / .pfm | SSP 全域 | Portable Bit／Gray／Pixmap 系列。.pfm 为浮点数（HDR）格式。 |
| PCX | .pcx | SSP 全域 | ZSoft Paintbrush。 |
| QOI | .qoi | SSP 全域 | Quite OK Image Format。 |
| ICO | .ico | SSP 全域 | Windows 图标格式。 |
| DLL/EXE | .dll / .exe | SSP 全域 | 列出 DLL 或 EXE 文件中包含的图标，并逐页显示。 |
| PSD | .psd | SSP 全域 | Adobe Photoshop。除了合并后的图像，也可以单独读取各个图层。 |
| PSP | .psp / .pspimage | SSP 全域 | Paint Shop Pro。支持 version4.0 及更高版本。除了合并后的图像，也可以单独读取各个图层。 |
| OpenRaster | .ora | SSP 全域 | 除了合并后的图像，也可以单独读取各个图层。 |
| Krita | .kra | SSP 全域 | 除了合并后的图像，也可以单独读取各个图层。 |
| CLIP STUDIO | .clip | SSP 全域 | 除了合并后的图像，也可以单独读取各个图层。 |
| GIMP | .xcf | SSP 全域 | 可以单独读取各个图层。无法读取合并后的图像（查看器会合成各个图层来显示，因此不影响使用）。 |
| HEIF / HEIC | .heif / .heic | 仅查看器 | 需要安装操作系统的“[HEIF 图像扩展](https://apps.microsoft.com/detail/9pmmsr1cgpwg)”。 |
| AVIF | .avif | 仅查看器 | 需要安装操作系统的“[AV1 视频扩展](https://apps.microsoft.com/detail/9mvzqvxjbq9v)”。 |
| JPEG XR | .jxr / .wdp / .hdp | 仅查看器 | HD Photo。 |
| DDS | .dds | 仅查看器 | DirectDraw Surface。仅显示第一帧。 |
| 相机 RAW | .cr2 / .nef / .arw 等 | 仅查看器 | 各厂商的 RAW 格式。依赖操作系统的“[RAW 图像扩展](https://apps.microsoft.com/detail/9nctdw2w1bh8)”。 |

!!! tip "ヒント"

    “仅查看器”格式依赖于操作系统中安装的编解码器（图像扩展）。上表列出的是常见格式，具体支持情况可能因环境而异。<br>
    此外，“仅查看器”方式不支持动画和多页图像，始终只显示第一帧。

## 启动方法

可以通过以下任一方式打开图片查看器。

- **[右键菜单](../howto/rclick.md) →“功能”→“图片查看器”**<br>
  启动图片查看器，初始状态下不加载图像。<br>
  ⇒另请参阅“[功能](index.md)”页面。
- **将图像文件拖放到人格上**<br>
  将图像文件拖放到人格上后，如果人格没有对该文件作出响应，文件就会自动在此图片查看器中打开。<br>
  如果文件无法作为图像读取，则不会启动图片查看器。

启动后，可以在查看器中选择“打开图像”，也可以从剪贴板粘贴，或将图像拖放到查看器内，以标签页的形式继续添加图像。

## 窗口构成

- **菜单栏**<br>
  可以通过“文件”“编辑”“显示”菜单执行所有操作（详情见后文）。
- **工具栏**<br>
  以按钮形式排列了常用操作。按钮对应各个菜单项，将鼠标悬停在按钮上时会显示功能名称（工具提示）。<br>
  启用“裁剪”和“将左上角颜色设为透明”时，对应按钮会显示为按下状态。每次点击背景切换按钮时，图标都会变为当前背景（棋盘格／白色／黑色）。
- **标签页**<br>
  每张已打开的图像都会显示为一个标签页。点击标签页即可切换显示的图像。
- **图像显示区域**<br>
  用于显示图像的区域。如果图像大于该区域，则会显示滚动条。
- **状态栏**<br>
  窗口底部会显示当前图像的“尺寸（宽×高）”“缩放比例”“旋转角度（左右翻转时也会显示 `<| />`）”和“格式”。<br>
  对于 WebP 这类扩展名相同但压缩方式不同的格式，会在格式后标注 `(lossless)`（无损）或 `(lossy)`（有损）。如果动画中的每一帧使用了不同的压缩方式，则会显示 `(mixed)`。<br>
  裁剪时，左侧会显示所选区域的坐标。

## 顶部菜单

### 文件

- **打开图像...\[Ctrl+O\]**<br>
  打开文件选择对话框，并在新标签页中打开所选图像。
- **重新载入\[Ctrl+R / F5\]**<br>
  从磁盘重新载入当前显示的图像。<br>
  从文件打开的图像会自动检测外部更新并重新载入；需要手动重新读取时可使用此功能。
- **另存为...\[Ctrl+S\]**<br>
  保存当前显示的图像。可以选择PNG／BMP／JPEG／WebP（无损・有损）格式。<br>
  如果进行了旋转、左右翻转、裁剪或调整大小，保存时会按当前显示状态（所见即所得）保存。

### 编辑

- **复制\[Ctrl+C\]**<br>
  将当前显示的图像复制到剪贴板，并保留透明度。<br>
  旋转、翻转或裁剪时，会按当前显示状态复制。
- **粘贴\[Ctrl+V\]**<br>
  将剪贴板中的图像作为新标签页导入。
- **调整大小...**<br>
  在对话框中指定宽度和高度，以放大或缩小图像。<br>
  原图会保留，指定与原图相同的尺寸即可还原（非破坏性操作）。
- **裁剪**<br>
  开启或关闭裁剪（剪切）模式。<br>
  开启后，可在图像上拖动鼠标以指定裁剪范围。保存或复制时，仅处理该范围。

### 显示

- **实际大小\[Ctrl+0\]**<br>
  将缩放比例恢复为100%（原始大小）。
- **放大\[Ctrl++\] / 缩小\[Ctrl+-\]**<br>
  每次将显示内容放大或缩小1.25倍。缩放比例范围为5%〜1600%。
- **适合窗口**<br>
  自动调整缩放比例，使整张图像适合窗口显示。调整窗口大小时，缩放比例也会随之调整。
- **指定缩放比例...**<br>
  在对话框中直接输入缩放比例（％）并显示图像。
- **上一页\[PageUp\] / 下一页\[PageDown\]**<br>
  在多页TIFF或动画图像中，切换到前一帧（页）或后一帧（页）。
- **向左旋转 / 向右旋转**<br>
  将显示内容向左或向右旋转90度。此操作只影响显示效果，不会更改原始图像数据（但会反映在保存和复制的结果中）。
- **左右翻转**<br>
  将显示内容左右翻转（镜像）。这同样只是显示操作，不会更改原始图像数据。
- **黑色背景 / 白色背景 / 棋盘格背景**<br>
  切换透明部分后方的背景（默认值为棋盘格）。可用于确认透明部分的显示效果。<br>
  此设置在所有标签页中通用，并会在下次启动时保留。
- **将左上角颜色设为透明**<br>
  仅在显示时，将图像左上角（坐标0,0）的颜色视为透明。对于背景不带透明色的图像，此功能有助于确认透明效果。<br>
  此设置在所有标签页中通用，并会在下次启动时保留。

!!! tip "ヒント"

    “将左上角颜色设为透明”仅对原本不带透明度（Alpha）的图像生效。对于已经包含透明部分的图像，即使开启此设置也不会应用，以免意外抹去不该消失的部分。

## 鼠标和键盘操作

转动鼠标滚轮，可围绕光标位置放大或缩小图像。<br>
可通过鼠标中键或标签页上的“×”按钮关闭标签页。也可以右键单击标签页，然后选择“关闭”。<br>
处于裁剪模式时，可在图像上拖动以指定裁剪范围。

主要键盘快捷键如下。

| 按键 | 功能 |
|---|---|
| Ctrl+O | 打开图像 |
| Ctrl+R / F5 | 重新载入 |
| Ctrl+S | 另存为 |
| Ctrl+C | 复制 |
| Ctrl+V | 粘贴 |
| Ctrl+0 | 实际大小（100%） |
| Ctrl++ | 放大 |
| Ctrl+- | 缩小 |
| PageUp | 上一页 |
| PageDown | 下一页 |
| Ctrl+Tab | 切换到下一个标签页 |
| Ctrl+Shift+Tab | 切换到上一个标签页 |

## 各项功能的详细说明

### 放大和缩小

缩放比例范围为5%〜1600%，每次放大或缩小1.25倍。<br>
使用鼠标滚轮时，会围绕光标位置放大或缩小，因此可以快速放大想查看的位置。选择“适合窗口”后，会自动调整缩放比例，使整张图像始终适合窗口显示。

### 旋转和左右翻转

可以向左或向右旋转图像（每次90度），也可以左右翻转。这些操作只影响显示效果，不会修改原始图像数据。

!!! tip "ヒント"

    旋转或翻转后选择“另存为”或“复制”，输出内容会保持当前显示的方向。<br>
    另外，切换页面或调整大小时，旋转、翻转和裁剪状态会被清除。

### 背景和透明部分的显示

可以选择透明部分后方的背景颜色：黑色、白色或棋盘格（默认值为棋盘格）。棋盘格背景会以棋盘状方格显示，方便辨认透明部分。<br>
与“将左上角颜色设为透明”组合使用，可以确认不带透明色的图像的透明效果。

### 调整大小和裁剪

使用“调整大小”可以指定宽度和高度来放大或缩小图像。原图会保留，因此也可以还原到原始尺寸。<br>
开启“裁剪”后，在图像上拖动即可指定裁剪范围。指定的范围会作为保存和复制的对象，坐标会显示在状态栏左侧。裁剪设置按标签页分别保存，不会更改原图。

### 保存・复制

通过“另存为”可以选择 PNG／BMP／JPEG／WebP（无损／有损）。WebP 无损格式可保持原画质，有损格式则可以减小文件大小。<br>
保存对话框中默认选中的格式会与原图格式一致。如果原图是 WebP，还会根据其保存时使用的是无损还是有损格式来选择。<br>
原图为 JPEG，且未调整尺寸或裁剪时，保存时不会重新编码。此时旋转和翻转会以不损失画质的方式应用（无损旋转），EXIF 等元数据则会被删除。<br>
“复制”会在保留透明度的同时将图像发送到剪贴板，因此可以直接将带透明区域的图像粘贴到支持此功能的应用中。

### 自动重新载入

从文件打开的图像如果被外部软件更新，程序会自动检测到，并在约 1 秒后更新显示。此功能适合在编辑图像的同时通过查看器确认效果。

### 多页图像・动画

对于多页 TIFF 以及 GIF、APNG、WebP 等动画图像，可以通过“上一页”“下一页”切换帧进行确认（不会自动播放）。<br>
PSD 的各个图层也可以通过“上一页”“下一页”切换，逐个查看。
