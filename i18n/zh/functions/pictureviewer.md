# 图片查看器

这是一个用于显示图片文件的查看器窗口，可进行缩放、旋转、裁剪等简单操作，也可转换格式后保存或复制。<br>
除了可以直接查看 SSP 支持的多种图片格式，还可以在多个标签页中打开图片并切换浏览。

它适合用来查看外壳、对话框的素材图片或拍摄的照片等，也可用于转换图片格式。

## 支持的图片格式

主要支持的图片格式如下。<br>
“支持范围”中的 **SSP 全局**表示 SSP 本体默认可读取的格式（也可用于外壳和对话框的素材等），**仅查看器**表示只能在此图片查看器中显示的格式（通过操作系统的 WIC 编解码器）。

| 格式 | 扩展名 | 支持范围 | 说明 |
|---|---|---|---|
| PNG / APNG | .png / .apng | SSP 全局 | 支持 Alpha（透明）。可结合使用同名 .pna 文件提供的外部 Alpha。也支持 APNG（动画 PNG）。 |
| WebP | .webp | SSP 全局 | 支持动画和透明。 |
| GIF | .gif | SSP 全局 | 支持动画和透明。 |
| MAG | .mag | SSP 全局 | 复古格式（MAKICHAN GRAPHICS，PC-9801 时代）。 |
| Pi | .pi | SSP 全局 | 复古格式（PC-9801 时代的 Pi 格式）。 |
| JPEG | .jpg / .jpeg | SSP 全局 | 自动应用 EXIF Orientation（拍摄时的方向信息）。 |
| BMP | .bmp | SSP 全局 | Windows 位图。 |
| TIFF | .tif / .tiff | SSP 全局 | 支持多页（通过上一页／下一页切换）。 |
| X BitMap / X PixMap | .xbm / .xpm | SSP 全局 | X Window 系统的文本格式图片。 |
| TGA | .tga | SSP 全局 | Truevision Targa。支持透明。 |
| Netpbm（Portable anymap） | .pbm / .pgm / .ppm / .pam / .pnm / .pfm | SSP 全局 | 可移植位图／灰度图／像素图系列。.pfm 是浮点数（HDR）格式。 |
| PCX | .pcx | SSP 全局 | ZSoft Paintbrush。 |
| QOI | .qoi | SSP 全局 | Quite OK Image Format。 |
| ICO / CUR | .ico / .cur | SSP 全局 | Windows 图标和光标格式。支持 Alpha（透明）。包含多个尺寸时使用最大尺寸。 |
| ANI | .ani | SSP 全局 | Windows 动画光标。支持动画和透明，并遵循播放顺序和等待时间。 |
| DLL/EXE | .dll / .exe | SSP 全局 | 列出 DLL 或 EXE 文件中存储的图标，逐页显示。 |
| PSD | .psd | SSP 全局 | Adobe Photoshop。除合并后的图片外，也可单独读取各图层。 |
| PSP | .psp / .pspimage | SSP 全局 | Paint Shop Pro。4.0 及以后的版本。除合并后的图片外，也可单独读取各图层。 |
| OpenRaster | .ora | SSP 全局 | 除合并后的图片外，也可单独读取各图层。 |
| Krita | .kra | SSP 全局 | 除合并后的图片外，也可单独读取各图层。 |
| CLIP STUDIO | .clip | SSP 全局 | 除合并后的图片外，也可单独读取各图层。 |
| GIMP | .xcf | SSP 全局 | 可单独读取各图层。无法读取合并后的图片（查看器会合成各图层后显示，因此不受影响）。 |
| HEIF / HEIC | .heif / .heic | 仅查看器 | 需要操作系统的“[HEIF 图像扩展](https://apps.microsoft.com/detail/9pmmsr1cgpwg)”。 |
| AVIF | .avif | 仅查看器 | 需要操作系统的“[AV1 视频扩展](https://apps.microsoft.com/detail/9mvzqvxjbq9v)”。 |
| JPEG XR | .jxr / .wdp / .hdp | 仅查看器 | HD Photo。 |
| DDS | .dds | 仅查看器 | DirectDraw Surface。仅显示第一帧。 |
| 相机 RAW | .cr2 / .nef / .arw 等 | 仅查看器 | 各厂商的 RAW 格式。依赖操作系统的“[RAW 图像扩展](https://apps.microsoft.com/detail/9nctdw2w1bh8)”。 |

!!! tip "ヒント"

    “仅查看器”格式依赖操作系统中安装的编解码器（图像扩展）。上表仅列出常见示例，某些环境下可能无法读取。<br>
    此外，“仅查看器”的读取方式不支持动画和多页，始终只显示第一帧。

## 启动方法

可以通过以下任一方式打开图片查看器。

- **[右键菜单](../howto/rclick.md) →“功能”→“图片查看器”**<br>
  以未加载图片的空白状态启动查看器。<br>
  ⇒另请参阅“[功能](index.md)”页面。
- **将图片文件拖放到人格上**<br>
  将图片文件放到人格上时，如果人格没有对该文件作出响应，就会自动在此查看器中打开。<br>
  如果文件无法作为图片读取，查看器便不会启动。

启动后，可以通过查看器中的“打开图片”、从剪贴板粘贴或拖放到查看器内，继续添加图片作为标签页。

## 界面组成

- **菜单栏**<br>
  可以通过“文件”“编辑”“视图”菜单执行所有操作（详见下文）。
- **工具栏**<br>
  以按钮形式排列常用操作。每个按钮都对应一个菜单项，将鼠标悬停在按钮上可显示功能名称（工具提示）。<br>
  裁剪和左上角色透明化开启时，按钮会显示为按下状态。背景切换按钮每按一次，图标就会变为当前背景（棋盘格／白色／黑色）。
- **标签页**<br>
  每张打开的图片对应一个标签页。单击标签页可切换显示的图片。
- **图片显示区域**<br>
  显示图片的区域。如果图片大于该区域，就会显示滚动条。
- **状态栏**<br>
  窗口底部显示当前图片的“尺寸（宽×高）”“缩放比例”“旋转角度（水平翻转时同时显示 `<| />`）”和“格式”。<br>
  对于 WebP 等扩展名相同但压缩方式不同的格式，格式后面会同时显示 `(lossless)`（无损）或 `(lossy)`（有损）。如果动画中各帧的方式不同，则显示 `(mixed)`。<br>
  裁剪时，左侧会显示所选区域的坐标。

## 顶部菜单

### 文件

- **打开图片...\[Ctrl+O\]**<br>
  打开文件选择对话框，在新标签页中打开选中的图片。
- **重新载入\[Ctrl+R / F5\]**<br>
  从磁盘重新载入当前显示的图片。<br>
  从文件打开的图片会自动检测外部更新并重新载入；需要手动重新载入时，可以使用此功能。
- **另存为...\[Ctrl+S\]**<br>
  保存当前显示的图片。格式可选择 PNG／BMP／JPEG／WebP（无损・有损）。<br>
  如果进行了旋转、水平翻转、裁剪或调整大小，将按当前显示状态保存（所见即所得）。

### 编辑

- **复制\[Ctrl+C\]**<br>
  将当前显示的图片复制到剪贴板，同时保留透明度。<br>
  如果进行了旋转、翻转或裁剪，将按当前显示状态复制。
- **粘贴\[Ctrl+V\]**<br>
  将剪贴板中的图片导入为新标签页。
- **调整大小...**<br>
  在对话框中指定宽度和高度，缩放图片。<br>
  原图会被保留，指定与原图相同的尺寸即可恢复原图（无损操作）。
- **裁剪**<br>
  开启或关闭裁剪模式。<br>
  开启后，可以在图片上拖动鼠标指定裁剪范围。保存或复制时，只会处理该范围。

### 视图

- **实际大小\[Ctrl+0\]**<br>
  将缩放比例恢复为100%（原始大小）。
- **放大\[Ctrl++\] / 缩小\[Ctrl+-\]**<br>
  每次以1.25倍的倍率放大或缩小显示。缩放比例范围为5%〜1600%。
- **适合窗口**<br>
  自动调整缩放比例，使整张图片适合窗口大小。调整窗口大小时，图片也会随之调整。
- **指定缩放比例...**<br>
  在对话框中直接输入缩放比例（％）进行显示。
- **上一页\[PageUp\] / 下一页\[PageDown\]**<br>
  在多页 TIFF 或动画图片中，切换到上一帧或下一帧（页面）。
- **向左旋转 / 向右旋转**<br>
  将显示的图片每次向左或向右旋转90度。这只是显示上的旋转，原始图片数据不会改变（保存和复制时会反映旋转效果）。
- **水平翻转**<br>
  将显示的图片水平翻转（镜像）。这也是显示上的操作，原始图片数据不会改变。
- **黑色背景 / 白色背景 / 棋盘格背景**<br>
  切换透明部分背后的背景（默认为棋盘格）。可用于确认透明部分的显示效果。<br>
  此设置适用于所有标签页，下次启动时也会保留。
- **将左上角色设为透明**<br>
  仅在显示时，将与图片左上角（坐标0,0）相同的颜色视为透明。方便确认背景没有透明色的图片的透明效果。<br>
  此设置适用于所有标签页，下次启动时也会保留。

!!! tip "ヒント"

    「将左上角色设为透明」仅对原本没有透明度（Alpha）的图片生效。对于已有透明部分的图片，即使开启该设置也不会应用，以防止意外隐藏其他部分。

## 鼠标和键盘操作

滚动鼠标滚轮，可以鼠标指针的位置为中心放大或缩小图片。<br>
可以用鼠标中键点击标签页或点击标签页上的「×」按钮将其关闭。也可以右键点击标签页并选择「关闭」。<br>
在裁剪模式下，拖动图片以指定裁剪范围。

主要键盘快捷键如下。

| 按键 | 功能 |
|---|---|
| Ctrl+O | 打开图片 |
| Ctrl+R / F5 | 重新载入 |
| Ctrl+S | 另存为 |
| Ctrl+C | 复制 |
| Ctrl+V | 粘贴 |
| Ctrl+0 | 实际大小（100%） |
| Ctrl++ | 放大 |
| Ctrl+- | 缩小 |
| PageUp | 上一页 |
| PageDown | 下一页 |
| Ctrl+Tab | 切换到下一个标签页 |
| Ctrl+Shift+Tab | 切换到上一个标签页 |

## 各功能详情

### 放大和缩小

缩放比例范围为5%〜1600%，每次放大或缩小的倍率为1.25倍。<br>
使用鼠标滚轮时，图片会以鼠标指针的位置为中心缩放，因此可以快速放大想看的位置。选择「适合窗口」后，缩放比例会自动调整，使整张图片始终适合窗口大小。

### 旋转和水平翻转

可以向左或向右旋转（每次90度），也可以水平翻转。这些都是显示上的操作，不会修改原始图片数据。

!!! tip "ヒント"

    在旋转或翻转后执行「另存为」或「复制」，将按当前看到的方向输出。<br>
    此外，切换页面或调整大小时，旋转、翻转和裁剪状态会被清除。

### 背景和透明部分的显示

可以将透明部分背后的背景设为黑色、白色或棋盘格（默认为棋盘格）。棋盘格以交错的方格显示，便于区分透明部分。<br>
与「将左上角色设为透明」配合使用，可以确认没有透明色的图片的透明效果。

### 调整大小和裁剪

使用「调整大小」可以指定宽度和高度来缩放图片。由于原图会被保留，也可以恢复到原始尺寸。<br>
开启「裁剪」并在图片上拖动，即可指定裁剪范围。指定的范围将作为保存和复制的对象，其坐标会显示在状态栏左侧。裁剪设置按标签页分别保存，原图不会改变。

### 保存与复制

在「另存为」中可以选择PNG／BMP／JPEG／WebP（无损・有损）格式。WebP无损格式可以保持原有画质，有损格式可以减小文件大小。<br>
保存对话框中默认选中的格式会与原始图片的格式一致。如果原图是WebP，还会根据原图采用的是无损还是有损格式进行选择。<br>
如果原图是JPEG，且未调整大小或裁剪，则会在不重新编码的情况下保存。此时旋转和翻转操作会在不降低画质的情况下应用（无损旋转），EXIF等元数据会被删除。<br>
「复制」会保留透明度并将图片发送到剪贴板，因此可以直接粘贴到支持透明度的应用中，保留透明部分。

### 自动重新载入

从文件打开的图片在被外部软件更新时，会自动检测到变化，并在约1秒后刷新显示。适合一边编辑图片一边在查看器中确认效果。

### 多页与动画

对于多页TIFF以及GIF・APNG・WebP等动画图片，可以使用「上一页」「下一页」切换帧进行查看（不会自动播放）。<br>
PSD的各个图层也可以通过「上一页」「下一页」切换，分别查看。
