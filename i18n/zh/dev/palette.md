# 面向开发者的帮助：开发用面板

这是一个汇集了有助于开发的设置开关和工具启动按钮的对话框。<br>
它不仅适用于人格开发，也有助于对话框和外壳的开发。

另外，开发用面板中的设置按各个人格分别管理。

## 复选框

### 显示命中区域

勾选后，会显示区域及其判定名称。<br>
半选时，判定名称会隐藏。例如，当区域边框与判定名称重叠而难以看清时，可以使用此选项。<br>
通过查看边框的重叠关系，也能大致了解判定区域的上下关系（位于下方的区域无法触摸）。

示例图片中只显示了矩形判定区域，但当然也支持多边形、圆形等判定区域。

### 对话框测试模式

启用后，`\1`・`\0`对话框上会显示测试用内容。<br>
根据显示的数字，可以确认横向和纵向显示的字符数；此外还会显示以下内容，可用于调整位置等。

- 用于显示更新进度的计数器
- 更新时播放的循环动画（由 `online*.png` 实现）
- 用于滚动的箭头（arrow0/1.png）
- SSTP 标记
- SSTP 消息

### SERIKO等待时间调整

开启后会打开输入框，可以按%单位调整外壳动画的等待时间。<br>
设为100%时，会按照设定的等待时间逐帧播放。<br>
关闭后设置将失效。<br>
可用于检查高速且帧数较多的动画中是否存在错误帧等。

### 仅检查更新

开启后进行在线更新时，会触发更新事件，但实际上不会覆盖文件。<br>
除了可防止因误操作更新而覆盖开发中的文件外，也可用于测试更新事件的运行情况等。

### 更改 SHIORI 的 Sender

开启后会打开输入框，可以更改 SSP 向 SHIORI 声明的发送者名称。<br>
关闭后设置将失效。

### 启用 SHIORI 调用日志

```
=====send=====
GET SHIORI/3.0
Charset: Shift_JIS
Sender: SSP
SecurityLevel: local
ID: OnSecondChange
Reference0: 193
Reference1: 0
Reference2: 0
Reference3: 1
Reference4: 0


=====response=====
SHIORI/3.0 204 No Content
Charset: Shift_JIS
```

开启后会记录 SSP 与 SHIORI 之间的通信日志，并将其输出到人格的 master 文件夹中，文件名为 `ssp_SHIORI_log.txt`。<br>
请注意不要将日志包含在在线更新文件中。<br>
另外，如果一直开启记录并放任不管，日志文件可能会变得非常大，请注意。

### 启用 SHIORI 内部日志功能

开启/关闭状态会通过 SHIORI 事件「`enable_log`」通知。<br>
SHIORI 可以查看该状态，并据此控制是否开启 SHIORI 自身的日志功能。

### 启用 SHIORI 调试功能

开启后，来自 SHIORIEcho 等外部的调试用事件将会启用。<br>
关闭时，出于安全风险考虑，这些事件会被忽略（通常 SHIORI 端也会忽略这些事件）。<br>
请注意，如果不启用此功能，部分 SHIORI 调试工具将无法运行（例如：华和梨的 らふらんす・幸水）。

### 禁用自动切换

开启后，SSP 的[自动切换功能](../config/ghost.md)对该人格将会失效。<br>
开发过程中通常会让人格一直保持启动状态，这项功能可以防止人格在这种情况下被自动切换。

### 禁用自动检查

开启后，该人格运行期间，无论设置如何，都不会自动进行 RSS/在线新闻感知和邮件检查。

### 禁用自动更新

开启后，该人格的[自动更新功能](../config/ghost.md)将被禁用。<br>
这有助于防止开发中的人格数据被更新内容覆盖。

### 不因 `\-` 标签而结束

开启后，即使运行中的脚本出现`\-`（结束人格的命令），也会对该人格忽略此命令。<br>
除了可以避免开发中的人格意外结束外，还可以用于测试包含`\-`的对话。

## 按钮

### 脚本输入

打开 SEND 输入框，输入 Sakura Script 后即可直接执行。<br>
请注意，这里不能输入各 SHIORI 字典所使用的语法。

### 外壳测试

打开用于对外壳进行各种测试的对话框。

对话框中央有四个列表。<br>
最左侧标有**WND**的列表用于选择要操作的作用域（`\0`、`\1`、`\p[2]`...）。<br>
从左数第二个标有**Surface**的列表会显示已识别的外壳列表。在此选择外壳，即可切换 WND 列表中所选作用域的显示。列表上方 Surface 旁边的数字表示（surfaces.txt 中定义的外壳数量/包含只有图像而没有定义的外壳在内的总数）。<br>
从右数第二个标有**ID**的列表会显示所选作用域中定义的动画 ID。选择某个 ID 后，如果当前显示的外壳中定义了该 ID，就会播放对应的动画。列表上方 ID 旁边的数字表示总数。<br>
最右侧的**COL**列表会显示所选外壳中定义的碰撞区域 ID 及其名称。列表上方 COL 旁边的数字表示总数。

点击左下方的「▼」按钮可打开功能菜单。<br>
目前只能选择「Copy Surface List」。选择后，已识别的所有外壳会以「`surface**`」的形式逐行列出，并复制到剪贴板。

其旁边记载着已加载的图像文件数量和总容量。

旁边还有3个复选框。<br>

### 显示错误日志

显示已通知错误的历史记录列表。<br>
详情请参阅「[脚本日志](scriptlog.md#エラーログ)」页面。

### 虚拟更改当前时间

设置时间后，SSP所识别的当前日期和时间将虚拟替换为设定的日期和时间。<br>
这样，无需实际修改OS的时间，也可以测试人格随日期和时间变化而产生的不同行为。

**Present Time**是SSP中当前设定的虚拟日期和时间。<br>
**System Time**是OS内部的实际日期和时间。<br>
按下**Apply**按钮后，输入框中的日期和时间将被设为虚拟时间。<br>
按下**Reset**按钮后，虚拟时间将恢复为System Time。

### SERIKO Inspector

以树状视图显示外壳定义。<br>
每个 surfaceID 都会分出 element、collision、animation 节点（分支），然后再分别分出各自 ID 的节点，并进一步展开其组成部分……以这种方式呈现，便于直观地掌握外壳定义的结构。

点击右下方的 **Dump** 按钮可打开文件保存对话框，并导出以制表符和缩进表示结构的文本文件。

### 重新载入

重新载入菜单中所选的内容。<br>
开发过程中修改、添加或删除文件时，请使用此功能。

### 打开/运行

打开或运行菜单中所选的项目。

- **BALLOON**<br>
  **GHOST**<br>
  **SHELL**<br>
  分别打开当前使用的对话框、人格和外壳文件夹。<br>
  开发过程中经常需要打开这些文件夹，此时可以使用此功能。
- **SHIORI LOG**<br>
  打开通过上述「[启用 SHIORI 调用日志](#shiori呼出ログ有効)」创建的日志文件。<br>
  如果尚未创建日志文件，则无法选择此项。
- **VCS Uppdate**<br>
  **VCS Commit**<br>
  **VCS Log**<br>
  **VCS Revert**<br>
  **VCS Export**<br>
  可在此处操作通过首选项的「[外部应用](../config/extprog.md)」设置的版本管理工具。
- **UPDATE EVENT/NORMAL**<br>
  **UPDATE EVENT/NONE**<br>
  **UPDATE EVENT/ERROR**<br>
  **UPDATE EVENT/NORMAL GBALLOON**<br>
  即使实际上没有更新，也可以使用虚构的更新内容测试更新事件的行为。<br>
  **NORMAL** 会模拟发现更新文件并成功完成更新时的行为。<br>
  **NONE** 会模拟未能发现更新文件时的行为。<br>
  **ERROR** 会模拟因错误（md5 不一致）而中断更新时的行为。<br>
  **NORMAL GBALLOON** 会模拟更新时同时进行的外壳和对话框更新检查；是否执行此操作取决于[首选项中的设置](../config/ghost.md)。
