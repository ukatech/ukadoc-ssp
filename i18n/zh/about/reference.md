# 术语说明

## 人格

指角色数据，或构成其模拟 AI 的部分。<br>
人格负责角色的「个性」，让角色能够做出各种反应、与人交谈，可以说是人格的「内心」或「灵魂」。<br>
不过，当然只有「灵魂」是无法具象化的，因此大多数情况下，也会将其与「外壳」组合成一套，并打包成可直接使用的形式。<br>
此外，根据上下文不同，这个词有时也会像后文提到的「伺か」一样，泛指某种类型或圈子。

## 外壳

指人格立绘的数据。<br>
这是负责显示角色的外观部分。虽然近年来情况有所变化，但从历史上看，由于开发者中男性较多(^\_^;)，外壳大多以女性为原型；不过也有男性、动物、非生物，以及单纯作为信息工具使用的「无萌（Moeless）」外壳。<br>
一个人格可以配备多个外壳，并可通过「外壳」菜单进行切换。

## 对话框

简单来说就是「对话气泡」。这是用于显示人格对话的小窗口。<br>
与上文提到的外壳类似，各种样式的对话框有很多可供下载，也可以轻松安装。

## 在线更新

这是一项通过互联网逐个检测构成人格等内容的文件是否有变化，并仅下载更新部分进行覆盖的功能。<br>
这样一来，用户就不必频繁访问发布网站确认是否有更新，也不必在有更新时下载完整压缩包并覆盖安装，从而省去了这些麻烦。<br>
除了人格，SSP也为外壳、对话框、在线新闻和插件提供同样的功能。<br>
可以从[右键菜单](../howto/rclick.md)更新人格；根据[首选项](../config/ghost.md)设置，也可以从右键菜单更新外壳和对话框；其他内容也都可以从[资源管理器](../functions/explorer/index.md)执行更新。

## 在线新闻

这是一项自动获取特定网站的更新信息等内容，并显示其列表的功能。<br>
在线新闻功能可以通过插件扩展：将插件包**拖放**到当前显示的人格上，或解压后放入 headline 文件夹，再退出并重新启动一次 SSP，即可识别。<br>
此外，也可以自动巡查在线新闻。

## 樱侧/污侧

在过去被称为「伪○○」的时期，以及「何か」的默认人格中，主角色名为樱，副角色名为污，这些称呼便是由此沿用下来的。<br>
SSP 的默认人格「Emily」中，戴着猫耳的女性一侧称为「樱侧」，谜样生物？泰迪一侧称为「污侧」。<br>
`\h`侧/`\u`侧、`\0`侧/`\1`侧、`\p0`侧/`\p1`侧、主角色侧/副角色侧、本体侧/搭档侧等称呼，都与此含义相同。

## SHIORI

这是构建「人格」所用系统的统称。<br>
通常以 Windows DLL 的形式提供，但其设计并不依赖特定操作系统。

## MAKOTO

这是一种用于替换人格或通过 SSTP 通信传来的文本中某些特定词语的机制。<br>
可用于改变语气等效果，例如修改句尾表达。<br>
它通常也以 Windows DLL 的形式提供，但其设计并不依赖特定操作系统。<br>
此外，也有对其功能作广义解释，用来演奏音乐或提供特殊功能的实现。

## SERIKO

指外壳动画。<br>
在 SSP 和伺か中，有时会用这个名称指代外壳动画的规格。

## MAYUNA

指外壳换装机制。<br>
SSP 和伺か中的换装，是作为 SERIKO（动画）的一种实现的。

## Sakura Script

这是指由一系列标签装饰的文本，这些标签用作命令，可控制人格的表情、打开指定 URL，或在对话框中显示文字和图片等；Sakura Script 用于人格、SSTP 等。

## 图像帧

surface，也称作 surface、surface 等。<br>
这是外壳（以及包含对话框等图像的内容）中相当于一张「画面」的部件或元素。<br>
在外壳中，每一种角色表情都对应一个图像帧；换装和动画也通过图像帧的连续播放或合成来呈现。

## SSTP

是 Sakura Script Transfer Protocol 的缩写。这是一种用于在网络上交换上述 Sakura Script 的机制。<br>
它似乎也被称为「毒电波」……(^\_^;)

## 伺か

读作 Ukagaka。<br>
原本是被称为桌面吉祥物的一类应用程序。<br>
不过现在，这个名称也泛指围绕角色数据「人格」形成的类型或社群，其中也包括只能在其兼容应用程序（SSP 也是其中之一）上运行的内容。

## baseware

这是软件「伺か」及其兼容应用程序的总称。SSP 也属于其中一种。<br>
这个称呼源于它是为人格提供运行基础环境的软件。<br>
另外，如上所述，「伺か」一词如今含义宽泛、比较模糊，因此专指作为 baseware 的伺か时，通常称为「MATERIA」。
