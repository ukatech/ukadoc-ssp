# 设置

本页介绍从[右键菜单](../howto/rclick.md)的“设置”子菜单中可以访问的各个项目。

请注意，项目名称可能因人格而异（位置不会改变）。<br>
如果觉得难以理解，可以在首选项的“[人格(1)](ghost.md)”中关闭人格定义菜单的显示。

## 各项目说明

### 首选项

打开 SSP 的首选项对话框。<br>
设置按类别分为多个页面。<br>
⇒各项目的详细说明，请参阅以下对应页面。

- [常规](ippan.md)
- [人格(1)](ghost.md)
- [人格(2)](ghost2.md)
- [文件夹](folder.md)
- [显示](disp.md)
- [谈话/对话框](talk.md)
- [语音识别/语音合成](dictation.md)
- [连接(1)](conn1.md)
- [连接(2)](conn2.md)
- [POP](pop.md)
- [外部应用](extprog.md)
- [IM](im.md)
- [国际化](i18n.md)
- [流媒体](streamingtool.md)
- [开发/其他](dev.md)

### 各人格的设置

打开可以为各个人格分别设置项目的对话框。<br>
⇒详情请参阅[详细页面](eachghost.md)。

### 窗口模式

切换“窗口模式”，将人格集中显示在一个窗口中。<br>
可以从“关”“全部人格”（将所有人格集中在一个窗口中）和“每个人格”（每个人格一个窗口）这3种模式中选择。<br>
⇒详情请参阅“[窗口模式](../functions/windowmode.md)”页面。

### 启用代理服务器

用于启用或停用已设置的代理服务器的快捷开关。<br>
代理服务器的详细设置可在首选项的“[连接(1)](conn1.md)”中进行，此项目与该页面上的复选框开关相同。

### 字符编码设置

指定读取人格内部各个文件时使用的字符编码。<br>
通常会自动识别，无需设置；不过，在非日文版 Windows 等环境中使用时，这项设置可能会派上用场。

### 让人格决定谈话时机

通常保持开启（已勾选）即可。<br>
运行旧人格等情况下，关闭此选项后，人格有时就会自行开始谈话。　

### 旧版规格支持

通常保持关闭（未勾选）即可。<br>
运行旧人格等情况下，开启此选项后，人格有时就会开始谈话。　<br>
反过来说，如果行为异常，也可能是此选项处于开启状态。请尝试将其关闭。
