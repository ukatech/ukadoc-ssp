# 设置：IM

本页介绍通过右键菜单的“设置”子菜单中的“首选项”打开的对话框里，“IM”页面的内容。

此处用于设置 SSP 独有的、基于 SSTP 或 IP Messenger 的即时通讯功能。

## 各项目说明

- **名称**<br>
  请输入在即时通讯中使用的名称，例如你的昵称。　
- **群组**<br>
  在即时通讯中使用的群组名称。
- **使用 SSTP 时不进行转换**<br>
  通过 SSTP 通信发送 Sakura Script 时，会忽略一种称为“转换”的人格内部文字转换机制，直接播放 Sakura Script。通常无需勾选。
- **发送后清空消息对话框**<br>
  发送消息后，清除消息输入框中输入的文字。
- **使用 IP Messenger 兼容模式**<br>
  设置为可以使用 IP Messenger 收发消息。
- **端口号**<br>
  设置 IP Messenger 使用的端口号。<br>
  通常无需设置。　
- **拨号连接**<br>
  如果所处环境无法传递广播，但仍想使用 IP Messenger 功能，请设置此项。通常保持关闭即可。

### 指定广播/多播目标地址

指定要向其发送登录、注销消息等内容的 IP 地址。<br>
通常应指定称为“广播地址”或“多播地址”的地址，这类地址可以向同一网段中的设备发送消息。

默认设置为 255.255.255.255。如果此设置可以正常工作，则无需更改。

## 下方的按钮

- **帮助**<br>
  打开首选项对话框中当前设置页面的帮助（也就是本页）。<br>
  对话框右上角的“？”标记也有相同的作用。
- **关闭**<br>
  关闭首选项对话框。<br>
  对话框右上角的“×”标记也有相同的作用。
