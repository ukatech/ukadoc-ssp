# 设置：外部应用程序

本页介绍在右键菜单的“设置”子菜单中选择“首选项”后打开的对话框里的“外部应用程序”页面。

本页用于设置从 SSP 启动的应用程序。

这里用于设置 SSP 根据需要启动的应用程序。通常会自动检测默认设置等，因此不一定需要进行设置。

## 各项说明

### 浏览器设置

这是在通过“推荐”等功能访问 URL 时使用的浏览器设置。<br>
如果想要使用其他浏览器，请进行设置。<br>
通常，留空时会使用系统设置的默认浏览器（＝大多数情况下为 Internet Explorer），因此一般无需特别设置。

### 文件管理器设置

这是在需要使用文件管理软件时要启动的软件设置，例如从资源管理器的右键菜单中选择“打开”。<br>
通常，留空时会启动 Windows Explorer，因此无需特别设置。

### 编辑器设置

这是从人格打开文本文件时使用的应用程序设置。<br>
通常，留空时会使用记事本等系统设置的默认程序，因此一般无需特别设置。

**参数**：可以指定传递给编辑器的参数。<br>
%1 会替换为文件名（完整路径），%2 会替换为打开文件时所选的行（数值）。

### 邮件客户端设置

这是从人格启动邮件软件或收到创建新邮件指令时使用的邮件软件设置。<br>
通常，留空时会使用系统设置的默认邮件软件，因此一般无需特别设置。

**参数**：可以指定仅在发送新邮件时使用的参数。收到创建新邮件的指令时，可以在此设置以何种形式将邮件地址传递给邮件软件。不同邮件软件的设置各不相同，请参阅相应软件的说明书。

另外，%1 会替换为「"mailto:地址"」。

EdMax 示例：　/A="%1"<br>
Becky!Ver2 示例：　"%1"<br>
Outlook Express 示例：　/mailurl:%1

### 版本控制工具

通过 SSP 执行 Subversion 或 Git，就可以像更新普通人格一样执行版本控制工具的更新。<br>
在这里，可以手动选择要使用的工具。<br>
通常会自动搜索，因此无需进行设置。

- **Subversion**<br>
  留空时，会自动搜索 TortoiseSVN。
- **Git**<br>
  留空时，会自动搜索 TortoiseGit。

**注记**：<br>
※浏览器和邮件客户端均留空时，会使用“Internet”控制面板中的设置。<br>
※文件管理器留空时，会使用 Windows 资源管理器。<br>
※编辑器留空时，会遵循 .txt 文件关联。通常为记事本。

## 下方的按钮

- **帮助**<br>
  打开首选项对话框中当前设置页面的帮助（也就是本页）。<br>
  对话框右上角的“？”图标也有相同功能。
- **关闭**<br>
  关闭首选项对话框。<br>
  对话框右上角的“×”图标也有相同功能。
