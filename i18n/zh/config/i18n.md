# 设置：国际化

本页介绍通过右键菜单的“设置”子菜单中的“首选项”打开的对话框里，“国际化”页面的内容。

本页用于设置与国际化相关的选项。

此处的设置与显示内容的国际化有关。

## 各项目说明

### 覆盖菜单字体设置 / 覆盖对话框字体设置

更改菜单和对话框使用的字体。<br>
这有助于减少在非日文版 Windows 上使用时出现的乱码，也可以用于单纯地更换显示字体。

- **选择**<br>
  打开字体选择对话框，选择用于显示的字体。
- **标准设置**<br>
  恢复标准设置。

### 未指定时使用的字符编码

在非日文操作系统环境中启动日文人格时，如果发生与字符编码有关的问题并出现乱码，可以更改此设置。<br>
通常请将所有选项保持为 Default（默认）。SSP 会尽可能自动识别。

- **文本定义**<br>
  指定 descript.txt、install.txt、surfaces.txt 等文本定义文件的字符编码。
- **文件输入/输出**<br>
  指定在线更新、解压 Zip 等文件输入/输出处理所使用的字符编码。
- **readme**<br>
  指定 readme.txt 文件的字符编码。
- **SHIORI**<br>
  指定与 SHIORI（AI）通信时使用的字符编码。
- **MAKOTO**<br>
  指定与 MAKOTO 插件通信时使用的字符编码。
- **PIRO（旧版）**<br>
  指定与旧版 PIRO 插件通信时使用的字符编码。
- **SCRIPT（旧版）**<br>
  指定旧版脚本处理所使用的字符编码。<br>
  从 2.8.86 版本起，除了旧规格的脚本定义文件（如 script.txt）之外，读取新闻定义（news.txt）时也会应用此设置。

## 下方的按钮

- **帮助**<br>
  打开首选项对话框中当前设置页面的帮助（也就是本页）。<br>
  对话框右上角的“？”标记也有相同的作用。
- **关闭**<br>
  关闭首选项对话框。<br>
  对话框右上角的“×”标记也有相同的作用。
