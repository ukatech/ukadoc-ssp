# 设置：邮件

本页介绍通过右键菜单的“设置”子菜单中的“首选项”打开的对话框里的“邮件”页面。

本页介绍邮件检查功能的设置。

这里可以设置检查是否有邮件到达 SSP 的功能。

## 各项说明

- **同时获取邮件头（也获取主题等信息）**<br>
  同时获取邮件头，以便人格能够解析邮件头（例如标题）。<br>
  如果不想将邮件头传递给人格，请关闭此项。
- **将新邮件数量作为邮件数通知**<br>
  通常，人格会告诉您“有××封邮件”，但这个数量是服务器上保留的邮件数量，而不是新邮件的数量。<br>
  启用此设置后，人格说出的将是新邮件数量，而不是服务器上的邮件数量。
- **仅在有新邮件时显示消息**<br>
  只有存在新邮件时，人格才会告诉您有邮件到达。

### 指定邮件到达时播放的声音

有新邮件到达时，会播放此处设置的音频文件。使用“浏览...”按钮选择文件，使用“无”按钮清除声音设置，使用“播放”按钮试听设置的声音。

### 账户设置

要添加账户，请点击“添加...”按钮；要删除账户，请在下方列表中选中该账户，然后点击“删除”按钮。<br>
要修改设置，请点击“更改...”按钮。点击“复制”按钮可以复制现有设置并新建账户。

- **账户名称**<br>
  请取一个便于自己识别的名称。此名称会显示在邮件检查菜单中。
- **类型**<br>
  支持 XOAUTH2-POP3/APOP/普通 POP3、XOAUTH2-IMAP4/IMAP4 和 NNTP。<br>
  请阅读服务提供商或其他邮件服务的使用说明后进行设置。<br>
  通常可以通过 POP3 或 APOP 连接。<br>
  XOAUTH2-POP3/XOAUTH2-IMAP4 属于通常所说的“现代身份验证”等方式。<br>
  使用此功能时，请在用户 ID 中输入“邮件地址”，并在密码中输入“访问令牌”。<br>
  访问令牌（Bearer token）的获取方法，请参阅各服务面向开发者的帮助文档等。
- **服务器**<br>
  输入存储您邮件的 POP 服务器地址。<br>
  通常，服务提供商提供的资料中会有“POP 服务器地址”之类的项目，请将其照抄到此处（使用半角字符）。<br>
  只有 NNTP 可以使用特殊格式，例如 nntp.example.com/`fj.*`，在斜杠后填写组名（或包含通配符的模式）
- **端口号**<br>
  通常保持默认值即可。<br>
  只有在指定了特殊端口号时才需要修改。
- **用户 ID/密码**<br>
  输入您的邮件用户 ID 和密码。<br>
  请注意，这些信息通常与用于连接互联网的用户名和密码不同。<br>
  使用 XOAUTH2 系列功能时，请分别将其理解为邮件地址和访问令牌。<br>
  连接不需要身份验证的 NNTP 服务器时，请先填写 guest/guest。
- **使用 SSL/TLS 连接服务器**<br>
  连接邮件服务器时，使用 SSL/TLS 加密以保护信息。<br>
  通常无需设置也可以连接，但也有 Gmail 等服务要求始终启用此项。
- **验证 SSL/TLS 服务器证书**<br>
  这是上述 SSL/TLS 功能的附加设置。通常请保持启用。<br>
  某些免费服务等可能需要关闭此项才能避免通信错误。
- **自动检查**<br>
  每隔指定时间自动检查是否有邮件到达。<br>
  请勿将检查间隔设得太短。

## 底部按钮

- **帮助**<br>
  打开首选项对话框中当前设置页面的帮助（也就是本页）。<br>
  对话框右上角的“？”标记也有相同作用。
- **关闭**<br>
  关闭首选项对话框。<br>
  对话框右上角的“×”标记也有相同作用。
