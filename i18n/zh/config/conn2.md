# 设置：连接(2)

本页介绍通过右键菜单的「设置」子菜单中的「首选项」打开的对话框内的「连接(2)」页面。

此页面用于设置网络连接相关选项。

## 各选项说明

### 在线新闻

- **自动检查**<br>
  如果希望定期自动执行在线新闻检查，请开启此选项。间隔可以按分钟设置。
- **手动执行在线新闻时更新自动巡查的起始位置**<br>
  使用自动检查功能时，将下次要执行的在线新闻设为手动执行的项目的下一项。<br>
  如果关闭此功能，每次都会从列表顶部开始按顺序巡查。
- **指定更新时播放的声音**<br>
  指定在线新闻检查发现更新时播放的声音。

### SSTP通信

设置SSP接收SSTP所用的端口。<br>
列表中IPv4和IPv6至少有一项启用的端口将用于SSTP监听。<br>
初始设置中，9801和9821端口的IPv4、IPv6均为Local（仅限此PC内部），11000端口则处于禁用状态。

列表左列为端口号，右列为状态。状态中会显示以下内容。

- 接收设置的类型（Local、Global、Custom）。禁用的端口显示为「Disabled」。
- 监听失败时，会在「Error:」（部分失败时为「Partial:」）后显示原因。例如「invalid address」（地址格式不正确）、「port in use」（端口已被其他程序使用）、「address not available」（此PC上没有该地址）、「no address in range」（没有属于指定范围的地址）等。
- 监听的IP版本（如`[IPv4+IPv6]`），以及使用Custom时指定的地址。

最左侧的图标也会根据接收设置的类型（Global、Local、Custom）和监听结果（成功、部分成功、失败）而变化。禁用的端口使用专用图标。

- **添加...**<br>
  添加端口。将打开[SSTP端口设置](#sstpポートの設定)对话框。
- **删除**<br>
  删除列表中选中的端口。
- **编辑...**<br>
  更改列表中选中端口的设置。双击列表中的端口也可以进行编辑。
- **右键点击**→**Retry Listen**<br>
  这是右键点击列表中的端口时显示的菜单项。可重新监听该端口。<br>
  可用于重试监听失败的端口，或在DHCP等原因导致此PC的地址发生变化后，重新获取以范围（CIDR）指定的端口的监听地址。

使用启动选项 `--sstp-listen` 启动期间，列表仅供查看，无法添加、删除或编辑（只能使用Retry Listen）。

!!! tip "ヒント"
    如果指定Global，或在Custom中指定非Local地址，SSP也会接受来自其他PC的SSTP。请仅在可信的网络中使用。

- **记录SSTP日志**<br>
  将通过SSTP通信收到的脚本和事件内容写入`log\SSTP.log`文件。<br>
  有些人格会利用此日志改变谈话内容，因此请按需开启。<br>
  点击后会进入指定日志最大KB数的画面。请输入希望设置的日志最大大小。
- **使未启动的人格也显示为已启动**<br>
  为了配合其他支持SSTP的软件，会将信息写入特定区域，使未启动的人格也显示为已启动。<br>
  如果不启用此设置，「尽可能使用指定人格播放」可能无法正常工作。
- **不因带选项的SSTP而阻塞**<br>
  通常收到带选项的SSTP时，为了将选中的选项返回给发送方，在选中选项之前，即使收到其他SSTP也不会播放。<br>
  这是规格上的限制。如果不希望被选项阻塞（例如播放SSTP Bottle时），可以开启此选项来改变行为。<br>
  但在这种情况下，以会返回选项为前提进行处理的工具将无法正常工作，请务必谨慎使用。
- **完全禁用人格内的SSTP过滤处理**<br>
  某些人格可能设置为完全屏蔽来自外部的SSTP，或忽略没有特定指定内容的SSTP，因此不会播放SSTP内容。<br>
  开启此功能可以禁用所有这些限制，但这会无视作者防止角色形象被破坏的意愿，因此请充分考虑后谨慎启用。
- **启动人格**<br>
  指定SSTP通信中收到启动特定人格的指令时的行为。<br>
  通常设置为仅根据通过SSP 即时通讯发送的指令启动\[仅即时通讯\[SSTP/1.5\]\]。<br>
  对于性能较低的设备，强烈建议选择「完全不启动」。<br>
  对于性能充足的设备，选择「尽可能使用指定人格播放」会更加热闹（但也可能变得不稳定）。
- **启动后的处理**<br>
  指定关闭通过上述设置临时启动的人格的时机。
- **临时启动人格的最大数量**<br>
  指定通过SSTP临时启动的人格的最大数量。<br>
  超过此数量时，将从较早启动的人格开始依次关闭。
- **临时启动人格的最小启动间隔**<br>
  指定通过SSTP临时启动人格的间隔。<br>
  如果同时收到大量请求，距离上一次请求尚未经过此处设置的秒数时，将返回409 Conflict，不会启动人格。<br>
  此设置仅在需要临时启动人格时生效。如果不需要临时启动，则会立即接受请求。

### SSTP端口设置

这是通过SSTP通信中的「添加...」「编辑...」打开的对话框。可为单个端口设置以下选项。

- **端口号**<br>
  要监听的端口号。请在1〜65535之间指定。<br>
  不能使用与其他端口相同的号码。不过，使用Custom且指定的地址不重叠时，可以添加相同号码的端口。
- **IPv4・IPv6**<br>
  要监听的IP版本。如果两项均未勾选，该端口将被禁用（不进行监听）。
- **接收设置**<br>
  选择接受来自何处的SSTP。

  - **Local (仅限PC内部)**<br>
    仅接受来自此PC内部（127.0.0.1和::1）的SSTP。这是初始设置。
  - **Global (全部允许)**<br>
    监听所有地址。也会接受来自其他PC的SSTP。
  - **自定义**<br>
    仅监听指定的地址。下方的地址栏仅在选择自定义时可以输入。

    - 请使用数字地址指定（不能使用主机名）。可以用逗号分隔来指定多个地址。例如：`192.168.0.5, ::1`
    - 也可以像 `192.168.192.0/24` 这样指定范围（CIDR）。指定范围后，将监听当前分配给此PC的地址中属于该范围的所有地址。即使在地址因DHCP而变化的环境中，只要指定了范围，重新监听（重启SSP或在列表中右键点击「Retry Listen」）即可使用新地址。<br>
      `127.0.0.0/8` 属于回环地址。前缀长度为地址的最大长度（IPv4为32，IPv6为128）时，等同于单个地址。
    - 仅当指定地址对应的版本（IPv4・IPv6）已勾选时，才会使用该地址。例如，未勾选IPv4时，不会使用IPv4地址。
    - 即使指定了格式不正确的地址、此PC上不存在的地址，或不包含此PC地址的范围，设置仍会保存。此时监听将失败，列表中会显示错误。
- **此PC的网络**<br>
  这是自定义地址栏下方的只读栏。当前分配给此PC的地址所属的网络会以逗号分隔的CIDR形式显示，例如 `192.168.192.0/24, 2001:db8:1::/64`。无法确定范围长度时，仅显示地址。<br>
  可以选中并复制，然后直接粘贴到地址栏中。

## 底部按钮

- **帮助**<br>
  打开首选项对话框中当前设置页面的帮助（即本页）。<br>
  对话框右上角的「？」标记也有相同功能。
- **关闭**<br>
  关闭首选项对话框。<br>
  对话框右上角的「×」标记也有相同功能。
