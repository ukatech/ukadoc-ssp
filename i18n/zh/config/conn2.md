# 设置：连接(2)

本页面介绍通过右键菜单的「设置」子菜单中的「首选项」打开的对话框里的「连接(2)」页面。

此页面用于设置网络连接相关选项。

## 各项说明

### 在线新闻

- **自动检查**<br>
  如果希望定期自动检查在线新闻，请开启此选项。检查间隔可以分钟为单位设置。
- **手动执行在线新闻时更新自动巡查起始位置**<br>
  自动检查功能下，将下次执行的在线新闻设为手动执行的项目的下一项。<br>
  如果关闭此功能，每次都会从顶部开始按顺序巡查。
- **指定更新时播放的声音**<br>
  指定在线新闻检查发现更新时播放的声音。　

### SSTP 通信

设置 SSP 接收 SSTP 的端口。<br>
列表中 IPv4 和 IPv6 至少有一项启用的端口将用于监听 SSTP。<br>
默认情况下，9801 和 9821 端口的 IPv4、IPv6 均为 Local（仅限本机），11000 端口则处于禁用状态。

列表左列是端口号，右列是状态。状态中会显示以下内容。

- 接收指定类型（Local、Global、Custom）。禁用的端口显示为「Disabled」。
- 监听失败时，会在「Error:」（部分失败时为「Partial:」）后显示原因。原因包括「invalid address」（地址格式不正确）、「port in use」（端口已被其他程序使用）、「address not available」（本机没有该地址）、「no address in range」（没有属于该范围的地址）等。
- 监听的 IP 版本（如 `[IPv4+IPv6]`），以及使用 Custom 时指定的地址。

最左侧的图标根据接收指定类型（Global、Local、Custom）而有所不同，也会随监听成功、部分成功或失败的状态变化。禁用的端口使用专用图标。

- **添加...**<br>
  添加端口。将打开 [SSTP 端口设置](#sstpポートの設定)对话框。
- **删除**<br>
  删除列表中选中的端口。
- **编辑...**<br>
  更改列表中选中的端口的设置。双击列表中的端口也可执行相同操作。
- **右键单击**→**Retry Listen**<br>
  右键单击列表中的端口时会显示此菜单。可重新监听该端口。<br>
  可用于重试监听失败的端口，或在 DHCP 等导致本机地址改变后，重新获取按范围（CIDR）指定的端口所监听的地址。

使用启动选项 `--sstp-listen` 启动期间，列表仅供查看，无法添加、删除或编辑（只能使用 Retry Listen）。

!!! tip "ヒント"
    选择 Global 或在自定义设置中指定非 Local 地址时，也会接收来自其他电脑的 SSTP。请仅在可信网络中使用。

- **记录 SSTP 日志**<br>
  将 SSTP 通信中收到的脚本和事件内容写入名为 `log\SSTP.log` 的文件。<br>
  有些人格会利用此日志改变谈话内容，请根据需要开启。<br>
  单击后会显示指定日志最大 KB 数的界面。请输入希望设置的日志最大大小。
- **让未启动的人格也看起来处于启动状态**<br>
  为了供其他支持 SSTP 的软件使用，将信息写入特定区域，使未启动的人格也看起来处于启动状态。<br>
  如果不启用此设置，「尽可能由指定人格播放」可能无法正常工作。
- **不因带选项的 SSTP 而阻塞**<br>
  通常收到带选项的 SSTP 时，为了将用户选择的选项返回给发送方，在选定选项之前，即使收到其他 SSTP 也不会播放。<br>
  这是由规格造成的问题。如果因选项而阻塞会带来不便（例如播放 SSTP Bottle 时），可以开启此选项来改变行为。<br>
  但在这种情况下，依赖返回选项进行处理的工具将无法工作，请务必谨慎使用。
- **完全禁用人格内的 SSTP 过滤处理**<br>
  某些人格设置了完全屏蔽外部 SSTP，或忽略不带特定指定的 SSTP，因此可能不会说出 SSTP 内容。<br>
  开启此功能可禁用所有此类限制，但这会无视作者防止角色形象崩坏的意愿，因此请在充分考虑后谨慎启用。
- **启动人格**<br>
  指定在 SSTP 通信中收到启动特定人格的指令时的行为。<br>
  默认设置为仅响应通过 SSP 即时通讯发出的启动指令\[仅即时通讯\[SSTP/1.5\]\]。<br>
  性能较弱的电脑强烈建议选择「一律不启动」。<br>
  性能充裕的电脑选择「尽可能由指定人格播放」会更加热闹（但也会变得不稳定）。
- **启动后的处理**<br>
  指定关闭通过上述设置临时启动的人格的时机。
- **临时启动人格的最大数量**<br>
  指定通过 SSTP 临时启动的人格的最大数量。<br>
  超过此数量时，将从先前启动的人格开始依次关闭。
- **临时启动人格的最小启动间隔**<br>
  指定通过 SSTP 临时启动人格的启动间隔。<br>
  如果一次收到大量请求，距上一个请求未经过此处设置的秒数时，将返回 409 Conflict，不会启动人格。<br>
  此设置仅在需要临时启动人格时适用。如果不需要，则会立即接受请求。

### SSTP 端口设置

这是通过 SSTP 通信中的「添加...」「编辑...」打开的对话框。可为单个端口设置以下项目。

- **端口号**<br>
  要监听的端口号。可指定为 1〜65535。<br>
  不能使用与其他端口相同的号码。但是，如果两者都使用自定义设置，且指定的地址不重叠，则可以同时使用相同的号码。
- **IPv4・IPv6**<br>
  要监听的 IP 版本。如果两项都取消勾选，该端口将被禁用，不再监听。
- **接收指定**<br>
  选择接收来自何处的 SSTP。

  - **Local (仅限本机)**<br>
    仅接收来自本机（127.0.0.1 和 ::1）的 SSTP。这是默认设置。
  - **Global (允许全部)**<br>
    在所有地址上监听，也会接收来自其他电脑的 SSTP。
  - **自定义**<br>
    仅在指定的地址上监听。只有选择自定义时，才能在下方的地址栏中输入内容。

    - 使用数字地址指定（不能使用主机名）。可用逗号分隔并指定多个地址。例如：`192.168.0.5, ::1`
    - 也可以像 `192.168.192.0/24` 这样按范围（CIDR）指定。指定范围后，将在当前分配给本机的地址中，所有属于该范围的地址上监听。即使在地址因 DHCP 而改变的环境中，只要按范围指定，重新启动 SSP 或在列表中右键单击并选择「Retry Listen」重新监听，就可以在新地址上监听。<br>
      `127.0.0.0/8` 属于环回地址。前缀长度为地址的最大值（IPv4 为 32，IPv6 为 128）时，与单个地址相同。
    - 只有勾选了指定地址对应的版本（IPv4、IPv6）时，才会使用该地址。例如，未勾选 IPv4 时不会使用 IPv4 地址。
    - 即使指定了格式不正确的地址、本机没有的地址，或不包含任何本机地址的范围，设置仍会保存。此时监听会失败，列表中会显示错误。
- **本机网络**<br>
  这是自定义地址栏下方的只读栏位。当前分配给本机的地址所属网络会以逗号分隔的 CIDR 格式显示，如 `192.168.192.0/24, 2001:db8:1::/64`。无法确定前缀长度时，仅显示地址。<br>
  可以选中并复制，直接粘贴到地址栏中。

## 底部按钮

- **帮助**<br>
  打开首选项对话框中当前设置页面的帮助（即本页面）。<br>
  对话框右上角的「？」标记也有相同作用。
- **关闭**<br>
  关闭首选项对话框。<br>
  对话框右上角的「×」标记也有相同作用。
