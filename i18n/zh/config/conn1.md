# 设置：连接(1)

本页介绍通过右键菜单的「设置」子菜单中的「首选项」打开的对话框里的「连接(1)」页面。

本页用于设置网络连接相关选项。

通常无需特别设置此区域，但如果要从防火墙内部的计算机执行在线更新等操作，有时可能需要进行设置。

!!! tip "ヒント"

    这里还有一些面向如今已很少见的连接环境的设置选项，请感受一下历史的痕迹。

## 各项说明

### 常规

- **使用的网络协议**<br>
  设置 IPv4、IPv6 的使用方式。<br>
  通常保持为\[Auto\]即可。<br>
  IPv4=>IPv6、IPv6=>IPv4分别会按照前者=>后者的顺序尝试名称解析等操作。
- **在 SSL/TLS 通信中验证服务器证书**<br>
  通常请保持开启。只有在与支持 SSL 等协议的服务器通信时出现问题，才可以暂时关闭试试。<br>
  此外，邮件检查器(POP3S)等可以[单独设置](pop.md)，无需在此处设置。

### 代理服务器(Proxy)设置

- **自动使用 Windows 设置**<br>
  将 InternetExplorer 的设置用作代理设置。<br>
  如果不清楚设置内容，建议始终勾选此项。
- **通过代理服务器连接**<br>
  如果知道代理服务器的信息，请在下方输入代理服务器名称和端口号，然后勾选此项。这样，在线新闻传感器等就会通过代理服务器获取数据。
- **用户名／密码**<br>
  设置需要用户身份验证的缓存服务器所用的用户名和密码。可以留空。

### 网络连接询问

- **未连接到网络时**<br>
  仅适用于拨号连接环境。勾选后会监控连接状态并自动控制网络连接。<br>
  请勿在其他环境中使用。
- **始终在以下时段内**<br>
  开启后，在指定时间范围内（例如非电话优惠时段的在线新闻检查），将禁止自动连接网络。<br>
  但是，如果您手动要求检查在线新闻，或人格指示进行邮件检查，则会显示对话框询问是否连接。

### 时钟同步

指定时钟同步时使用的 SNTP/HTTP 服务器。<br>
也可以不指定服务器，保持\[RANDOM\]设置不变。如果没有无法正常工作的情况，建议保持原样。

- **SNTP 服务器 / HTTP 服务器**<br>
  选择用于时钟同步的服务器类型。<br>
  使用 HTTP 进行时钟同步的精度不太高。仅在防火墙内部等无法使用 SNTP 时使用。
- **自动执行时钟同步**<br>
  按指定的时间间隔自动执行时钟同步。间隔可以按小时设置。

## 底部按钮

- **帮助**<br>
  打开首选项对话框中当前设置页面的帮助（也就是本页）。<br>
  对话框右上角的「？」标记也有相同作用。
- **关闭**<br>
  关闭首选项对话框。<br>
  对话框右上角的「×」标记也有相同作用。
