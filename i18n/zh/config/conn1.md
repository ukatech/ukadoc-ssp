# 设置：连接(1)

本页介绍通过右键菜单中「设置」子菜单的「首选项」打开的对话框里的「连接(1)」页面。

本页面用于配置网络连接相关设置。

一般来说，无需特别配置此处的设置，但从防火墙内部的计算机进行在线更新等操作时，可能需要配置。

!!! tip "ヒント"

    其中也有一些针对如今已很少见的连接环境的设置，不妨感受一下历史的痕迹。

## 各项设置说明

### 常规

- **使用的网络协议**<br>
  设置如何使用 IPv4、IPv6。<br>
  通常保持为 \[Auto\] 即可。<br>
  IPv4=>IPv6、IPv6=>IPv4 分别按前者=>后者的顺序尝试名称解析等操作。
- **在 SSL/TLS 通信中验证服务器证书**<br>
  通常请保持开启。只有在与支持 SSL 等协议的服务器通信出现问题时，才尝试暂时关闭。<br>
  邮件检查器(POP3S)等可以[单独设置](pop.md)，无需在此设置。

### 代理服务器(Proxy)设置

- **自动使用 Windows 的设置**<br>
  使用 InternetExplorer 的代理设置。<br>
  如果不清楚设置内容，建议始终勾选此项。
- **使用代理服务器**<br>
  如果知道代理服务器的信息，请在下方输入代理服务器名称和端口号并勾选此项，在线新闻传感器等便会通过代理服务器获取数据。
- **用户名／密码**<br>
  用于设置需要用户身份验证的缓存服务器的用户名和密码。可以留空。

### 网络连接询问

- **未连接到网络时**<br>
  仅在拨号连接环境下，勾选此项可监视连接状态并自动控制网络连接。<br>
  请勿在其他环境中使用。
- **在以下时段内始终**<br>
  开启后，将禁止在线新闻获取等操作在指定时段内自动连接网络，例如避开 Telehodai 优惠时段以外的时间。<br>
  但如果您手动指示获取在线新闻，或人格指示检查邮件，则会显示对话框，询问是否连接。

### 时间同步

指定进行 NTP 时间同步时使用的 SNTP/HTTP 服务器。<br>
也可以不指定服务器，保持 \[RANDOM\] 设置正常运行，因此除非出现无法正常工作等问题，否则建议保持原样。

- **SNTP 服务器 / HTTP 服务器**<br>
  选择用于 NTP 时间同步的服务器类型。<br>
  使用 HTTP 进行时间同步的精度不太高。仅在防火墙内等无法使用 SNTP 的情况下使用。
- **自动执行时间同步**<br>
  按指定的时间间隔自动执行时间同步。时间间隔以小时为单位设置。<br>
  使用启用了 UAC 的管理员账户正常启动 SSP 时，无法选择此项。使用标准用户账户时，每次修正时钟都可能出现确认界面（UAC）。即使关闭此设置，人格进行 NTP 时间同步时也可能出现确认界面。详情请参阅「[关于 SSPH（SSP Helper）](../about/ssph.md#uacの確認画面が出るとき)」。

## 底部按钮

- **帮助**<br>
  打开首选项对话框中当前设置页面的帮助（即本页面）。<br>
  对话框右上角的「？」按钮也有相同作用。
- **关闭**<br>
  关闭首选项对话框。<br>
  对话框右上角的「×」按钮也有相同作用。
