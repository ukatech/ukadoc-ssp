# 设置：语音识别/语音合成

本页介绍右键菜单的“设置”子菜单中，通过“首选项”打开的对话框里的“语音识别/语音合成”页面。

本页用于设置 SSP 的语音识别和语音合成功能。

有关功能的使用方法，请分别参阅“[语音识别](../functions/speech-recognition.md)”和“[语音合成](../functions/speech-synthesis.md)”页面。

!!! tip "ヒント"

    如果电脑无法使用语音识别或语音合成，相应分组中的项目会显示为灰色，无法选择。<br>
    各项目中的“(System Default)”表示使用 Windows 设置中选定的项目。通常保持默认即可。

## 各项目说明

### 语音识别

选择“功能→语音识别”菜单，打开识别面板后即可使用。

!!! tip "ヒント"

    更改此栏中的设置后，会立即应用到已打开的识别面板。无需重新启动 SSP。

- **识别引擎**<br>
  更改语音识别引擎。选择“(System Default)”时，将使用语音识别控制面板中选定的引擎。<br>
  如果电脑上安装了多个识别引擎，请选择适合所说语言的引擎。
- **配置文件**<br>
  切换用于提高识别精度的学习信息。选择“(System Default)”时，将使用语音识别控制面板中选定的配置文件。<br>
  如果要为不同用户分别使用训练结果，请切换此项。
- **识别引擎设置、麦克风设置、训练**<br>
  是否可设置取决于识别引擎。通常这些项目均不可用。<br>
  如果可以使用，点击后会打开识别引擎提供的设置界面。在“麦克风设置”中可以调整麦克风音量，在“训练”中可以让识别引擎学习说话习惯，从而提高识别精度。
- **音频输入源**<br>
  切换作为音频输入源的麦克风接口、耳机麦克风等设备。选择“(System Default)”时，将使用语音识别控制面板中选定的输入源。<br>
  只有选定的输入源提供专用设置界面时，才能点击右侧的“设置...”按钮。

### 语音合成

启用“功能→语音合成”菜单后即可使用。

!!! tip "ヒント"

    更改此栏中的设置后，会从下一次朗读开始生效。无需重新启动 SSP。

- **`\0`（主角色）**<br>
  设置主角色（`\0`）的语音。可以选择语音、调整音高，也可以通过设置按钮进行详细设置。
- **`\1`（副角色）**<br>
  设置副角色（`\1`）的语音。可以选择语音（可与 `\0` 或 `\2` 相同）、调整音高，也可以通过设置按钮进行详细设置。
- **`\2`～（其他角色）**<br>
  设置 `\2` 及之后的附加角色的语音。可以选择语音（可与 `\0` 或 `\1` 相同）、调整音高，也可以通过设置按钮进行详细设置。
- **选择语音**<br>
  列表中会显示 Windows 自带的语音，以及用于调用外部语音合成的“LocalAPI-0〜9”和“CloudAPI-0〜9”选项。<br>
  选择“LocalAPI-”或“CloudAPI-”选项后，请点击右侧的“设置...”按钮，设置连接目标等信息，然后再使用。<br>
  只有 Windows 语音提供专用设置界面时，才能点击“设置...”按钮。
- **音高**<br>
  设置声音的高低。可在 -10〜10 的范围内选择（0 为基准）。数值越大，声音越高。<br>
  默认值为：`\0` 是 0，`\1` 是 +5（稍高），`\2`～ 是 -5（稍低）。
- **音频输出目标**<br>
  切换用于输出音频的扬声器、耳机接口等设备。可以通过设置按钮进行详细设置。
- **朗读速度**<br>
  调整语音合成的朗读速度。可以使用滑块在“慢”和“快”之间调节。请从标准位置开始调整。<br>
  此设置适用于所有角色。
- **音量**<br>
  调整语音合成的音量。可以使用滑块将音量设置为 0% 到 100%。默认值为 100%。<br>
  此设置适用于所有角色。
- **根据语音合成的播放进度等待脚本播放**<br>
  根据语音合成的朗读速度同步脚本的显示时机。<br>
  关闭时，对话框中的文字会按平常速度播放，语音则会跟随文字。开启后，播放人格会等待语音跟上，从而减少语音和文字之间的不同步（但如果合成耗时较长，人格的动作也会变慢）。默认情况下此项关闭。

## 语音合成详细设置对话框（右侧的设置按钮）

在“LocalAPI-”或“CloudAPI-”选项中点击“设置...”后会打开此对话框。请选择要使用的软件或服务类型，并填写必要项目。<br>
除使用云端语音合成时所需的 API 密钥外，其他项目均可留空。只填写必需的信息，其余项目请留空。所选类型不使用的项目会显示为灰色，无法输入。

- **类型**<br>
  选择要使用的语音合成软件或服务。在 LocalAPI 选项中可以选择本地软件，在 CloudAPI 选项中可以选择云端服务。
- **语音 ID／风格 ID／浏览...**<br>
  指定要使用的语音。点击“浏览...”后，会从连接目标的软件获取语音列表，方便你查看名称并进行选择。如果知道 ID，也可以直接输入。<br>
  对于 LocalAPI，如果连接目标的软件尚未启动，就无法显示列表（此时会响起蜂鸣声）。请先启动软件，再点击此按钮。<br>
  对于 Aivis Cloud API 和 OpenAI TTS，点击“浏览...”不会获取列表，而会在浏览器中打开列有语音列表的网页。
- **主机名／IP・端口号**<br>
  在 LocalAPI 中，指定运行连接目标软件的电脑。如果软件运行在同一台电脑上，留空即可。
- **API 密钥**<br>
  用于连接云端服务的密钥。请从服务的管理页面获取密钥并粘贴到此处。

### LocalAPI

- **VOICEVOX,VOICEVOX Nemo,SHAREVOX,AivisSpeech**<br>
  点击浏览按钮后，可以查看角色名称并选择语音 ID。如果知道 ID，也可以直接输入。<br>
  如果软件运行在同一台电脑上，主机名和端口号留空即可。
- **COEIROINK v2**<br>
  点击浏览按钮后，可以查看角色名称并选择语音 ID 和风格 ID。如果知道 ID，也可以直接输入。<br>
  风格 ID 请填写风格名称（例如“れいせい”）。如果知道 ID，也可以使用 ID。<br>
  如果软件运行在同一台电脑上，主机名和端口号留空即可。
- **Style-BERT-VITS2**<br>
  点击浏览按钮后，可以查看角色名称并选择语音 ID 和风格 ID。如果知道 ID，也可以直接输入。<br>
  风格 ID 请填写风格名称。如果知道 ID，也可以使用 ID。<br>
  如果软件运行在同一台电脑上，主机名和端口号留空即可。<br>
  请启动 Server.bat(`server_fastapi.py`)。
- **OpenAI TTS - Local（兼容本地 API）**<br>
  语音 ID 请填写 Text-to-speech AI 模型的名称，例如“irodori-tts”。<br>
  风格 ID 请按照兼容服务器的规范填写。例如，对于 Irodori-TTS-Server，请填写放入 voices 文件夹中的参考音频 wav 文件名（不含扩展名）。<br>
  如果软件运行在同一台电脑上，主机名留空即可。端口号需要根据具体服务进行设置。例如，Irodori-TTS-Server 使用 8088。

### CloudAPI

- **Aivis Cloud API**<br>
  语音 ID 请复制并填写“模型 UUID”。注意！这不是说话人 UUID。<br>
  风格 ID 可在语音的详细信息页面中找到。<br>
  建议将音高设为 0。其他数值似乎会降低合成速度。<br>
  可以从[此处的控制面板](https://hub.aivis-project.com/cloud-api/dashboard)获取 API 密钥，请将密钥粘贴到密钥栏中。
- **OpenAI TTS - Cloud（云端 API 或兼容服务）**<br>
  语音 ID 请填写 Text-to-speech AI 模型的名称，例如“gpt-4o-mini-tts”或“tts-1”。<br>
  风格 ID 请填写[此处文档的“Voice options”部分](https://developers.openai.com/api/docs/guides/text-to-speech#voice-options)列出的名称。例如：“marin”“cedar”<br>
  可以从[此处的控制面板](https://platform.openai.com/account/api-keys)获取 API 密钥，请将密钥粘贴到密钥栏中。<br>
  使用兼容服务时，请设置主机名。使用 OpenAI 的 Text-to-speech 时，留空即可。

## 底部按钮

- **帮助**<br>
  打开首选项对话框中当前设置页面的帮助（也就是本页）。<br>
  对话框右上角的“？”标记也有相同作用。
- **关闭**<br>
  关闭首选项对话框。<br>
  对话框右上角的“×”标记也有相同作用。
