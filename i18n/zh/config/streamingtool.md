# 设置：直播

本页介绍通过右键菜单的“设置”子菜单中的“首选项”打开的对话框里的“直播”页面。

这里可以设置将人格用作视频直播等辅助工具时的相关选项。使用直播软件进行捕获或使用音频联动功能时，请进行相应设置。

## 各项说明

- **让直播工具更容易捕获角色**<br>
  调整人格角色窗口的状态，使其更容易被 OBS 等直播工具捕获。<br>
  通过更改窗口的显示方式，让直播软件的窗口捕获功能更容易识别。
- **让直播工具更容易捕获对话框**<br>
  调整人格的对话框（对话气泡）的状态，使其更容易被直播工具捕获。<br>
  如果想让对话框也显示在直播画面中，请启用此项。
- **检测到音频时自动做出口型**<br>
  检测来自麦克风的音频输入，并让人格自动做出口型动作。<br>
  直播时，角色会随着音频动嘴，从而实现更自然的表现。
- **音频输入选择**<br>
  选择口型功能使用的音频输入设备（麦克风）。<br>
  请从系统可用的音频输入设备列表中选择要使用的麦克风。
- **音频级别**<br>
  调整口型功能的灵敏度。<br>
  请一边查看音频级别条显示的当前输入音量，一边调整到合适的灵敏度。<br>
  灵敏度过高时，即使环境音也会触发口型；灵敏度过低时，则无法对声音做出响应。
- **在单个窗口中显示人格**<br>
  不将人格直接放在桌面上，而是将其显示在一个窗口中（窗口模式）。<br>
  这样可以捕获整个窗口，也不会影响整个桌面。<br>
  ⇒详情请参阅“[窗口模式](../functions/windowmode.md)”页面。
- **所有人格放在一个窗口中／每个人格单独一个窗口**<br>
  选择窗口的布局方式。<br>
  “所有人格放在一个窗口中”会将所有正在运行的人格排列在一个窗口中（默认值）。<br>
  “每个人格单独一个窗口”会为每个人格分别准备一个窗口。

!!! tip "ヒント"

    也可以通过[右键菜单](../howto/rclick.md)中的“设置”或窗口自身的“操作”菜单切换窗口模式。<br>
    加载人格时无法切换，勾选状态会恢复原样。

## 使用注意事项

!!! tip "ヒント"

    启用面向直播工具的设置后，窗口的行为可能会与平时不同。<br>
    不进行直播时，建议关闭此设置。

!!! tip "ヒント"

    使用音频检测功能时，请注意麦克风可能与其他应用程序发生冲突。<br>
    与某些直播软件或音频软件同时使用时，访问音频设备可能会出现问题。

!!! tip "ヒント"

    OBS Studio 请在“窗口捕获”中选择“捕获方法：Windows 10（1903 及更高版本）”。<br>
    使用其他捕获方法时可能无法正确捕获。<br>
    可以直接捕获单个窗口，因此不需要特殊插件。

## 底部按钮

- **帮助**<br>
  打开首选项对话框中当前设置页面的帮助（也就是本页）。<br>
  对话框右上角的“？”标记也有相同作用。
- **关闭**<br>
  关闭首选项对话框。<br>
  对话框右上角的“×”标记也有相同作用。
