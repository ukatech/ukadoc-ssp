# 设置：显示

本页介绍通过右键菜单的“设置”子菜单中的“首选项”打开的对话框里，“显示”页面的相关内容。

本页用于设置画面显示相关选项。

## 各项说明

- **不更改光标（从下次载入人格时生效）**<br>
  开启后，即使对话框带有鼠标光标，也不会更改光标。<br>
  如果不希望对话框更改鼠标光标，请开启此选项。
- **桌面底部偏移（通常设为0即可）**<br>
  设置与桌面底部相差多少像素。<br>
  例如，开启“自动隐藏任务栏”时，可以通过此设置避免窗口被任务栏遮住。
- **使菜单宽度与背景图片一致**<br>
  通常，菜单宽度与菜单项的宽度一致；开启此选项后，菜单宽度会与人格附带的菜单图片一致。<br>
  这样就能显示完整的人格菜单图片。
- **选择菜单项时显示预览图片**<br>
  在右键菜单中选择切换人格、呼出人格、切换外壳、切换对话框等菜单项时，如果支持预览图片，就会显示预览图片（thumbnail.png）。<br>
  处于\[—\]状态时仅显示菜单，处于\[✓\]状态时，还会在资源管理器中鼠标悬停时显示预览图片。
- **设置菜单的纵向留白（标准值为2）**<br>
  设置右键菜单各行之间的留白。<br>
  Windows 菜单的间距为2；如有需要，可进行调整以便于查看。
- **将部分菜单分层显示**<br>
  如果在[设置：文件夹](folder.md)中设置了读取多个文件夹，开启此选项后，菜单会按文件夹分组。<br>
  此设置适用于人格、对话框等所有可设置文件夹的菜单。<br>
  如果安装了许多人格，并希望整理菜单显示内容，可以使用此选项。
- **人格和对话框菜单的最大字符数（5-255）**<br>
  如果某些人格名称过长，可能会导致菜单占满整个屏幕；此选项用于避免这种情况。名称超过此处设置的字符数时，会在末尾加上“...”，并以省略形式显示。<br>
  如果屏幕较窄，可以将字符数设得小一些。
- **“最近使用”菜单的最大记录数（2-255）**<br>
  设置“最近使用”中保留的记录数。早于此数量的已启动/使用项目将被移除。
- **在 Flip3D 中也显示（Vista及以上版本）**<br>
  使用 Flip3D 切换窗口时，也会继续显示角色和对话框。如果希望随时显示角色，请使用此选项。
- **在任务栏中显示角色窗口**<br>
  通常，显示角色的窗口不会出现在任务栏中；但在 Windows 7及以上版本中，如果想使用跳转列表或预览，有时需要将其显示出来。<br>
  开启此选项后，即可使用上述功能。
- **启动全屏应用时最小化**<br>
  启动游戏等全屏应用程序时，自动最小化显示人格。
- **在所有虚拟桌面上显示角色窗口（Win10及以上版本）**<br>
  无论 Windows 10及以上版本新增的虚拟桌面功能切换到哪个桌面，角色窗口都会显示在所有虚拟桌面上。
- **点击角色时也将其他窗口置于最前**<br>
  点击角色时，资源管理器、日志窗口等不属于特定角色显示的窗口也会一同置于最前。<br>
  由于窗口容易被其他窗口遮挡而找不到，通常请保持此选项开启。
- **高 DPI 支持\[需要重新启动SSP\]**<br>
  改善高 DPI 环境下 SSP 的显示效果。更改此设置后，需要重新启动 SSP。
- **自动将屏幕外的窗口移回屏幕内**<br>
  当显示器分辨率发生变化、显示器电源关闭，或当前显示器配置与上次启动时不同时，会自动将外壳移至可用显示器的范围内。<br>
  关闭此设置可能会解决多显示器环境中的一些问题，但窗口移到屏幕外时，需要手动重置位置。

### 半透明窗口

此设置用于启用一种名为“Layered Window”的功能，可实现从 Windows 2000起提供的半透明窗口效果。<br>
如果可以使用，默认情况下会启用此功能。

- **使用交叉淡化**<br>
  角色表情切换，或对话框等的显示状态切换时，会使用逐渐切换的淡入淡出效果。
- **拖动时提高透明度**<br>
  拖动角色窗口时，会降低窗口的不透明度，让下方的内容更容易看见。
- **（本体/对话框/日历的透明度设置）**<br>
  移动滑块以调节各窗口的透明度。

## 底部按钮

- **帮助**<br>
  打开首选项对话框中当前设置页面的帮助（也就是本页）。<br>
  对话框右上角的“？”标记也有相同作用。
- **关闭**<br>
  关闭首选项对话框。<br>
  对话框右上角的“×”标记也有相同作用。
