# 基本用法：RSS/在线新闻

这项功能可以让人格读出互联网上网页的摘要（在线新闻）。

安装 SSP 时已预装了一些内容，也可以添加更多。<br>
其中有些内容会播报知名网站或个人主页的更新，欢迎试用。

此外，SSP 也支持朗读 RSS。<br>
对于支持 RSS 的网站，建议使用 RSS。

## 查看在线新闻/RSS

首次启动时，自动巡查功能处于关闭状态。<br>
如需更改自动获取间隔或启用自动巡查，请在首选项的「[连接（2）](../config/conn2.md)」中进行设置。

无论哪种情况，都可以指定特定的在线新闻/RSS并获取内容。<br>
请在[右键菜单](rclick.md)的「RSS/在线新闻」中选择。

## 添加在线新闻传感器

在线新闻传感器也和「外壳」或「人格」一样，会以文件形式发布。<br>
请将下载的文件直接**拖放**到人格上。只要文件内容没有损坏，就可以立即使用。

## 添加 RSS

SSP 支持名为「RSS」和「Atom」的网站或博客更新通知规范（Feed）。<br>
支持的规范如下：

- RSS 0.9x / 2.0
- RSS 1.0
- Atom 0.3 / 1.0

可以通过以下几种方式将 RSS 添加到 SSP：

- 将各网站上标有 RSS 或 Atom 的图标拖放到角色上
- 将支持 RSS 的网站 URL 从地址栏或链接直接拖放到角色上（自动识别＝RSS Auto Discovery）
- 将上述任一 URL 粘贴到可从右键菜单「功能」中打开的「地址栏」等位置

具体效果取决于各网站的设置，但以上几种方法基本都能得到相同的结果。
