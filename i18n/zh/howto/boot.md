# 基本用法：启动

## 启动基础

解压后的文件夹中有一个名为「SSP.EXE」的程序。<br>
运行它即可启动。<br>
启动方法就这么简单。

当「人格」和「对话框」显示在桌面上时，就表示启动完成。<br>
刚安装好时的人格是「Emily/Phase4.5」。请好好疼爱它哦。

### 创建快捷方式

每次都打开解压文件夹再双击，操作起来比较繁琐，所以最好创建一个快捷方式。

如果你的 Windows 默认带有快速启动功能，可以创建一个新的工具栏，并将快捷方式放在那里。<br>
（有关创建快捷方式或工具栏的方法，请参阅 Windows 帮助或手册。）

### 随电脑启动

添加各种外部数据后，你一定会想让它一直运行（断言）。<br>
这种情况下，可以设置为随电脑启动。<br>
如果有这类外部工具，设置起来会很轻松；没有也没关系。<br>
请按照以下步骤创建快捷方式。

- 打开资源管理器窗口，点击地址栏
- 输入 shell:statup 并按 Enter
- 在显示的资源管理器窗口中创建快捷方式

## 启动相关设置

你可以在首选项中选择启动 SSP 时要启动的人格：

- 随机启动
- 启动上次退出时使用的人格
- 启动后立即打开资源管理器，选择人格后启动

⇒　详情请参阅[「人格（1）」](../config/ghost.md)页面。
