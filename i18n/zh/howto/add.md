# 基本用法：添加内容

## 来试着添加各种内容吧

![原始人格菜单](../assets/screenshots/howto/add/2.png)<br>
如图所示，刚安装好的 SSP 中，通常只有「Emily/Phase4.5」这一个人格（角色数据）。<br>
此外，Emily/Phase4.5 还包含一套 master 外壳（立绘）。<br>
另外，对话框（气泡）有「SSP默认+」和「balloon for Emily/P4」两种。<br>
这些人格、对话框、外壳等内容都可以添加。

## 添加基础

![拖放安装包](../assets/screenshots/howto/add/0.png)![安装时的反应示例](../assets/screenshots/howto/add/1.png)<br>
要添加各种内容，请将下载的（或随附的）安装包文件**拖放**到正在运行的 SSP 上。<br>
在大多数情况下，无论当前显示的是哪个人格，都可以安装。<br>
偶尔会有专供特定人格使用的附加内容，这种情况下，拖放时人格应该会告诉你……吧。

添加后，请通过相应内容的切换菜单确认是否已成功安装。<br>
![安装后的人格菜单](../assets/screenshots/howto/add/3.png)

### 关于安装包文件

通常，各种内容的安装包会以扩展名为 .nar 的文件形式发布和分发，这类文件一般称为 **nar 文件**。<br>
如果在首选项的「[常规](../config/ippan.md)」中勾选了「将文件与 SSP 关联」，也可以双击 nar 文件进行安装。

此外，nar 文件实际上只是扩展名改成了 .nar 的 zip 格式压缩文件。<br>
可以通过修改文件名等方式将扩展名改回 zip，然后使用常见的解压软件打开文件。<br>
将打开后的文件放入各种内容对应的文件夹（参见首选项的「[文件夹](../config/folder.md)」），即可手动安装。<br>
不过，如果在 SSP 运行时进行此类操作，要等到重启后才会生效。

另外，即使拖放的是 zip 或 lzh 格式的文件（扩展名不是 nar），只要其中包含相关内容，SSP 也可以正常安装。

## 各类内容的补充说明

### 添加人格

许多人格都在互联网上发布。<br>
大多数都登记在本帮助的[链接集](../about/links.md)中提到的「GHOST TOWN」等搜索网站上，不妨到那里寻找你可能喜欢的人格。

添加后，请通过右键菜单中的「切换人格」切换人格。<br>
如果屏幕分辨率足够，或者使用多显示器，也可以通过「呼叫人格」让多个人格同时显示。<br>
有时，同时显示的多个人格之间还会进行对话……？

### 添加对话框

和人格一样，互联网上也有许多对话框供人下载。<br>
寻找对话框时，同样可以使用[链接集](../about/links.md)中提到的「BALLOON TOWN」等搜索网站。

安装后，在右键菜单中更换对话框，就能改变人格说话时显示的气泡。<br>
对话框会按人格分别记忆，无法一次性更换多个人格的对话框。

### 添加外壳

一个人格可以拥有多个「外壳」。<br>
切换外壳可以产生「换装」或「变身」的效果。

许多外壳都是为特定人格制作的。<br>
如果它不是为拖放目标人格制作的，就会显示某种提示信息，无法安装。<br>
虽然偶尔也有不指定人格的外壳，但即使要让多个人格使用此类外壳，也需要分别为每个人格安装。

安装后，请通过右键菜单切换外壳。<br>
切换后，除了外观会变化之外，鼠标操作的响应区域等也可能存在不易察觉的差异。

此外，如前所述，外壳往往是为特定人格制作的，因此不太容易像人格或对话框那样建立便于搜索的网站。<br>
不过，大多数情况下，人格的发布页面都会汇总相关信息。<br>
下载人格时，不妨顺便确认一下是否有可添加的外壳。

## 添加其他内容

此外，还有一些其他的附加内容。

例如，用于读取特定网站更新信息的[在线新闻传感器](headline.md)，以及为 SSP 提供附加功能的[插件](plugin.md)等。<br>
此外，有时也会为特定人格提供称为「补充包」的专用附加文件。<br>
内容各不相同，例如非人格原有设定的 if 类对话或功能等，希望由使用者自行决定是否添加的内容，有时会以这种形式发布。

无论是哪种内容，安装方法都相同，可以通过拖放到人格上等方式安装。
