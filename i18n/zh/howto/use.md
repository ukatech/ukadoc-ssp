# 基本用法：与人格互动

人格会做什么、能做什么，基本上完全取决于人格本身。<br>
不过，刚开始时可能不知道该做些什么，所以这里介绍几种许多人格都有的功能。

## 说话

启动后放着不管，大多数人格都会自己说话。<br>
人格的基本形式是由「本体」和「搭档」组成的二人组合，所以说成是在演双人相声或许更准确。

!!! tip "ヒント"

    也有１人或３人以上的人格。例如人格「Emily/Phase4.5」中，３个角色会相互对话。<br>
    ![Emily/Phase4.5的3个角色](../assets/screenshots/howto/use/0.png){ width="400" }

## 用光标触碰

光是看着也很有趣，不过，使用光标抚摸、戳、拉、拍角色，应该会得到各种回应。<br>
试着做各种操作，看看会有什么反应吧。

不过，可以触碰的位置和角色的反应，完全因人格而异，有时也会因外壳而异。<br>
还有一些操作无法在这里一一介绍。这些不同之处正是人格丰富「个性」的体现。

!!! tip "ヒント"

    可以触碰的位置可能会让光标形状发生变化。<br>
    ![可触碰的位置和光标](../assets/screenshots/howto/use/1.png)

### 移动光标

在角色的特定部位上方**上下左右移动光标**，就能触发触碰、抚摸等动作。<br>
例如，许多人格在头部附近移动光标时，就能抚摸角色。<br>
（也有反应比较迟钝的人格，不过这也是个性的一部分。）<br>
![移动光标进行抚摸](../assets/screenshots/howto/use/4.png)

### 拖动

可以通过**拖动**移动角色和对话框（包括搭档）。<br>
也有角色会因为和搭档重叠而抱怨……<br>
![通过拖动移动角色](../assets/screenshots/howto/use/2.png)

移动时，如果角色靠近显示器边缘或彼此靠近，就会触发吸附（自动调整位置，让它们整齐排列）。按住 Ctrl 键即可解除吸附，不需要时可以试着按一下。

### 滚轮

**滚动鼠标滚轮**可能会触发拉扯、翻动等动作。<br>
不过，这项功能出现得比较晚，所以不同人格或不同位置对滚轮操作的解释方式有很多种，例如切换说话频率。<br>
![滚轮带来的恶作剧](../assets/screenshots/howto/use/3.png)

### 双击

**双击**会触发戳、拍、抓等动作。<br>
根据触碰的位置，角色可能会觉得疼。<br>
![粗暴行为可不好](../assets/screenshots/howto/use/8.png)

此外，大多数人格在没有特别反应的位置（光标不会变化的位置）被**双击**时，会在对话框中显示自己的菜单。<br>
接下来会介绍这个菜单。

## 菜单

![人格菜单](../assets/screenshots/howto/use/5.png){ width="400" }<br>
大多数人格在**双击**没有特别反应的位置时，会打开菜单。<br>
通过这个菜单，可以使用或设置人格独有的功能。

!!! tip "ヒント"

    即使是相同的功能，不同人格的菜单项名称也大多不一样。

### 听它说话

让人格说点什么。<br>
在人格「Emily/Phase4.5」中，这个菜单项叫作「说点什么」。

### 和它说话

会打开一个输入单词的文本框，可以用简单的词语和人格交谈。<br>
它可能听不懂太复杂的内容，不过应该会回应简单的问候。<br>
人格「Emily/Phase4.5」没有这个菜单项。<br>
![对话输入框](../assets/screenshots/howto/use/6.png)

### 说话频率

设置人格说话的频率。<br>
在人格「Emily/Phase4.5」中，按下「拜托Emily」后会显示这个菜单项。

## 按键输入

让人格获得焦点（点击一次，使其显示在最前面）后，按下特定按键，有时会得到回应。<br>
按键通常用于执行类似特定功能快捷键的操作。

例如在人格「Emily/Phase4.5」中，按下 t 键后会立即开始说话。<br>
这可能比从菜单中选择「说点什么」更方便。

!!! tip "ヒント"

    很多情况下，输入模式不是半角时，按键输入不会被接受。<br>
    如果无法正常使用，请确认是否处于全角输入模式。

## 人格特有的操作

刚开始时，可以试着体验前面介绍的各种操作。

不过，正如本页开头所说，每个人格能做的事情都不一样。<br>
有的人格无法执行这里介绍的操作，也有很多人格能做更多事情。<br>
人格特有的操作也许会写在人格的 readme 中，不妨读一读。

!!! tip "ヒント"

    可以右键点击当前正在显示的人格，选择弹出菜单中从下往上数第５个「信息」菜单项，然后在打开的子菜单中点击从上往下数第２个菜单项，打开该人格的 readme。<br>
    另外，菜单项的名称可能因人格而异（详情请参阅「[右键菜单](rclick.md)」页面）。<br>
    ![人格的readme](../assets/screenshots/howto/use/7.png)
