# 基本用法：RSS／線上新聞

這項功能可以讓人格朗讀網路上網站的摘要（線上新聞）。

安裝 SSP 時就已經內含一些項目，也可以再新增更多內容。<br>
其中有些項目會朗讀知名網站或個人網站的更新資訊，請務必試用看看。

此外，SSP 也支援朗讀 RSS。<br>
若網站支援 RSS，建議使用 RSS。

## 確認線上新聞／RSS

初次啟動時，自動巡覽功能是關閉的。<br>
若要變更自動取得的間隔，或啟用自動巡覽，請在偏好設定的「[連線（2）](../config/conn2.md)」中設定。

無論是哪種情況，都可以指定特定的線上新聞／RSS 進行取得。<br>
請從[右鍵選單](rclick.md)的「RSS／線上新聞」中選擇。

## 新增線上新聞感應器

線上新聞感應器的散布方式也和「外殼」或「人格」相同。<br>
將下載的檔案直接**拖放**到人格上即可。只要檔案內容沒有損壞，就能立即使用。

## 新增 RSS

SSP 支援名為「RSS」和「Atom」的網站或部落格更新通知規格（Feed）。<br>
支援的規格如下。

- RSS 0.9x / 2.0
- RSS 1.0
- Atom 0.3 / 1.0

可以選擇以下幾種方式，將內容新增到 SSP。

- 將各網站標示為 RSS 或 Atom 的圖示拖放到角色上
- 將支援 RSS 網站的網址，從網址列或連結直接拖放到角色上（自動偵測＝RSS Auto Discovery）
- 將上述任一網址貼到可從右鍵選單「功能」開啟的「網址列」中，或以其他方式輸入

依各網站的設定而定，不過以上任何一種方式大致上都會得到相同結果。
