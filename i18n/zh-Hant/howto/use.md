# 基本用法：和人格一起玩

人格會做什麼、能做什麼，基本上完全取決於人格本身。<br>
話雖如此，剛開始可能會不知道該做些什麼，所以這裡要介紹幾種多數人格都具備的功能。

## 說話

啟動後放著不管，大多數人格都會自己說話。<br>
人格的基本形式是「本體」和「搭檔」兩人一組，所以說成是在演漫才或許更貼切。

!!! tip "ヒント"

    也有人格只有一個角色，或有三個以上的角色。例如人格「Emily/Phase4.5」會由三個角色輪流對話。<br>
    ![Emily/Phase4.5 的 3 個角色](../assets/screenshots/howto/use/0.png){ width="400" }

## 用游標互動

光是欣賞也很有趣，不過用游標撫摸、戳、拉扯或敲打，應該就會得到各種反應。<br>
試著看看會有什麼反應吧。

不過，可以互動的位置和會出現的反應，還是會因人格而異，有時也會因外殼而異。<br>
還有一些操作無法在這裡一一介紹，這些正是形塑人格多樣「個性」的要素。

!!! tip "ヒント"

    可以互動的位置，游標形狀可能會有所變化。<br>
    ![可互動的位置和游標](../assets/screenshots/howto/use/1.png)

### 移動游標

在角色的特定部位上，**將游標往上下左右移動**，就能觸發觸碰、撫摸等動作。<br>
例如，許多人格在頭部附近移動游標，就能撫摸角色。<br>
（也有人格的反應比較遲鈍，不過那就是個性）<br>
![移動游標撫摸角色](../assets/screenshots/howto/use/4.png)

### 拖曳

可以用**拖曳**移動角色和對話方塊（搭檔也可以）。<br>
有些角色會在和搭檔重疊時抱怨……<br>
![拖曳移動角色](../assets/screenshots/howto/use/2.png)

移動時，如果靠近螢幕邊緣或角色之間，就會自動吸附（自動調整位置，讓它們整齊排列）。按住 Ctrl 鍵即可停用；不需要時可以試著按住它。

### 滾輪

**轉動滑鼠滾輪**，可能會觸發拉扯、翻頁等動作。<br>
不過，這項功能出現的時間相對較晚，因此不同人格或不同部位對它的解讀差異很大，例如用來切換說話頻率。<br>
![用滾輪惡作劇](../assets/screenshots/howto/use/3.png)

### 雙擊

**雙擊**可能會觸發戳、敲打或抓取等動作。<br>
在某些部位，角色甚至可能會覺得痛。<br>
![不可以這麼粗暴](../assets/screenshots/howto/use/8.png)

此外，大多數人格在沒有特別反應的位置（游標不會變化的位置）被**雙擊**時，會在對話方塊內顯示自己的選單。<br>
接下來會說明這個選單。

## 選單

![人格選單](../assets/screenshots/howto/use/5.png){ width="400" }<br>
大多數人格在沒有特別反應的位置**雙擊**時，都會開啟選單。<br>
可以透過這個選單使用或設定人格特有的功能。

!!! tip "ヒント"

    即使是相同功能，各人格的項目名稱也幾乎都不一樣

### 聽人格說話

讓人格說些話。<br>
在人格「Emily/Phase4.5」中，這個項目叫做「說點什麼吧」。

### 和人格交談

會開啟輸入單字的方框，可以輸入簡單的單字和人格交談。<br>
人格可能聽不懂太複雜的內容，但應該會回應簡單的問候。<br>
人格「Emily/Phase4.5」沒有這個項目。<br>
![交談輸入框](../assets/screenshots/howto/use/6.png)

### 說話頻率

設定人格說話的頻率。<br>
在人格「Emily/Phase4.5」中，按下「拜託 Emily」後才會出現這個項目。

## 按鍵輸入

將焦點放在人格上（點一下，讓人格顯示在最上層）後，按下特定按鍵，有時就會觸發反應。<br>
這通常會作為特定功能的快捷鍵。

例如在人格「Emily/Phase4.5」中，按下 t 鍵就會立刻開始說話。<br>
這或許比從選單中選擇「說點什麼吧」更簡單。

!!! tip "ヒント"

    很多時候，輸入法必須處於半形模式，才能輸入按鍵。<br>
    如果無法順利操作，請確認輸入法是否處於全形模式。

## 人格特有的操作

剛開始時，請先試試看前面介紹的各種操作。

不過，就像這個頁面一開始提到的，各人格能做的事都不一樣。<br>
有些人格無法進行這裡介紹的操作，也有很多人格能做更多不同的事。<br>
人格特有的操作可能會寫在人格的 readme 中，不妨讀讀看。

!!! tip "ヒント"

    要開啟目前正在桌面上的人格的 readme，請在右鍵選單中選擇由下往上第五個（資訊）項目，開啟子選單後，再點選由上往下第二個項目。<br>
    不過，選單項目的名稱可能因人格而異（詳細說明請參閱「[右鍵選單](rclick.md)」頁面）。<br>
    ![人格的 readme](../assets/screenshots/howto/use/7.png)
