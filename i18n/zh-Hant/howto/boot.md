# 基本用法：啟動

## 啟動基本操作

解壓縮目的地資料夾中有一個名為「SSP.EXE」的程式。<br>
執行這個程式即可啟動。<br>
啟動方式就只有這樣，簡單吧。

當「人格」和「對話方塊」顯示在桌面上時，就表示啟動完成。<br>
剛安裝完的人格是「Emily/Phase4.5」。請好好疼愛她。

### 建立捷徑

每次都開啟解壓縮資料夾並按兩下程式……這樣做很沒效率，因此建議先建立捷徑。

如果你的 Windows 預設提供快速啟動列功能，可以建立新的工具列，並將捷徑放在其中。<br>
（關於建立捷徑或工具列的方法，請參閱 Windows 說明或手冊）

### 設定為與電腦同時啟動

新增各種外部資料後，你一定會想讓它一直執行（斷言）。<br>
遇到這種情況，就讓它在電腦啟動時一併執行吧。<br>
如果有這類外部工具，設定起來會很方便；即使沒有，也能做到。<br>
請依照以下步驟建立捷徑。

- 開啟資源管理器視窗，並按一下網址列
- 輸入 shell:statup，然後按 Enter
- 在顯示的資源管理器視窗中建立捷徑

## 啟動相關設定

在偏好設定中，可以從以下選項選擇啟動 SSP 時要使用哪個人格。

- 隨機啟動
- 使用上次結束時的人格啟動
- 啟動後立即開啟資源管理器，選擇人格後再啟動

⇒　詳細資訊請參閱[「人格（1）」](../config/ghost.md)頁面。
