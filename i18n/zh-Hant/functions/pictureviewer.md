# 圖片檢視器

這是一個檢視器視窗，可顯示圖片檔案，進行放大縮小、旋轉、裁切等簡單操作，也能轉換格式後儲存或複製。<br>
除了能即時檢視 SSP 支援的多種圖片格式，也能以分頁並排開啟多張圖片，方便切換瀏覽。

無論是外殼或對話方塊的素材圖片，還是拍攝的照片，都很適合用來檢視或轉換這類小型圖片。

## 支援的圖片格式

以下列出主要支援的圖片格式。<br>
「支援狀況」中的**SSP 全域**表示 SSP 本體預設可讀取的格式（也可用於外殼或對話方塊素材等），**僅限檢視器**表示只能透過此圖片檢視器顯示的格式（透過作業系統的 WIC 編解碼器）。

| 格式 | 副檔名 | 支援狀況 | 備註 |
|---|---|---|---|
| PNG / APNG | .png / .apng | SSP 全域 | 支援 Alpha（透明度）。可搭配同名的 .pna 檔案使用外部 Alpha。也支援 APNG（動畫 PNG）。 |
| WebP | .webp | SSP 全域 | 支援動畫與透明度。 |
| GIF | .gif | SSP 全域 | 支援動畫與透明度。 |
| MAG | .mag | SSP 全域 | 復古格式（MAKICHAN GRAPHICS，PC-9801 時代）。 |
| Pi | .pi | SSP 全域 | 復古格式（PC-9801 時代的 Pi 格式）。 |
| JPEG | .jpg / .jpeg | SSP 全域 | 會自動套用 EXIF Orientation（拍攝時的方向資訊）。 |
| BMP | .bmp | SSP 全域 | Windows 點陣圖。 |
| TIFF | .tif / .tiff | SSP 全域 | 支援多頁檔案（可切換至上一頁／下一頁）。 |
| X BitMap / X PixMap | .xbm / .xpm | SSP 全域 | X Window 系列的文字格式圖片。 |
| TGA | .tga | SSP 全域 | Truevision Targa。支援透明度。 |
| Netpbm（Portable anymap） | .pbm / .pgm / .ppm / .pam / .pnm / .pfm | SSP 全域 | Portable Bitmap／Graymap／Pixmap 系列格式。.pfm 是浮點數（HDR）格式。 |
| PCX | .pcx | SSP 全域 | ZSoft Paintbrush。 |
| QOI | .qoi | SSP 全域 | Quite OK Image Format。 |
| ICO | .ico | SSP 全域 | Windows 圖示格式。 |
| DLL/EXE | .dll / .exe | SSP 全域 | 列出 DLL 或 EXE 檔案中包含的圖示，並逐頁顯示。 |
| PSD | .psd | SSP 全域 | Adobe Photoshop。除了合併後的圖片，也能個別讀取各圖層。 |
| PSP | .psp / .pspimage | SSP 全域 | Paint Shop Pro。支援 version4.0 以上版本。除了合併後的圖片，也能個別讀取各圖層。 |
| OpenRaster | .ora | SSP 全域 | 除了合併後的圖片，也能個別讀取各圖層。 |
| Krita | .kra | SSP 全域 | 除了合併後的圖片，也能個別讀取各圖層。 |
| CLIP STUDIO | .clip | SSP 全域 | 除了合併後的圖片，也能個別讀取各圖層。 |
| GIMP | .xcf | SSP 全域 | 可個別讀取各圖層。不支援合併後的圖片（檢視器會合成並顯示各圖層，因此不受影響）。 |
| HEIF / HEIC | .heif / .heic | 僅限檢視器 | 需要作業系統的「[HEIF 影像延伸功能](https://apps.microsoft.com/detail/9pmmsr1cgpwg)」。 |
| AVIF | .avif | 僅限檢視器 | 需要作業系統的「[AV1 影片延伸功能](https://apps.microsoft.com/detail/9mvzqvxjbq9v)」。 |
| JPEG XR | .jxr / .wdp / .hdp | 僅限檢視器 | HD Photo。 |
| DDS | .dds | 僅限檢視器 | DirectDraw Surface。只顯示第一個影格。 |
| 相機 RAW | .cr2 / .nef / .arw 等 | 僅限檢視器 | 各廠牌的 RAW 格式。需使用作業系統的「[RAW 影像延伸功能](https://apps.microsoft.com/detail/9nctdw2w1bh8)」。 |

!!! tip "ヒント"

    「僅限檢視器」的格式需使用安裝在作業系統中的編解碼器（影像延伸功能）。上表列出常見範例，實際上可能因環境而無法讀取。<br>
    此外，透過「僅限檢視器」方式讀取的格式不支援動畫或多頁檔案，一律只顯示第一個畫面。

## 啟動方式

可以透過以下任一方式開啟圖片檢視器。

- **[右鍵選單](../howto/rclick.md) →「功能」→「圖片檢視器」**<br>
  會在尚未載入圖片的空白狀態下啟動檢視器。<br>
  ⇒也請參閱「[功能](index.md)」頁面。
- **將圖片檔案拖放到人格上**<br>
  將圖片檔案放到人格上時，如果人格沒有對該檔案做出反應，就會自動以此檢視器開啟。<br>
  如果檔案無法作為圖片讀取，則不會啟動檢視器。

啟動後，可以在檢視器中使用「開啟圖片」、從剪貼簿貼上，或拖放到檢視器內，將更多圖片新增為分頁。

## 畫面配置

- **功能表列**<br>
  可透過「檔案」、「編輯」、「檢視」各功能表執行所有操作（詳情如下）。
- **工具列**<br>
  以按鈕排列常用操作。每個按鈕都對應一個功能表項目，將滑鼠游標移到按鈕上時，會顯示功能名稱（工具提示）。<br>
  裁切和將左上角的顏色設為透明，在啟用時會顯示為按下的按鈕。背景切換按鈕每按一次，圖示就會變為目前的背景（棋盤格／白色／黑色）。
- **分頁**<br>
  每張已開啟的圖片都會顯示為一個分頁。點選分頁即可切換顯示的圖片。
- **圖片顯示區域**<br>
  顯示圖片的區域。如果圖片比區域大，就會顯示捲軸。
- **狀態列**<br>
  視窗下方會顯示目前圖片的「尺寸（寬×高）」、「縮放比例」、「旋轉角度（水平翻轉時也會一併顯示 `<| />`）」和「格式」。<br>
  如果是 WebP 這類副檔名相同、但壓縮方式不同的格式，格式後方會一併顯示 `(lossless)`（無損）或 `(lossy)`（有損）。如果動畫的各影格使用不同方式，則會顯示 `(mixed)`。<br>
  裁切時，左側會顯示所選範圍的座標。

## 上方選單

### 檔案

- **開啟圖片...\[Ctrl+O\]**<br>
  開啟檔案選擇對話方塊，並在新分頁中開啟選取的圖片。
- **重新載入\[Ctrl+R / F5\]**<br>
  從磁碟重新載入目前顯示的圖片。<br>
  從檔案開啟的圖片會自動偵測外部更新並重新載入；若要手動重新載入，則可使用此功能。
- **另存新檔...\[Ctrl+S\]**<br>
  儲存目前顯示的圖片。可選擇 PNG／BMP／JPEG／WebP（無損・有損）格式。<br>
  若已旋轉、水平翻轉、裁切或調整大小，則會依目前顯示的狀態（也就是畫面上看到的內容）儲存。

### 編輯

- **複製\[Ctrl+C\]**<br>
  將目前顯示的圖片複製到剪貼簿，並保留透明度。<br>
  若正在旋轉、翻轉或裁切，則會依目前顯示的狀態複製。
- **貼上\[Ctrl+V\]**<br>
  將剪貼簿中的圖片匯入為新分頁。
- **調整大小...**<br>
  在對話方塊中指定寬度和高度，以放大或縮小圖片。<br>
  原始圖片會保留；指定與原始圖片相同的尺寸，即可還原原始圖片（非破壞性編輯）。
- **裁切**<br>
  切換裁切模式的開啟／關閉。<br>
  開啟後，可用滑鼠在圖片上拖曳，指定要裁切的範圍。儲存或複製時，只會處理該範圍。

### 檢視

- **實際大小\[Ctrl+0\]**<br>
  將縮放比例還原為100%（原始大小）。
- **放大\[Ctrl++\] / 縮小\[Ctrl+-\]**<br>
  每次以1.25倍放大或縮小顯示比例。縮放比例範圍為5%〜1600%。
- **符合視窗大小**<br>
  自動調整縮放比例，使整張圖片都能顯示在視窗內。變更視窗大小時，顯示比例也會隨之調整。
- **指定縮放比例...**<br>
  在對話方塊中直接輸入縮放比例（％）並顯示。
- **上一頁\[PageUp\] / 下一頁\[PageDown\]**<br>
  在多頁 TIFF 或動畫圖片中，切換至前一格（頁）或下一格（頁）。
- **向左旋轉 / 向右旋轉**<br>
  將顯示內容向左或向右旋轉90度。這只會旋轉顯示畫面，不會變更原始圖片資料（但會套用至儲存和複製的內容）。
- **水平翻轉**<br>
  將顯示內容左右翻轉（鏡像）。這也只是顯示畫面上的操作，不會變更原始圖片資料。
- **黑色背景 / 白色背景 / 棋盤格背景**<br>
  切換透明部分後方的背景（預設為棋盤格）。可用來確認透明部分的顯示效果。<br>
  此設定適用於所有分頁，並會保留至下次啟動。
- **將左上角的顏色設為透明**<br>
  僅在顯示時，將與圖片左上角（座標0,0）相同的顏色視為透明。適合用來確認背景未設為透明色的圖片，其透明顯示效果。<br>
  此設定適用於所有分頁，並會保留至下次啟動。

!!! tip "ヒント"

    「將左上角的顏色設為透明」只適用於原本不含透明度（Alpha）的圖片。為避免已含透明部分的圖片出現非預期的透明區域，即使開啟此設定，也不會套用至這類圖片。

## 滑鼠與鍵盤操作

轉動滑鼠滾輪，即可將游標所在位置設為中心來放大或縮小。<br>
按滑鼠中鍵或點擊分頁上的「×」按鈕，即可關閉分頁。也可以在分頁上按右鍵，選擇「關閉」來關閉分頁。<br>
在裁切模式中，可在圖片上拖曳以指定要裁切的範圍。

以下是常用的鍵盤快速鍵。

| 按鍵 | 功能 |
|---|---|
| Ctrl+O | 開啟圖片 |
| Ctrl+R / F5 | 重新載入 |
| Ctrl+S | 另存新檔 |
| Ctrl+C | 複製 |
| Ctrl+V | 貼上 |
| Ctrl+0 | 實際大小（100%） |
| Ctrl++ | 放大 |
| Ctrl+- | 縮小 |
| PageUp | 上一頁 |
| PageDown | 下一頁 |
| Ctrl+Tab | 切換至下一個分頁 |
| Ctrl+Shift+Tab | 切換至上一個分頁 |

## 各項功能詳細說明

### 放大與縮小

縮放比例範圍為5%〜1600%，每次放大或縮小都會變更為1.25倍。<br>
使用滑鼠滾輪時，會以游標所在位置為中心放大或縮小，因此能快速放大想查看的區域。選擇「符合視窗大小」後，會自動調整顯示比例，讓整張圖片都能顯示在視窗內。

### 旋轉與水平翻轉

可以向左或向右旋轉（每次旋轉90度），也可以水平翻轉。這些操作只會影響顯示畫面，不會修改原始圖片資料。

!!! tip "ヒント"

    以旋轉或翻轉後的狀態「另存新檔」或「複製」時，輸出的內容會維持畫面上看到的方向。<br>
    另外，切換頁面或調整大小時，旋轉、翻轉和裁切狀態都會解除。

### 背景與透明部分的顯示

可以選擇透明部分後方的背景顏色：黑色、白色或棋盤格（預設為棋盤格）。棋盤格背景會以棋盤狀方格顯示，方便辨識透明部分。<br>
搭配「將左上角的顏色設為透明」，即可確認未含透明色的圖片，其透明顯示效果。

### 調整大小與裁切

使用「調整大小」可指定寬度和高度來放大或縮小圖片。由於原始圖片會保留，因此也可以還原為原始尺寸。<br>
開啟「裁切」後，在圖片上拖曳即可指定要裁切的範圍。指定的範圍會套用至儲存或複製的內容，座標則會顯示在狀態列左側。裁切設定僅適用於個別分頁，不會變更原始圖片。

### 儲存・複製

「另存新檔」可選擇 PNG／BMP／JPEG／WebP（無損・有損）。WebP 無損可維持原有畫質，有損則可縮小檔案大小。<br>
儲存對話框中預先選取的格式會與原始圖片的格式相同。若原始圖片是 WebP，還會依照原圖是以無損或有損方式儲存來選取格式。<br>
若原始圖片是 JPEG，且未變更大小或裁切，則會直接儲存而不重新編碼。此時旋轉・翻轉會以不降低畫質的方式套用（無損旋轉），並會移除 EXIF 等中繼資料。<br>
「複製」會在保留透明度的情況下傳送至剪貼簿，因此可以直接貼上並保留透明區域至支援的應用程式。

### 自動重新載入

從檔案開啟的圖片若由外部軟體更新，系統會自動偵測，並在約 1 秒後更新顯示。適合一邊編輯圖片，一邊在檢視器中確認的情況。

### 多頁・動畫

多頁 TIFF，以及 GIF・APNG・WebP 等動畫圖片，可以透過「上一頁」「下一頁」切換影格來確認（不會自動播放）。<br>
PSD 的各個圖層也可以透過「上一頁」「下一頁」切換，分別確認。
