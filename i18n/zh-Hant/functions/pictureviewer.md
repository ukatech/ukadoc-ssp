# 圖片檢視器

這是一個可顯示圖片檔案的檢視器視窗，支援縮放、旋轉、裁切等簡單操作，也能轉換格式後儲存或複製。<br>
除了能直接查看 SSP 支援的多種圖片格式，也可以透過分頁排列多張圖片，切換瀏覽。

無論是查看外殼、對話方塊的素材圖片或拍攝的照片，還是轉換圖片格式，都很方便。

## 支援的圖片格式

主要支援的圖片格式如下。<br>
「支援範圍」中的 **SSP 全域**表示 SSP 本體預設可讀取的格式（也可用於外殼、對話方塊的素材等），**僅限檢視器**表示只有此圖片檢視器能顯示的格式（透過作業系統的 WIC 編解碼器）。

| 格式 | 副檔名 | 支援範圍 | 備註 |
|---|---|---|---|
| PNG / APNG | .png / .apng | SSP 全域 | 支援 Alpha（透明度）。可搭配使用同名的 .pna 檔案作為外部 Alpha。也支援 APNG（動畫 PNG）。 |
| WebP | .webp | SSP 全域 | 支援動畫及透明度。 |
| GIF | .gif | SSP 全域 | 支援動畫及透明度。 |
| MAG | .mag | SSP 全域 | 復古格式（MAKICHAN GRAPHICS，PC-9801 時代）。 |
| Pi | .pi | SSP 全域 | 復古格式（PC-9801 時代的 Pi 格式）。 |
| JPEG | .jpg / .jpeg | SSP 全域 | 自動套用 EXIF Orientation（拍攝時的方向資訊）。 |
| BMP | .bmp | SSP 全域 | Windows 點陣圖。 |
| TIFF | .tif / .tiff | SSP 全域 | 支援多頁面（以「上一頁」／「下一頁」切換）。 |
| X BitMap / X PixMap | .xbm / .xpm | SSP 全域 | X Window 系列的文字格式圖片。 |
| TGA | .tga | SSP 全域 | Truevision Targa。支援透明度。 |
| Netpbm（Portable anymap） | .pbm / .pgm / .ppm / .pam / .pnm / .pfm | SSP 全域 | 可攜式點陣圖／灰階圖／像素圖系列。.pfm 為浮點數（HDR）格式。 |
| PCX | .pcx | SSP 全域 | ZSoft Paintbrush。 |
| QOI | .qoi | SSP 全域 | Quite OK Image Format。 |
| ICO / CUR | .ico / .cur | SSP 全域 | Windows 圖示及游標格式。支援 Alpha（透明度）。包含多種尺寸時會使用最大尺寸。 |
| ANI | .ani | SSP 全域 | Windows 動畫游標。支援動畫及透明度，並遵循播放順序與等待時間。 |
| DLL/EXE | .dll / .exe | SSP 全域 | 列出 DLL 或 EXE 檔案中儲存的圖示，並逐頁顯示。 |
| PSD | .psd | SSP 全域 | Adobe Photoshop。除了合併後的圖片，也可個別讀取各圖層。 |
| PSP | .psp / .pspimage | SSP 全域 | Paint Shop Pro。version4.0 以後。除了合併後的圖片，也可個別讀取各圖層。 |
| OpenRaster | .ora | SSP 全域 | 除了合併後的圖片，也可個別讀取各圖層。 |
| Krita | .kra | SSP 全域 | 除了合併後的圖片，也可個別讀取各圖層。 |
| CLIP STUDIO | .clip | SSP 全域 | 除了合併後的圖片，也可個別讀取各圖層。 |
| GIMP | .xcf | SSP 全域 | 可個別讀取各圖層，但無法讀取合併後的圖片（檢視器會合成各圖層後顯示，因此不影響使用）。 |
| HEIF / HEIC | .heif / .heic | 僅限檢視器 | 需要作業系統的「[HEIF 影像延伸模組](https://apps.microsoft.com/detail/9pmmsr1cgpwg)」。 |
| AVIF | .avif | 僅限檢視器 | 需要作業系統的「[AV1 視訊延伸模組](https://apps.microsoft.com/detail/9mvzqvxjbq9v)」。 |
| JPEG XR | .jxr / .wdp / .hdp | 僅限檢視器 | HD Photo。 |
| DDS | .dds | 僅限檢視器 | DirectDraw Surface。只顯示第一個影格。 |
| 相機 RAW | .cr2 / .nef / .arw 等 | 僅限檢視器 | 各廠商的 RAW 格式。需依賴作業系統的「[RAW 影像延伸模組](https://apps.microsoft.com/detail/9nctdw2w1bh8)」。 |

!!! tip "ヒント"

    「僅限檢視器」的格式需依賴作業系統中安裝的編解碼器（影像延伸模組）。上表僅列出代表性範例，部分格式可能因使用環境而無法讀取。<br>
    此外，「僅限檢視器」的讀取方式不支援動畫及多頁面，一律只顯示第一個影格。

## 啟動方式

可以透過下列任一方式開啟圖片檢視器。

- **[右鍵選單](../howto/rclick.md) →「功能」→「圖片檢視器」**<br>
  以未載入圖片的空白狀態啟動檢視器。<br>
  ⇒ 也請參閱「[功能](index.md)」頁面。
- **將圖片檔案拖放至人格上**<br>
  將圖片檔案放到人格上時，若人格沒有對該檔案做出反應，就會自動以此檢視器開啟。<br>
  如果檔案無法作為圖片讀取，則不會啟動檢視器。

啟動後，可以在檢視器中使用「開啟圖片」、從剪貼簿貼上，或拖放至檢視器內，將更多圖片新增為分頁。

## 畫面配置

- **選單列**<br>
  可透過「檔案」「編輯」「檢視」選單執行所有操作（詳見後文）。
- **工具列**<br>
  以按鈕排列常用操作。每個按鈕都對應一個選單項目，將滑鼠移到按鈕上時會顯示功能名稱（工具提示）。<br>
  裁切及將左上角的顏色設為透明功能開啟時，按鈕會呈現按下的狀態。每次按下切換背景按鈕，圖示都會變成目前的背景（棋盤格／白色／黑色）。
- **分頁**<br>
  每張開啟的圖片都有一個分頁。點擊分頁即可切換顯示的圖片。
- **圖片顯示區域**<br>
  顯示圖片的區域。如果圖片大於區域，便會顯示捲軸。
- **狀態列**<br>
  視窗下方會顯示目前圖片的「尺寸（寬×高）」「縮放比例」「旋轉角度（左右翻轉時會一併顯示 `<| />`）」「格式」。<br>
  像 WebP 這類副檔名相同但壓縮方式不同的格式，會在格式後方一併顯示 `(lossless)`（無損）或 `(lossy)`（有損）。動畫的各影格使用不同壓縮方式時，則會顯示 `(mixed)`。<br>
  裁切時，左側會顯示所選範圍的座標。

## 上方選單

### 檔案

- **開啟圖片...\[Ctrl+O\]**<br>
  開啟檔案選取對話方塊，並在新分頁中開啟選取的圖片。
- **重新載入\[Ctrl+R / F5\]**<br>
  從磁碟重新載入目前顯示的圖片。<br>
  從檔案開啟的圖片會自動偵測外部更新並重新載入，但也可以使用此功能手動重新載入。
- **另存新檔...\[Ctrl+S\]**<br>
  儲存目前顯示的圖片。可選擇PNG／BMP／JPEG／WebP（無損・有損）格式。<br>
  若已進行旋轉、水平翻轉、裁切或變更尺寸，圖片會以目前顯示的狀態（所見內容）儲存。

### 編輯

- **複製\[Ctrl+C\]**<br>
  將目前顯示的圖片複製到剪貼簿，並保留透明度。<br>
  若已進行旋轉、翻轉或裁切，會以目前顯示的狀態複製。
- **貼上\[Ctrl+V\]**<br>
  將剪貼簿中的圖片匯入為新分頁。
- **變更尺寸...**<br>
  在對話方塊中指定寬度和高度，放大或縮小圖片。<br>
  原始圖片會保留下來，指定與原圖相同的尺寸即可還原原始圖片（非破壞性操作）。
- **裁切**<br>
  開啟或關閉裁切（剪裁）模式。<br>
  開啟後，可以在圖片上以滑鼠拖曳，指定要裁切的範圍。儲存或複製時，只會處理該範圍。

### 檢視

- **實際大小\[Ctrl+0\]**<br>
  將縮放比例還原為100%（原始大小）。
- **放大\[Ctrl++\] / 縮小\[Ctrl+-\]**<br>
  每次以1.25倍放大或縮小顯示內容。縮放比例範圍為5%〜1600%。
- **符合視窗大小**<br>
  自動調整縮放比例，讓整張圖片符合視窗大小。變更視窗大小時也會隨之調整。
- **指定縮放比例...**<br>
  在對話方塊中直接輸入縮放比例（％）來顯示圖片。
- **上一頁\[PageUp\] / 下一頁\[PageDown\]**<br>
  在多頁TIFF或動畫圖片中，移至前後影格（頁面）。
- **向左旋轉 / 向右旋轉**<br>
  將顯示內容每次向左或向右旋轉90度。這只是顯示上的旋轉，不會改變原始圖片資料（儲存或複製時則會反映旋轉結果）。
- **水平翻轉**<br>
  將顯示內容水平翻轉（鏡像）。這也是顯示上的操作，不會改變原始圖片資料。
- **黑色背景 / 白色背景 / 棋盤格背景**<br>
  切換透明部分後方的背景（預設為棋盤格）。可用來確認透明部分的顯示效果。<br>
  此設定適用於所有分頁，下次啟動時也會保留。
- **將左上角色彩設為透明**<br>
  僅在顯示時，將與圖片左上角（座標0,0）相同的色彩視為透明。方便確認背景沒有透明色彩的圖片呈現透明時的效果。<br>
  此設定適用於所有分頁，下次啟動時也會保留。

!!! tip "ヒント"

    「將左上角色彩設為透明」只對原本沒有透明度（Alpha）的圖片有效。對於已有透明部分的圖片，即使設定為開啟也不會套用，以避免非預期的部分消失。

## 滑鼠與鍵盤操作

轉動滑鼠滾輪，即可將游標位置作為中心放大或縮小。<br>
使用滑鼠中鍵或分頁上的「×」按鈕即可關閉分頁。也可以在分頁上按右鍵，選擇「關閉」來關閉分頁。<br>
在裁切模式中，於圖片上拖曳即可指定要裁切的範圍。

主要鍵盤快捷鍵如下。

| 按鍵 | 功能 |
|---|---|
| Ctrl+O | 開啟圖片 |
| Ctrl+R / F5 | 重新載入 |
| Ctrl+S | 另存新檔 |
| Ctrl+C | 複製 |
| Ctrl+V | 貼上 |
| Ctrl+0 | 實際大小（100%） |
| Ctrl++ | 放大 |
| Ctrl+- | 縮小 |
| PageUp | 上一頁 |
| PageDown | 下一頁 |
| Ctrl+Tab | 切換至下一個分頁 |
| Ctrl+Shift+Tab | 切換至上一個分頁 |

## 各項功能詳解

### 放大・縮小

縮放比例範圍為5%〜1600%，放大或縮小時每次以1.25倍變化。<br>
使用滑鼠滾輪時，會以游標位置為中心放大或縮小，因此可以快速放大想看的位置。選擇「符合視窗大小」時，會自動調整，讓整張圖片始終符合視窗大小。

### 旋轉・水平翻轉

可以向左或向右旋轉（每次90度）及水平翻轉。這些都是顯示上的操作，不會修改原始圖片資料本身。

!!! tip "ヒント"

    在旋轉或翻轉的狀態下執行「另存新檔」或「複製」時，會以所見的方向輸出。<br>
    此外，切換頁面或變更尺寸時，會清除旋轉、翻轉及裁切狀態。

### 背景・透明部分的顯示

透明部分後方的背景可選擇黑色、白色或棋盤格（預設為棋盤格）。棋盤格以方格交錯的方式顯示，方便辨識透明部分。<br>
搭配「將左上角色彩設為透明」使用，可以確認沒有透明色彩的圖片呈現透明時的效果。

### 變更尺寸・裁切

「變更尺寸」可指定寬度和高度來放大或縮小圖片。由於原始圖片會保留，因此也可以還原為原始尺寸。<br>
開啟「裁切」並在圖片上拖曳，即可指定要裁切的範圍。儲存或複製時會處理指定的範圍，座標會顯示在狀態列左側。裁切是各分頁獨立的設定，原始圖片不會改變。

### 儲存與複製

「另存新檔」可選擇 PNG／BMP／JPEG／WebP（無損・有損）格式。WebP 無損格式可保持原有畫質，有損格式則可縮小檔案大小。<br>
儲存對話方塊中預先選取的格式會與原始圖片格式相同。若原始圖片為 WebP，還會依照原檔是無損或有損格式來選取。<br>
如果原始圖片是 JPEG，且未調整大小或裁切，儲存時不會重新編碼。此時旋轉與翻轉會以不降低畫質的方式套用（無損旋轉），EXIF 等中繼資料則會被移除。<br>
「複製」會保留透明度並將圖片送至剪貼簿，因此可以直接貼到支援的應用程式中，保留透明部分。

### 自動重新載入

從檔案開啟的圖片若被外部軟體更新，系統會自動偵測，並在約1秒後更新顯示。這項功能方便您一邊編輯圖片，一邊在檢視器中確認結果。

### 多頁與動畫

多頁 TIFF 及 GIF、APNG、WebP 等動畫圖片，可透過「上一頁」「下一頁」切換影格來查看（不會自動播放）。<br>
PSD 的各個圖層也可以透過「上一頁」「下一頁」切換，分別查看。
