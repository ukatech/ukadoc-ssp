# SSP 即時通訊：新增收件者

透過 IP 位址和連接埠號碼指定收件者很麻煩，也常常容易出錯。<br>
如果對方或自己是透過撥接網路連線交換訊息，每次連線時雙方的 IP 位址都可能改變，設定起來也會很費工。

這時就可以使用目錄服務。

指定使用者 ID（電子郵件地址）後，就能只透過名稱查詢登入同一個目錄服務的使用者。SSP 預設使用「SSP 與愉快夥伴們」作為伺服器，任何人都能免密碼自由使用。<br>
※這項服務讓您公開自己的資訊，以便查詢對方的資訊。因此，即使您使用固定 IP，若要尋找使用動態 IP 的使用者，也必須登入目錄服務。<br>
※可公開及查詢的資訊只有兩項：IP 位址，以及等待接收 SSTP 的連接埠號碼。

此外，雖然使用機會可能不多，但如果雙方都有固定 IP（無論透過網際網路或區域網路），也可以在本機儲存名稱與 IP 位址的對應資料。這樣可以省去查詢步驟，更快將訊息傳送給對方。

## 登錄目錄服務使用者

按一下「登錄」中的「新增收件者」選單，開啟對話方塊後，先選取「目錄服務」。

接著輸入對方的名稱和群組。（這兩項用來識別 SSP 中登錄的資訊。）

選取對方登入的目錄服務。目錄服務請在[設定對話方塊](../../config/im.md)中登錄。

使用者 ID 通常會填入對方的電子郵件地址，但必須是對方用來登入的使用者 ID，請向對方確認。

完成以上步驟後，即完成登錄。之後傳送訊息時，系統會自動取得對方的位址並傳送。

## 直接指定 IP 位址來登錄使用者

按一下「登錄」中的「新增收件者」選單，開啟對話方塊後，選取「指定位址」。

接著輸入對方的名稱和群組。（這兩項用來識別 SSP 中登錄的資訊。）

指定對方的 IP 位址，以及對方用於 SSP 即時通訊的連接埠號碼。

完成以上步驟後，即完成登錄。
