# 視窗模式

這是一種不將人格直接放在桌面上，而是將它限制在一個視窗內顯示的模式。<br>
視窗內的空間就像一個小小的桌面，人格只會在其中活動。

如果想用直播軟體擷取整個視窗，或想將桌面留給其他工作，這種模式就很方便。<br>
人格不會跑到其他應用程式前面，也不會影響整個桌面。

!!! tip "ヒント"

    視窗模式是實驗性功能，使用方式與規格未來可能會變更。

!!! tip "ヒント"

    受作業系統功能限制，Windows 7 以前的版本無法使用。請使用 Windows 8 以後的版本。

## 兩種顯示方式

- **所有人格合併在一個視窗**<br>
  將所有已啟動的人格合併顯示在一個視窗中（預設值）。<br>
  使用起來就像是將桌面原封不動地縮小了一樣。
- **每個人格各自一個視窗**<br>
  每個人格各自使用一個視窗。<br>
  可以將人格分別排列在不同位置，或只擷取其中一個人格。

## 切換至視窗模式

可以透過以下任一方式切換。無論從哪裡變更，都會套用相同設定，且狀態會保持一致。

- **[右鍵選單](../howto/rclick.md) →「設定」**<br>
  從「視窗模式 - 關閉」、「視窗模式 - 所有人格」及「視窗模式 - 每個人格」三個項目中選擇。目前的狀態會顯示勾選記號。<br>
  ⇒請參閱「[設定](../config/index.md)」頁面。
- **偏好設定中的「[直播](../config/streamingtool.md)」**<br>
  將「在人格視窗中顯示人格」設為 ON，並選擇「所有人格合併在一個視窗」或「每個人格各自一個視窗」。
- **視窗的「操作」選單**<br>
  也可以直接從視窗模式的視窗中，透過相同的三個項目切換。選擇「關閉」即可返回一般的桌面顯示方式。

選擇的狀態會被記住，下次啟動 SSP 時也會沿用。<br>
也可以使用啟動選項 `--windowmode` 指定後啟動。⇒請參閱「[啟動選項一覽](option.md)」頁面。

!!! tip "ヒント"

    人格載入期間無法切換。此時選單或勾選狀態會還原成原本的狀態，請等載入完成後再試一次。<br>
    切換前後，人格位置相對於畫面的比例大致會保持不變。即使可顯示的範圍改變，也不會突然跑到很遠的地方。

## 開啟「操作」選單

視窗本身的操作都集中在「操作」選單中。可以透過以下任一方式開啟。

- **在視窗內按右鍵**<br>
  在沒有顯示人格或對話方塊的位置按右鍵即可開啟。無論是否顯示視窗邊框，都可以使用。
- **標題列選單**<br>
  如果有顯示視窗邊框，可以在標題列按右鍵（或點選左上角的圖示），並在出現的選單中選擇「操作」。
- **左上角的 `≡` 按鈕**<br>
  隱藏視窗邊框或使用全螢幕顯示時，將滑鼠移到視窗上，左上角就會出現 `≡` 按鈕。點選即可開啟「操作」選單。<br>
  此時右上角也會出現 `×` 按鈕，可用來關閉視窗。

## 「操作」選單項目

- **視窗模式 - 關閉 / 所有人格 / 每個人格**<br>
  切換顯示方式（如上所述）。
- **全螢幕顯示\[F11\]**<br>
  將視窗放大至整個螢幕，並隱藏邊框。畫面上只會顯示人格。<br>
  按 ESC 鍵或再按一次 F11，即可還原成原本的大小。全螢幕顯示時無法移動視窗位置。
- **顯示視窗邊框**<br>
  切換是否顯示標題列與邊框（預設為顯示）。<br>
  隱藏邊框後，畫面會更簡潔，擷取畫面時也不會拍到邊框。即使沒有邊框，仍可拖曳視窗邊緣調整大小。抓住角落附近的位置即可斜向調整。<br>
  將滑鼠移到邊緣時，可拖曳的位置會以細線標示。拖曳視窗內空白處也可以移動位置。
- **也整合歷史記錄／發話記錄**<br>
  也會將歷史記錄（發話記錄）視窗整合到此視窗中（預設為 ON）。⇒請參閱下方的「[整合歷史記錄](#バックログの統合)」。
- **背景 - 白色 / 灰色 / 黑色 / 桌面 / 圖片...**<br>
  切換視窗背景（預設為「桌面」）。<br>
  「桌面」會依照目前桌布的顯示方式（置中、並排、配合螢幕大小等）重現桌布。變更桌布後也會同步更新。<br>
  白色、灰色、黑色都是單色背景。可用於直播時去除背景，或確認人格的顯示效果。<br>
  選擇「圖片...」會開啟檔案選擇對話方塊，讓您將喜歡的圖片設為背景。圖片會在保持長寬比例的情況下放大至填滿整個視窗，超出範圍的部分會被裁切。
- **螢幕截圖...**<br>
  將視窗內的畫面直接儲存為 PNG 圖片。您可以在儲存對話方塊中選擇以下兩種格式。<br>
  **PNG** … 將包含背景的畫面原樣儲存。<br>
  **PNG - 透明背景** … 將背景設為透明，只儲存人格與對話方塊。<br>
  預設檔名格式為 `ssp_日付_時刻.png`。滑鼠移上去時出現的按鈕和邊緣線條不會被拍進去。
- **關閉\[Ctrl+W\]**<br>
  關閉視窗。如果使用「每個人格各自一個視窗」，也會結束該視窗中的人格。

!!! tip "ヒント"

    邊框、背景、全螢幕等外觀設定會分別記錄在各個視窗中。如果使用「每個人格各自一個視窗」，也可以為不同人格設定不同背景。

!!! tip "ヒント"

    **搭配全像裝置使用時**，建議採用「背景 - 黑色」、「關閉顯示視窗邊框」及「也整合歷史記錄／發話記錄」的組合。<br>
    全像裝置是指能投影出角色彷彿懸浮在空中的顯示裝置。許多裝置會投影電腦螢幕畫面，而在這類裝置上，黑色部分不會發光，會直接呈現透明效果。<br>
    因此將背景設為黑色，並隱藏邊框及其他視窗後，人格與對話方塊就會看起來像是懸浮在空中。<br>
    如果想讓畫面盡量填滿裝置可投影的範圍，也可以一併使用全螢幕顯示（F11）。

## 整合歷史記錄

「也整合歷史記錄／發話記錄」設為 ON 時，歷史記錄視窗會收納在此視窗中。這樣就不會有其他視窗跳出到桌面上，也能直接將它納入擷取畫面。

整合後的歷史記錄會呈現為沒有邊框的板狀視窗。將它移到視窗邊緣附近時，就會自動吸附對齊。<br>
文字大小會配合該人格對話方塊的放大比例變更，避免對話方塊與發話記錄的文字大小不一致。<br>
背景顏色會配合視窗的背景設定變更。如果背景使用圖片，則會採用該圖片中使用最多的顏色（主色）。

!!! tip "ヒント"

    設為 OFF 時，歷史記錄會如同以往一樣，在桌面上以獨立視窗開啟。<br>
    只有這項設定是 SSP 全體共用，而非各個視窗各自設定；切換顯示方式後也會沿用。

## 工作列與最小化

使用視窗模式時，工作列只會顯示此視窗。人格或對話方塊不會各自顯示在工作列上。<br>
將視窗最小化時，人格也會一併隱藏；還原視窗時，人格也會跟著恢復。反過來說，將所有人格都最小化時，視窗也會一併最小化。

## 鍵盤快速鍵

視窗位於最前方時，可以使用以下按鍵。

| 按鍵 | 功能 |
|---|---|
| F11 | 切換全螢幕顯示 |
| ESC | 退出全螢幕顯示（僅限全螢幕顯示時） |
| Ctrl+W | 關閉視窗 |
