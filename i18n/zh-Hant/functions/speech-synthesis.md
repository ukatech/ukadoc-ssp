# 語音合成

這項功能會將人格在對話方塊中說的內容直接讀出來。<br>
除了 Windows 內建的語音，也可以使用 VOICEVOX 等外部語音合成軟體，或雲端語音合成服務提供的語音。<br>
您可以為每個角色（`\0`、`\1`、`\2` 以後）指定不同的語音。

!!! tip "ヒント"

    這項功能會讓人格發出聲音。若要用語音和人格交談，請參閱「[語音辨識](speech-recognition.md)」頁面。

## 開始使用

1. 在右鍵選單中選取「功能」→「語音合成」。項目會出現勾選標記，並開始朗讀。<br>
   再次選取即可關閉。下次啟動時也會沿用開啟／關閉狀態。
2. 在偏好設定的「[語音辨識／合成](../config/dictation.md)」中，選擇各角色的語音。若不選擇任何項目（「(System Default)」），就會使用 Windows 預設語音。
3. 視需要調整語速、音量和音高（音調）。變更設定後，會從下一次朗讀開始套用（不需要重新啟動 SSP）。

開啟功能時正在說話的內容不會被朗讀。朗讀會從下一段發言開始。

## 會朗讀哪些內容

對話方塊中顯示的一般文字會配合顯示進度朗讀。<br>
以下內容不會朗讀。

- 選項和錨點（可點選的文字）。
- 表情符號或「★」等符號。若出現在句子中間，會略過而不朗讀，並留出停頓。只有標點符號的發言也不會朗讀。
- 未設定等待時間、會瞬間顯示的文字。
- 人格指定為不朗讀（或改用其他文字朗讀）的內容。有些人格可能會朗讀與對話方塊中顯示內容不同的文字。

使用的語音會依發言角色而異。主角色（`\0`）、副角色（`\1`）及其他角色（`\2` 以後）會使用各自設定的語音。<br>
預設音高為主角色（`\0`）0、副角色（`\1`）+5（稍高），而 `\2` 以後則為 -5（稍低）。這樣會讓各角色的音高略有不同。您可以隨時在偏好設定的「[語音辨識／合成](../config/dictation.md)」中變更設定。

## 讓語音與文字同步

以下說明偏好設定中的「配合語音合成進度等待腳本播放」。

- **關閉（預設設定）**<br>
  對話方塊中的文字會照平常的速度播放，語音則會跟著文字朗讀。<br>
  在語音合成需要較長時間的環境中，文字會先播放，語音則會落後。落後期間如果開始播放下一段發言，前一段尚未讀完的內容可能會被跳過。
- **開啟**<br>
  腳本播放會等待語音朗讀追上進度。對話方塊文字與語音的時間差會縮小，也較不容易漏讀。<br>
  但如果語音合成需要較長時間，人格的動作也會相應變慢。

## 使用外部語音合成軟體

「選擇語音」清單除了列出 Windows 內建語音，也會列出「LocalAPI-0〜9」和「CloudAPI-0〜9」。<br>
這些是用來設定外部語音合成的欄位。每個欄位可以分別設定一組伺服器、語音和風格等項目。您可以為不同角色指定不同欄位，也可以共用同一個欄位。

- **LocalAPI**<br>
  連線至在您的電腦（或區域網路中的電腦）上執行的軟體。支援 VOICEVOX、VOICEVOX Nemo、SHAREVOX、AivisSpeech、COEIROINK v2、Style-BERT-VITS2，以及相容於 OpenAI 的本機伺服器。
- **CloudAPI**<br>
  連線至網際網路上的服務。支援 Aivis Cloud API 和 OpenAI TTS（或相容服務）。您需要取得 API 金鑰，使用費用則依服務提供者的規定計算。

設定步驟如下。

1. 使用 LocalAPI 時，請先啟動語音合成軟體。
2. 開啟偏好設定的「[語音辨識／合成](../config/dictation.md)」，然後在角色的「選擇語音」中選取「LocalAPI-0」等項目。
3. 按右側的「設定...」，然後在「類型」中選擇要使用的軟體。
4. 按「瀏覽...」後，會顯示軟體中登錄的語音清單，請選擇要使用的語音（如果知道 ID，也可以直接輸入）。
5. 按「確定」關閉視窗，再開啟「功能」→「語音合成」。

各項目的輸入方式會因軟體而異。詳細說明請參閱「[語音合成詳細設定對話方塊](../config/dictation.md#音声合成の詳細設定ダイアログ-右側の設定ボタン)」。

## 沒有聲音時

- 請確認「功能」→「語音合成」是否已勾選。
- 請確認偏好設定中的「音訊輸出裝置」、音量和 Windows 音效設定是否正確，且目前可以播放聲音。
- 使用外部語音合成軟體時，請確認軟體是否正在執行，以及主機名稱和連接埠號碼是否正確。如果按「瀏覽...」後沒有顯示語音清單，表示尚未連線至軟體。
- 使用雲端服務時，請確認 API 金鑰是否正確輸入。
- 如果語音需要等待一段時間才會播放，表示合成需要較長時間。若要配合人格動作，請開啟「同步」；若要優先播放動作，請關閉「同步」。
- 如果電腦無法使用語音合成功能，偏好設定中的語音合成選項會呈現灰色，無法選取。
