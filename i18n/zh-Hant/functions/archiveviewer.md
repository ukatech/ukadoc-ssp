# 壓縮檔檢視器

這是一個檢視器視窗，可像資源管理器一樣列出 ZIP 等壓縮檔（封存檔）的內容，並將檔案取出。<br>
只要檢視內容就不需要解壓縮，您可以透過拖放取出需要的檔案。您也可以在多個壓縮檔之間切換分頁，逐一瀏覽內容。

反過來說，您也可以收集手邊的檔案和資料夾，建立新的壓縮檔（進行壓縮）。

## 支援的壓縮檔格式

以下列出主要支援的壓縮檔格式。<br>
「建立」欄標示為○的格式，也可以使用此檢視器建立新的壓縮檔；其他格式則只能檢視及解壓縮。

| 格式 | 副檔名 | 建立 | 註解 |
|---|---|---|---|
| ZIP | .zip / .zipx | ○ | 也支援加密（ZipCrypto / AES-128・192・256）。 |
| NAR | .nar | − | 用於散布人格等項目的壓縮檔。內容是 ZIP。 |
| 7-Zip | .7z | ○ | 支援加密（AES-256），以及連檔名也會隱藏的標頭加密。 |
| LZH | .lzh / .lha | − | 在日本沿用已久的格式。 |
| CAB | .cab | − | Windows 櫃檔。也能辨識分割（多磁碟區）壓縮檔。 |
| 自解壓縮檔 | .exe | − | 會搜尋並開啟嵌入執行檔中的壓縮檔。 |
| TAR | .tar / .tgz / .txz / .tbz2 / .tlz / .tzst 等 | − | UNIX 系統常用的封裝格式。也能直接開啟與下列壓縮方式組合的檔案。 |
| 單一壓縮檔 | .gz / .bz2 / .xz / .lzma / .zst / .br / .Z | − | gzip / bzip2 / XZ / LZMA / Zstandard / Brotli / UNIX compress。會以只有 1 個檔案的壓縮檔形式開啟。 |
| cpio | .cpio | − | UNIX cpio 壓縮檔（newc / crc / odc / 舊式二進位格式）。 |
| ar / Debian 套件 | .deb / .udeb | − | 實際上是 ar 壓縮檔。 |
| RPM 套件 | .rpm | − | Red Hat 系統使用的套件。 |
| CD/DVD 映像檔 | .iso | − | ISO9660 / Joliet / Rock Ridge / UDF。可以取出其中的檔案。 |
| 磁碟映像檔 | .img | − | FAT12 / FAT16 / FAT32 軟碟等磁碟映像檔。 |

!!! tip "ヒント"

    格式是根據**檔案內容**而非副檔名判斷。因此，即使是只修改過副檔名的壓縮檔，或是沒有副檔名的壓縮檔，也能正確開啟。<br>
    此外，也會根據內容自動判斷 `.iso.gz` 這類「再壓縮過的映像檔」等組合格式。

## 啟動方式

您可以透過下列任一方式開啟壓縮檔檢視器。

- **[按右鍵選單](../howto/rclick.md) →「功能」→「壓縮檔檢視器」**<br>
  會以尚未開啟任何檔案的空白狀態啟動檢視器。<br>
  ⇒請參閱「[功能](index.md)」頁面。
- **將壓縮檔拖放到人格上**<br>
  將壓縮檔拖放到人格上時，如果人格端沒有對該檔案做出反應，就會自動使用此檢視器開啟。<br>
  如果檔案無法以壓縮檔形式讀取，檢視器就不會啟動。
- **將壓縮檔拖放到檢視器中**<br>
  啟動檢視器後，將壓縮檔拖放到檢視器中，即可新增分頁開啟。可以放在視窗的任何位置（標題列、分頁列或清單上都可以）。<br>
  一次拖放多個檔案時，只有能以壓縮檔形式開啟的檔案會新增為分頁，其他檔案則會忽略。

## 畫面配置

- **功能表列**<br>
  您可以在此執行所有操作（詳情如下）。
- **工具列**<br>
  以按鈕排列常用操作。每個按鈕都對應一個功能表項目，將滑鼠移到按鈕上時會顯示功能名稱（工具提示）。<br>
  目前無法使用的操作會以灰色虛線按鈕顯示。最右側的顯示方式切換按鈕，每按一次就會變更圖示，以表示目前的顯示方式。
- **分頁**<br>
  每個已開啟的壓縮檔都會顯示為一個分頁。按一下分頁即可切換顯示的壓縮檔。<br>
  可以透過分頁最左側的圖示，分辨這是檢視用分頁，還是用來建立新壓縮檔的分頁。
- **清單**<br>
  顯示壓縮檔內容的區域。在「詳細資料」檢視中，會顯示**名稱・大小・壓縮後大小・方式・更新日期時間**等欄位。<br>
  「壓縮後大小」欄中的 `-` 表示該格式無法得知個別檔案的壓縮後大小（例如 7-Zip 或 tar 等會將檔案一併壓縮的格式）。
- **狀態列**<br>
  視窗底部會由左至右顯示<strong>壓縮檔中的目前位置（資料夾）</strong>・**實際的壓縮檔格式**・**此資料夾中的項目數**。<br>
  解壓縮或壓縮正在執行時，最左側會顯示進度列。

!!! tip "ヒント"

    「實際的壓縮檔格式」會依照實際讀取到的內容，顯示為 `Zip/Deflate/AES-256`、`7Zip/LZMA2/AES-256/Encrypted Header`、`GZip/Tar`、`UDF Image` 等格式。這是根據內容而非副檔名判斷，因此例如副檔名是 `.exe`，但內容是 ZIP 時，就會顯示為 `Zip`。

## 上方功能表

### 瀏覽・解壓縮

- **開啟...\[Ctrl+O\]**<br>
  開啟檔案選擇對話方塊，並在新分頁中開啟所選的壓縮檔。可以複選。<br>
  如果已有分頁開啟相同的壓縮檔，則會切換到該分頁。
- **解壓縮...**<br>
  將清單中**所選的項目**解壓縮至指定資料夾。如果選擇的是資料夾，也會一併解壓縮其中的內容。<br>
  解壓縮後會保留相對於目前顯示資料夾的資料夾階層。
- **全部解壓縮...**<br>
  將壓縮檔中的**所有內容**解壓縮至指定資料夾。此功能會保留從壓縮檔最上層開始的資料夾階層。

!!! tip "ヒント"

    系統會記住解壓縮目的資料夾，並在下次解壓縮時將其設為預設值。

### 建立壓縮檔

- **新增\[Ctrl+N\]**<br>
  建立空白的「壓縮分頁」。先將要放入壓縮檔的項目收集到這裡，再將它們儲存為壓縮檔。
- **新增檔案...**<br>
  將檔案加入壓縮分頁。可以複選。
- **新增資料夾...**<br>
  將資料夾連同其內部的資料夾階層加入壓縮分頁。由於資料夾選擇對話方塊一次只能選擇一個資料夾，若要一次加入多個資料夾，請使用拖放。
- **刪除\[Delete\]**<br>
  從預定加入的清單中移除所選項目。如果選擇的是資料夾，也會一併移除其中的內容。<br>
  項目只會從清單中移除，不會刪除原始檔案。
- **另存為壓縮檔...\[Ctrl+S\]**<br>
  將收集的項目輸出為單一壓縮檔。格式會依儲存時選擇的副檔名決定（`.7z` 為 7-Zip，其餘則為 ZIP）。<br>
  勾選儲存對話方塊中的「密碼」核取方塊，即可設定密碼（詳見下文）。

!!! tip "ヒント"

    這些項目只能在壓縮分頁中使用。在瀏覽壓縮檔的分頁中會呈現灰色。相反地，「解壓縮」和「全部解壓縮」則只能在瀏覽分頁中使用。

### 選取・顯示

- **全選\[Ctrl+A\]**<br>
  選取目前顯示資料夾中的所有項目。
- **大圖示 / 小圖示 / 清單 / 詳細資料**<br>
  切換清單的顯示方式（預設為「詳細資料」）。與資源管理器中的檢視方式切換相同。<br>
  所有分頁共用此設定，並會保留至下次啟動。
  
## 滑鼠・鍵盤操作

- **雙擊資料夾**<br>
  移至該資料夾內。若要返回上一層，請雙擊最上方的 `..`。
- **雙擊檔案**<br>
  取出該檔案，並模擬將它拖放至目前顯示的人格。<br>
  如果人格沒有反應，就會像一般拖放一樣，以[圖片檢視器](pictureviewer.md)或媒體播放器等程式開啟。無須解壓縮壓縮檔即可查看內容，非常方便。
- **將項目拖曳至資源管理器**<br>
  可以將所選檔案或資料夾直接拖曳至資源管理器中的資料夾或桌面，以取出檔案。也可以在複選項目後一併拖曳。資料夾會連同其內部的資料夾階層一起取出。<br>
  檔案會直接取出至放開項目的位置，而非先解壓縮至某處再複製。<br>
  檔案會在放開滑鼠後開始取出，因此即使是大型壓縮檔，也能立即放開滑鼠，並在等待期間繼續操作檢視器。<br>
  即使是設有密碼的壓縮檔，只要開啟時已輸入密碼，就不會再次要求輸入。
- **拖放至檢視器**<br>
  放入壓縮檔後，會在新分頁中開啟。<br>
  但**顯示壓縮分頁期間**，放入的檔案或資料夾會加入「預定加入」清單。

常用的鍵盤快捷鍵如下。

| 按鍵 | 功能 |
|---|---|
| Ctrl+N | 新增（壓縮分頁） |
| Ctrl+O | 開啟壓縮檔 |
| Ctrl+A | 全選 |
| Ctrl+S | 另存為壓縮檔 |
| Delete | 從預定加入清單中移除（僅限壓縮分頁） |
| Ctrl+W | 關閉分頁 |
| Ctrl+Tab | 切換至下一個分頁 |
| Ctrl+Shift+Tab | 切換至上一個分頁 |

## 各項功能詳解

### 開啟有密碼的壓縮檔

嘗試開啟有密碼的壓縮檔時，系統會要求輸入密碼。密碼正確的話，直到關閉該視窗之前都不必再次輸入。<br>
對於使用 7-Zip「加密標頭」功能的壓縮檔，顯示檔名清單時就需要輸入密碼。

### 建立壓縮檔

使用「新增」開啟壓縮分頁，再將檔案或資料夾拖放至其中，或透過「新增檔案」或「新增資料夾」收集項目。加入的資料夾會保留原有的內部資料夾階層。<br>
收集項目時，雙擊資料夾即可移至該資料夾內。在此狀態下新增的項目也會放在壓縮檔的相同階層中。<br>
再次加入同名項目時，新的項目會取代舊的項目。

收集完成後，使用「另存為壓縮檔」輸出。儲存後壓縮分頁仍會保留，因此也可以繼續加入內容，再另存為其他名稱。

### 壓縮時設定密碼

勾選儲存對話框中的「密碼」核取方塊後，會開啟設定密碼的對話框。

- **輸入**<br>
  輸入自行設定的密碼。輸入內容會以遮蔽字元顯示。
- **產生**<br>
  自動產生隨機密碼。您可以指定使用的字元類型（小寫字母、大寫字母、數字、符號）和字元數（4〜64 個字元，預設值為 16 個字元）。<br>
  為了方便抄錄，產生的密碼會直接顯示，不會以遮蔽字元呈現。

!!! tip "ヒント"

    忘記密碼就無法取出內容。請務必抄下產生的密碼。<br>
    如果輸出格式為 `.7z`，除了內容之外，檔案名稱清單也會一併加密（標頭加密）。ZIP 無法隱藏檔案名稱。

### 顯示可疑項目的警告

如果壓縮檔中包含解壓縮後可能造成意外結果的項目，該項目名稱會以**紅色文字**顯示。<br>
如果資料夾中包含這類項目，資料夾名稱也會變成紅色，讓您不必逐層開啟資料夾也能注意到。

符合下列任一條件的項目會以紅色顯示。

| 類型 | 說明 |
|---|---|
| 壓縮率異常 | 解壓縮後的大小膨脹至壓縮後的200倍以上的項目（俗稱「zip 炸彈」）。 |
| 檔案過大 | 單一檔案超過64GB。 |
| 可疑路徑 | 試圖將檔案寫出至壓縮檔外部的名稱（包含 `..`、以磁碟機名稱開頭等）。SSP 會自動將其轉為無害，但這也是懷疑壓縮檔來源的線索。 |
| 名稱重複 | 存在名稱相同、但只有大小寫不同的檔案。解壓縮時，其中一個檔案會在不顯示提示的情況下覆寫另一個。 |
| 日期異常 | 更新日期早於1980年或晚於2100年的項目。 |
| 特殊項目 | 符號連結或裝置等非一般檔案或資料夾的項目。即使解壓縮，也不會建立實際項目。 |
| 偽裝副檔名 | 名稱中含有特殊控制字元，導致顯示的副檔名與實際副檔名不同的項目。 |

!!! tip "ヒント"

    紅色顯示僅用於提醒，不會阻止解壓縮。<br>
    此外，SSP 會自動將試圖寫出至壓縮檔外部的項目轉為無害，並略過連結或裝置等特殊項目，不會建立實際項目。即使解壓縮紅色項目，也不會破壞壓縮檔外部的內容。

### 解壓縮大型壓縮檔

解壓縮或壓縮期間，狀態列最左端會顯示進度列。處理完成後，進度列會自動消失。
