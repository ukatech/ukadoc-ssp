# 快速鍵一覽

SSP 為常用功能設定了快速鍵。

以下標示<strong>【開発】</strong>的功能，只有在偏好設定「[一般](../config/ippan.md)」中的「啟用開發者功能」設為 ON 時才能使用。

| 功能 | 快速鍵 |
|---|---|
| 往回瀏覽 | Ctrl - B (Backlog) |
| 行事曆 | Ctrl - D |
| 開發用面板 | <strong>【開発】</strong>Ctrl - Shift - D (Development) |
| 資源管理器 | Ctrl - E (Explorer) |
| 在資源管理器等位置搜尋 | Ctrl - F (Find) |
| 最小化 | Ctrl - I / Ctrl - Shift - Return\[即使未取得焦點也可使用\] |
| 關閉對話方塊 | Ctrl - Shift - Delete\[即使未取得焦點也可使用\] |
| 保留暫時啟動的人格 | Ctrl - K (Keep) |
| 腳本記錄 | <strong>【開発】</strong>Ctrl - L (Log) |
| SSP 即時通訊 | Ctrl - M (Messenger) |
| 開啟檔案 | Ctrl - O (Open) |
| 選取資料夾 | Ctrl - F |
| 全部結束 | Ctrl - Q (Quit) |
| 輸入腳本 | <strong>【開発】</strong>Ctrl - S (Script) / Ctrl - Shift - Insert |
| Surface 測試 | <strong>【開発】</strong>Ctrl - T (Test) |
| 線上更新 | Ctrl - U (Update) |
| 網址列 | Ctrl - Shift - U (URL) |
| 重設對話方塊位置 | Ctrl - Shift - F10 |
| 重設外殼位置 | Ctrl - Shift - F12 |
| 結束 | Ctrl - W / Ctrl - F4 |
