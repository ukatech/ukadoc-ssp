# 用語說明

## 人格

指角色資料，或構成其擬似 AI 的部分。<br>
人格掌管角色的「人格」，負責做出各種反應或與人交談，可說是角色的「心」與「靈魂」。<br>
不過，當然光有「靈魂」是無法具體呈現的，因此大多數情況下，指的是與「外殼」組成一套，並包裝成可立即使用的形式。<br>
此外，視上下文而定，這個詞也可能像後文提到的「伺か（Ukagaka）」一樣，泛指某種風格或類型。

## 外殼

指人格的角色立繪資料。<br>
外殼是掌管角色「外觀」的部分。最近雖然不太如此，但從歷史上來看，由於開發者多為男性（^_^;），因此外殼似乎大多以女性為造型。不過也有男性、動物、非生物，以及單純作為資訊工具使用的「非萌系（Moeless）」外殼。<br>
一個人格可以搭配多個外殼，並可從「外殼」選單切換。

## 對話方塊

簡單來說，就是「對話泡泡」。這是用來顯示人格對話的小型視窗。<br>
與上述外殼相同，也有許多不同外觀的對話方塊可供下載，並且可以輕鬆安裝。

## 線上更新

這項功能會透過網際網路，逐一檢查構成人格等內容的檔案是否有變更，並只下載有更新的部分，再覆寫原有檔案。<br>
如此一來，使用者就不必經常前往發佈網站確認是否有更新，也不必在有更新時下載整個壓縮檔，再覆寫安裝。<br>
除了人格之外，SSP 也提供外殼、對話方塊、線上新聞及外掛程式的同類功能。<br>
人格可從[按右鍵選單](../howto/rclick.md)執行更新；外殼和對話方塊則視[偏好設定](../config/ghost.md)而定，也可以從按右鍵選單執行；除此之外的所有項目，都可以從[資源管理器](../functions/explorer/index.md)執行更新。

## 線上新聞

自動取得特定網站的更新資訊等內容，並顯示其清單的功能。<br>
線上新聞功能可透過外掛程式擴充。將其套件**拖曳**到目前顯示的人格上，或解壓縮後放入 headline 資料夾，再重新啟動一次 SSP，即可辨識此外掛程式。<br>
線上新聞也有自動巡覽的功能。

## さくら側／うにゅう側

這是過去稱為「偽○○」的時期，以及「何か」預設人格中的稱呼：主要角色稱為さくら，配角稱為うにゅう。<br>
SSP 的預設人格「Emily」中，戴著貓耳的女性角色是「さくら側」，謎樣生物？テディ則是「うにゅう側」。<br>
`\h`側／`\u`側、`\0`側／`\1`側、`\p0`側／`\p1`側、主角側／配角側、本體側／搭檔側等稱呼，都與此相同。

## SHIORI

用來打造「人格」的系統名稱。<br>
通常以 Windows DLL 的形式提供，但其設計並不依賴特定作業系統。

## MAKOTO

用來替換人格或透過 SSTP 通訊傳來的文字中，特定詞語的機制。<br>
例如，可藉由變換句尾等方式改變說話語氣。<br>
這通常也以 Windows DLL 的形式提供，但其設計並不依賴特定作業系統。<br>
此外，也有將此機制延伸運用，用來演奏音樂或提供特殊功能的實作。

## SERIKO

指外殼的動畫。<br>
在 SSP 和伺か中，有時會以此稱呼外殼動畫的規格。

## MAYUNA

指外殼的換裝機制。<br>
SSP 和伺か的換裝功能，是以 SERIKO（動畫）的一種形式實作。

## Sakura Script

指一種以標籤裝飾的字串，標籤代表各種命令，可用來控制人格的表情、開啟特定網址，或在對話方塊中顯示文字和圖片等，並用於人格或 SSTP 等。

## 表面（Surface）

surface。也稱為 surface、surface 等。<br>
這是外殼（以及包含對話方塊等圖片的內容）中，相當於一張「畫格」的零件或元素。<br>
在外殼中，每個表面都對應角色的一種表情；換裝和動畫也會透過表面的連續播放與合成呈現。

## SSTP

是 Sakura Script Transfer Protocol 的縮寫。這是一種在網路上傳送上述 Sakura Script 的機制。<br>
好像也有人稱它為「毒電波」……(^_^;)

## 伺か（Ukagaka）

讀作「うかがか」。<br>
原本是稱為桌面吉祥物的一種應用程式。<br>
不過現在，這個詞也泛指圍繞角色資料「人格」的風格或社群，包含只能在其相容應用程式（SSP 也是其中之一）上執行的內容。

## baseware

這是軟體「伺か」及其相容應用程式的總稱。SSP 也屬於其中一種。<br>
這個名稱是因為它提供人格執行時所需的基礎環境。<br>
此外，如上所述，「伺か」一詞目前含義廣泛且模糊，因此若特別指作為 baseware 的伺か，一般會稱為「MATERIA」。
