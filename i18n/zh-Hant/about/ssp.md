# SSP 基本資訊

請一併閱讀 SSP 隨附的「readme.txt」。

## 支援環境資訊

- **作業系統：**<br>
  Windows 2000 以上版本，或相當於上述環境的 Wine 相容環境
- **CPU：**<br>
  足以執行上述作業系統的規格
- **記憶體：**<br>
  約 64MB 可用空間

## 聯絡方式

### SSP BUGTRAQ

[![SSP BUGTRAQ](../assets/banners/bugtraqbanner.png)](http://ssp.shillest.net/)

<http://ssp.shillest.net/>

這是集中處理 SSP 錯誤資訊的網站（※也就是官方網站）。<br>
此處提供最新的本體。

### 待辦事項（意見回饋）

<http://ssp.shillest.net/bts/?project=ssp&action=top>

這是 SSP 的錯誤回報系統。也歡迎在此提出需求。

熟悉 GitHub 的使用者，也可以在本說明文件的 GitHub 儲存庫（[ukatech/ukadoc-ssp](https://github.com/ukatech/ukadoc-ssp)）提交 [Issue](https://github.com/ukatech/ukadoc-ssp/issues) 或 [Pull Request](https://github.com/ukatech/ukadoc-ssp/pulls)。<br>
若要指出說明文件中的錯誤或提出修改建議，透過此方式會比較方便。

### 取得舊版壓縮檔

<http://ssp.shillest.net/archive.html>

這是固定網址，除了最新版 SSP 的壓縮檔之外，也存放舊版壓縮檔。
