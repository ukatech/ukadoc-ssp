# 關於 SSPH（SSP Helper）

如果您在 SSP 資料夾或 Windows 畫面中看到不熟悉的 `SSPH.exe`，因此感到不安，請參考本頁。<br>
安裝 SSP 的資料夾中的 `data\SSPH.exe`，是協助 SSP 執行工作的輔助程式「SSPH」。它是隨 SSP 主程式（`ssp.exe`）附帶的 SSP 一部分，名稱是 **SSP Helper** 的縮寫。

SSPH 只會在 SSP 主程式等程式要求時啟動，工作結束後就會立即結束。平常並不會執行。<br>
如果您在 Windows 使用者帳戶控制（UAC）的確認畫面中看到「SSP Helper」或「SSPH.exe」而感到困惑，請參閱「[出現 UAC 確認畫面時](#uacの確認画面が出るとき)」。

## 什麼是 SSPH

- **檔案位置**<br>
  位於 `(SSPのフォルダ)\data\SSPH.exe`。
- **檔案內容**<br>
  在「詳細資料」分頁中，檔案描述為「SSP Helper」、產品名稱為「SSPH」、公司名稱為「SSP BUGTRAQ」。
- **啟動方式**<br>
  SSP 主程式、安裝程式或 Windows「已安裝的應用程式」中的解除安裝操作會指定工作內容並啟動它。您不需要自行啟動。即使不帶引數啟動，也會直接結束，不會執行任何工作。
- **顯示的畫面**<br>
  視工作內容顯示安裝畫面、進度視窗或確認訊息。除此之外不會顯示任何內容。
- **網路通訊**<br>
  SSPH 本身只會在安裝程式中選擇下載語言套件時進行網路通訊，從語言套件的發佈位置（GitHub）下載。

## SSPH 執行的工作

| 場景 | SSPH 的工作 | SSPH 是否會引發 UAC 確認畫面 |
|---|---|---|
| NTP 時間同步 | 將電腦時鐘改為伺服器時間 | 可能出現 |
| 安裝 SSP | 顯示安裝畫面，將 SSP 檔案複製到安裝位置 | 不會出現 |
| 更新 SSP 主程式 | 等待 SSP 結束，以下載的更新覆寫檔案，再重新啟動 SSP | 不會出現 |
| 取得人格更新位置 | 查詢人格的更新位置（`homeurl`） | 不會出現 |
| 解除安裝 SSP | 刪除 SSP 資料夾及登錄資訊 | 不會出現 |

SSPH.exe 本身設定為不要求系統管理員權限（`asInvoker`）。表中的「可能出現」是指僅在進行 NTP 時間同步時，SSP 主程式會要求 Windows 以系統管理員權限啟動 SSPH。

## 出現 UAC 確認畫面時

修改電腦時鐘需要 Windows 系統管理員權限。只有在進行 NTP 時間同步時，SSPH 才會出現在詢問是否允許對裝置進行變更的 UAC 確認畫面中。

### 出現的時機

- 使用右鍵選單的「功能→NTP 時間同步」，人格修正時鐘時。光是選擇選單不會出現確認畫面；在查詢伺服器完成後，人格實際修正時鐘的階段才會出現。
- 人格主動開始進行 NTP 時間同步時。人格可以透過 Sakura Script 的 `\![executesntp]` 查詢時間伺服器。連線成功後會收到 `OnSNTPCompare` 事件通知，人格可以在該事件的腳本中加入 `\6` 來修正時鐘。因此，即使沒有選擇選單，也可能在人格談話途中出現確認畫面。
- 在偏好設定中啟用「自動執行時鐘同步」時。系統會依指定的時間間隔修正時鐘，每次都可能出現確認畫面。使用已啟用 UAC 的系統管理員帳戶以一般方式啟動 SSP 時，無法選擇此設定（請參閱下方的「不會出現的情況」）。

### 如何辨識畫面

確認畫面中的程式名稱會顯示為「SSP Helper」或「SSPH.exe」。由於 SSPH.exe 沒有數位簽章，發行者會顯示為「未知」。畫面的細節會因 Windows 版本而異。

僅憑發行者顯示為「未知」，無法判斷檔案是否為正版。請透過畫面中的「顯示詳細資料」確認下列事項。

- 程式位置是您使用的 SSP 資料夾中的 `data\SSPH.exe`
- 引數以 `time` 開頭（這是進行 NTP 時間同步的指示）

詳細資料的顯示方式也會因 Windows 版本而異。如果顯示不認識的檔案，請選擇「否」。

### 選擇「是」或「否」時

- **是**<br>
  SSPH 會將電腦時鐘改為從伺服器取得的時間，然後結束。同步時也會加上確認畫面開啟期間經過的時間。SSPH 只會修改時鐘。
- **否**<br>
  時鐘不會改變，也不會影響 SSP 的其他動作。<br>
  不過，人格仍會收到「已修正時鐘」的通知（`OnSNTPCorrect` 事件）。因此，即使時鐘實際上沒有改變，人格也可能表現得像是已經修正。

### 不會出現的情況

- 以系統管理員身分執行 SSP 時。SSP 主程式會自行修改時鐘，因此不會使用 SSPH，也不會出現確認畫面。
- 使用已啟用 UAC 的系統管理員帳戶，以一般方式啟動 SSP 時。「自動執行時鐘同步」會呈灰色而無法選擇，也不會自動出現確認畫面。不過，透過選單或人格進行 NTP 時間同步時，仍會如上所述出現確認畫面。
- 使用沒有系統管理員權限的標準使用者帳戶時。您可以選擇「自動執行時鐘同步」。每次修正時鐘時，都可能出現要求輸入系統管理員密碼的畫面。

### 不想顯示確認畫面時

- 請勿使用 NTP 時間同步。較新的 Windows 會自動校準時鐘。
- 建議將「自動執行時鐘校準」設為關閉。不過，即使關閉此設定，當人格執行 NTP 時間同步時，仍可能顯示確認畫面。
- 不建議只為了避免確認畫面而以系統管理員身分執行 SSP，因為這會讓 SSP 和在其中執行的所有人格都以系統管理員權限運作。

!!! tip "ヒント"

    在此處說明以外的作業（安裝、主程式更新、取得人格的更新位置、解除安裝）中，不會因為 SSPH 而顯示 UAC 確認畫面。<br>
    如果在這些作業期間出現確認畫面，請透過「顯示詳細資料」確認即將啟動的檔案。如果是不認識的檔案，請選擇「否」。

## 各項作業的詳細運作方式

### 安裝 SSP

執行 SSP 安裝程式（自解壓縮格式的 exe）時，解壓縮後的檔案中的 `data\SSPH.exe` 會顯示安裝畫面。剛啟動安裝程式時出現的「要安裝 SSP 嗎？」確認訊息，是由自解壓縮部分顯示的，並非 SSPH 的畫面。

- **安裝位置**<br>
  如果已有註冊檔案關聯的 SSP，預設會填入該 SSP 的資料夾。否則為 `%LOCALAPPDATA%\Programs\SSP`。
- **可選項目**<br>
  包括開始功能表捷徑、檔案關聯、桌面捷徑及下載語言套件。預設會啟用開始功能表捷徑和檔案關聯，停用桌面捷徑。如果有符合您使用語言的語言套件，則會啟用下載。
- **受 UAC 保護的資料夾**<br>
  由於在 `Program Files` 或 `Windows` 資料夾底下寫入檔案需要系統管理員權限，因此無法將其選為安裝位置。請選擇其他資料夾（例如：`C:\Users\ユーザー名\SSP`）。
- **包含 SSP 以外檔案的資料夾**<br>
  如果選擇的資料夾已有檔案，卻沒有 `ssp.exe` 和 `data\SSPH.exe`，就會顯示確認畫面。這是因為解除安裝時，資料夾中的所有資料都會被刪除。

安裝完成後，會啟動 SSP。

### 更新 SSP 主程式

SSP 更新會在下載完成後立即套用，或在下次啟動 SSP 時，套用事先下載並保留的更新。此時，SSP 主程式會將 `data\SSPH.exe` 複製為 `data\SSPH2.exe` 並啟動，然後自行結束。由於 SSP 執行時無法覆寫主程式，`SSPH2.exe` 會等到 SSP 結束後才開始作業。

`SSPH2.exe` 會顯示「正在更新 SSP...」視窗，並以覆寫方式解壓縮下載的更新。接著會刪除下載的檔案並重新啟動 SSP，重新啟動的 SSP 則會刪除 `SSPH2.exe`。

更新步驟請參閱「[更新主程式版本](../howto/verup.md)」。

### 取得人格的更新位置

當 SSP 需要知道人格的更新位置（`homeurl`）時，有時會交由 SSPH 查詢。SSPH 會依下列方式查詢：

1. 讀取人格的 `ghost\master` 資料夾中的字典檔等檔案，尋找 `homeurl` 的記述。
2. 如果找不到，則暫時載入人格的 SHIORI，取得 `homeurl` 的資源。

此作業會在 SSP 主程式以外的處理程序中執行，最多等待 2 分鐘。這段期間即使開啟對話視窗，也會自動關閉。<br>
SSPH 啟動期間，SSP 主程式會暫時變更人格資料夾中執行檔的名稱（不包括以 `perl`、`php`、`lisp` 開頭的檔案，例如將 `xxx.exe` 改為 `xxx_exe`）。這段期間無法啟動這些執行檔。SSPH 結束後，會將名稱還原。

### 解除安裝 SSP

啟用檔案關聯時，Windows 的「已安裝的應用程式」（「程式和功能」）中會註冊「SSP」。從這裡移除時，SSPH 會執行解除安裝。

1. 如果 SSP 正在執行，會提示先結束 SSP，然後不做任何處理便結束。
2. 顯示「人格等所有資料都將被刪除」的確認畫面。選擇「是」後會繼續。
3. 由於無法刪除位於 SSP 資料夾中的 SSPH 自身，會在暫存資料夾（`%TEMP%\SSPHUninstall.exe`）建立並啟動自身的複本。
4. 複本會移除捷徑和檔案關聯等註冊項目，並刪除 SSP 資料夾中的所有內容（會顯示進度視窗）。
5. 最後顯示完成訊息。

如果 SSP 資料夾位於磁碟機根目錄（如 `C:\`），為了避免刪除磁碟機的內容，不會刪除任何資料。<br>
SSP 資料夾中的所有內容都會被刪除，包括人格資料和備份。請事先將想保留的內容移至其他位置。

`SSPHUninstall.exe` 會被排定在 Windows 重新啟動時刪除。如果無法排定，可能會留在暫存資料夾中。若有殘留，可以自行刪除。

## 如何確認是否為正版

與 SSP 有關的 SSPH 只有以下 3 個名稱。

- `SSPH.exe`：位於 SSP 資料夾中的 `data` 資料夾。執行安裝程式時，會執行解壓縮後的暫存資料夾中 `data` 資料夾內的檔案。
- `SSPH2.exe`：僅在主程式更新期間，會在同一個 `data` 資料夾中產生。
- `SSPHUninstall.exe`：解除安裝期間，會在 Windows 暫存資料夾中產生。

名稱或位置與上述不同的 SSPH，可能不是 SSP 的檔案。此外，內容視窗中顯示的資訊可以被修改，請優先確認檔案位置。<br>
如果有疑慮，請將手邊的檔案與從 [SSP BUGTRAQ](ssp.md#ssp-bugtraq) 取得的 SSP 中的 `data\SSPH.exe` 比較。
