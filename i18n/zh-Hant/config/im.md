# 設定：IM

本頁說明在右鍵選單的「設定」子選單中，點選「偏好設定」後開啟的對話方塊裡，「IM」頁面的內容。

這裡可以設定 SSP 獨有的即時通訊功能，使用 SSTP 或 IP Messenger。

## 各項目說明

- **名稱**<br>
  請輸入您在即時通訊中使用的名稱，例如您的暱稱。　
- **群組**<br>
  即時通訊中使用的群組名稱。
- **使用 SSTP 時不進行轉換**<br>
  透過 SSTP 通訊傳送 Sakura Script 時，會忽略名為「轉換」的人格內部文字轉換機制，直接播放 Sakura Script。一般情況下不需要勾選。
- **傳送後清除訊息對話方塊**<br>
  傳送訊息後，清除訊息輸入欄中輸入的文字。
- **使用 IP Messenger 相容模式**<br>
  設定為可使用 IP Messenger 傳送及接收訊息。
- **連接埠號碼**<br>
  設定 IP Messenger 使用的連接埠號碼。<br>
  一般情況下不需要設定。　
- **撥接連線**<br>
  在無法傳送廣播的環境中使用 IP Messenger 功能時，請設定此選項。一般情況下維持關閉即可。

### 指定廣播／多點傳播目的地

指定要傳送登入、登出訊息等的 IP 位址。<br>
一般情況下，請指定稱為「廣播位址」或「多點傳播位址」的位址，這些位址可向同一網段中的電腦同時傳送訊息。

標準設定為 255.255.255.255。如果這樣就能正常運作，則不需要變更。

## 下方按鈕

- **說明**<br>
  開啟偏好設定對話方塊中目前設定頁面的說明（也就是本頁）。<br>
  對話方塊右上角的「？」圖示也有相同功能。
- **關閉**<br>
  關閉偏好設定對話方塊。<br>
  對話方塊右上角的「×」圖示也有相同功能。
