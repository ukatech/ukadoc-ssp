# 設定：外部應用程式

本頁說明在右鍵選單的「設定」子選單中，透過「偏好設定」開啟的對話方塊裡，「外部應用程式」頁面的內容。

本頁可設定從 SSP 啟動的應用程式。

這裡可設定 SSP 視需要啟動的應用程式。通常會自動判斷預設設定等，因此不一定需要設定。

## 各項目說明

### 瀏覽器設定

設定在「推薦」等項目中參照 URL 時所使用的瀏覽器。<br>
如果想特別使用其他瀏覽器，請在此設定。<br>
一般來說，欄位空白時會使用系統設定的預設瀏覽器（＝大多數情況下為 Internet Explorer），因此通常不需要特別設定。

### 檔案管理器設定

設定在資源管理器的右鍵選單執行「開啟」等操作時，需要檔案管理軟體時所啟動的軟體。<br>
一般來說，欄位空白時會啟動 Windows Explorer，因此不需要特別設定。

### 編輯器設定

設定從人格開啟文字檔時所使用的應用程式。<br>
一般來說，欄位空白時會使用記事本等系統預設的應用程式，因此通常不需要特別設定。

**引數**：可指定傳遞給編輯器的引數。<br>
%1會替換為檔案名稱（完整路徑），%2會替換為開啟檔案時選取的行（數值）。

### 郵件軟體設定

設定從人格啟動郵件軟體或收到建立新郵件的指令時所使用的郵件軟體。<br>
一般來說，欄位空白時會使用系統設定的預設郵件軟體，因此通常不需要特別設定。

**引數**：可指定僅在寄送新郵件時使用的引數。設定收到建立新郵件的指令時，要以何種格式將電子郵件地址傳遞給郵件軟體。各郵件軟體的設定方式不同，請參閱各自的說明文件。

另外，%1的部分會替換為「"mailto:地址"」。

EdMax的範例：　/A="%1"<br>
Becky!Ver2的範例：　"%1"<br>
Outlook Express的範例：　/mailurl:%1

### 版本管理工具

從 SSP 執行 Subversion 或 Git，就能以和更新一般人格相同的操作來更新版本管理工具。<br>
在此可手動選擇要使用的工具。<br>
通常會自動搜尋，因此不需要設定。

- **Subversion**<br>
  欄位空白時，會自動搜尋 TortoiseSVN。
- **Git**<br>
  欄位空白時，會自動搜尋 TortoiseGit。

**備註**：<br>
※瀏覽器和郵件軟體欄位皆空白時，會使用「網際網路」控制台中的設定。<br>
※檔案管理器欄位空白時，會使用 Windows 檔案總管。<br>
※編輯器欄位空白時，會依照 .txt 檔案關聯設定。一般來說是記事本。

## 下方按鈕

- **說明**<br>
  開啟偏好設定對話方塊中目前設定頁面的說明（也就是本頁）。<br>
  對話方塊右上角的「？」圖示也有相同功能。
- **關閉**<br>
  關閉偏好設定對話方塊。<br>
  對話方塊右上角的「×」圖示也有相同功能。
