# 設定：顯示

本頁說明如何設定在右鍵選單的「設定」子選單中，選擇「偏好設定」後開啟的對話方塊之「顯示」頁面。

本頁可設定畫面顯示相關項目。

## 各項目說明

- **不變更游標（從下次載入人格起生效）**<br>
  開啟後，即使對話方塊附有滑鼠游標，也不會變更游標。<br>
  如果不希望對話方塊變更滑鼠游標，請開啟此選項。
- **桌面底部偏移（通常設為 0 即可）**<br>
  指定與桌面底部相差幾個點。<br>
  例如，設定「自動隱藏工作列」時，可避免人格被工作列遮住。
- **讓選單寬度配合背景圖片**<br>
  一般來說，選單寬度只會依選單項目的寬度顯示；開啟此選項後，選單寬度會配合人格所附的選單圖片。<br>
  這樣便能顯示完整的人格選單圖片。
- **選取選單時顯示預覽圖片**<br>
  在右鍵選單中選取切換人格、呼叫人格、切換外殼、切換對話方塊等項目時，若支援此功能，便會顯示預覽圖片（thumbnail.png）。<br>
  在 \[—\] 狀態下只會顯示選單；在 \[✓\] 狀態下，除了選單之外，也會在資源管理器中將滑鼠停在項目上時顯示預覽圖片。
- **設定選單的垂直間距（預設為 2）**<br>
  設定右鍵選單各列之間的間距。<br>
  與 Windows 選單相同的間距為 2，您也可以視需要調整，讓選單更容易閱讀。
- **將部分選單分層顯示**<br>
  在[設定：資料夾](folder.md)中設定載入多個資料夾時，開啟此選項後，選單會依資料夾分類。<br>
  此設定會套用至人格、對話方塊等所有可設定資料夾的選單。<br>
  如果安裝了許多人格，想要分類顯示時，可以使用此選項。
- **人格、對話方塊選單的字數上限（5-255）**<br>
  這項設定可避免部分名稱較長的人格讓選單塞滿畫面。超過此處設定的字數時，名稱末尾會加上「...」並以省略方式顯示。<br>
  如果畫面較窄，建議將字數上限設低一些。
- **最近使用項目的記錄數上限（2-255）**<br>
  設定「最近使用項目」中保留的歷史記錄數。超出此數量的較早啟動／使用項目會逐漸移除。
- **Flip3D 時也顯示（Vista 以上）**<br>
  使用 Flip3D 切換視窗時，仍會顯示角色與對話方塊。如果希望隨時都能看到角色，請使用此選項。
- **在工作列顯示角色視窗**<br>
  一般來說，顯示角色的視窗不會出現在工作列中；但在 Windows 7 以上版本中，如果想使用跳躍清單或預覽功能，有時會需要顯示在工作列中。<br>
  開啟此選項後，即可使用上述功能。
- **啟動全螢幕應用程式時最小化**<br>
  啟動遊戲等以全螢幕顯示的應用程式時，自動以最小化狀態顯示人格。
- **在所有虛擬桌面顯示角色視窗（Win10 以上）**<br>
  不論 Windows 10 以上版本的新功能「虛擬桌面」目前切換至哪個桌面，都會在所有虛擬桌面上顯示角色。
- **點擊角色時，也將角色以外的視窗移至最前方**<br>
  資源管理器或記錄視窗等不屬於特定角色顯示的視窗，也會在點擊時一併移至最前方。<br>
  視窗可能會被其他視窗遮住而難以找到，因此通常請保持開啟。
- **支援高 DPI \[需要重新啟動 SSP\]**<br>
  改善 SSP 在高 DPI 環境下的顯示效果。變更此設定後，需要重新啟動 SSP。
- **自動將畫面外的視窗移至畫面內**<br>
  當螢幕解析度變更、螢幕電源關閉，或目前螢幕配置與上次啟動時不同時，會自動將外殼移至可用螢幕範圍內。<br>
  關閉此設定可能有助於解決多螢幕環境中的各種問題，但視窗移出畫面時，必須手動重設位置。

### 半透明視窗

這項設定可使用 Windows 2000 以上版本推出的半透明視窗功能，也稱為「Layered Window」。<br>
若可使用此功能，預設會啟用。

- **使用交叉淡化**<br>
  角色表情切換，或對話方塊等項目顯示／隱藏切換時，會使用逐漸切換的淡入、淡出效果。
- **拖曳時提高透明度**<br>
  拖曳角色視窗時，會降低不透明度，讓視窗下方的內容更容易看見。
- **（本體／對話方塊／行事曆的透明度設定）**<br>
  拖曳滑桿即可調整各視窗的透明度。

## 下方按鈕

- **說明**<br>
  開啟偏好設定對話方塊中目前設定頁面的說明（也就是本頁）。<br>
  對話方塊右上方的「？」圖示也有相同功能。
- **關閉**<br>
  關閉偏好設定對話方塊。<br>
  對話方塊右上方的「×」圖示也有相同功能。
