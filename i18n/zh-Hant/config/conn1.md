# 設定：連線(1)

本頁說明透過右鍵選單的「設定」子選單中的「偏好設定」開啟的對話方塊裡，「連線(1)」頁面的設定。

本頁可設定網路連線相關選項。

基本上，此處通常不需要特別設定，但從防火牆內部的電腦進行線上更新等操作時，可能需要設定。

!!! tip "ヒント"

    其中也有一些針對如今已不常見的連線環境所設計的設定，算是歷史的痕跡。

## 各項設定說明

### 一般

- **使用的網路通訊協定**<br>
  設定如何使用 IPv4、IPv6。<br>
  通常保留 \[Auto\] 即可。<br>
  IPv4=>IPv6、IPv6=>IPv4 分別會依照前者=>後者的順序嘗試名稱解析等操作。
- **驗證 SSL/TLS 通訊的伺服器憑證**<br>
  通常請保持開啟。只有在與支援 SSL 等協定的伺服器通訊發生問題時，才暫時嘗試關閉。<br>
  郵件檢查器(POP3S)等功能可以[另行設定](pop.md)，不需要在此設定。

### Proxy 伺服器設定

- **自動使用 Windows 設定**<br>
  使用 Internet Explorer 的 Proxy 設定。<br>
  如果不清楚設定內容，建議保持勾選。
- **透過 Proxy 伺服器**<br>
  如果知道 Proxy 伺服器，請在下方欄位輸入伺服器名稱和連接埠號碼並勾選此項，線上新聞感應器等功能便會透過 Proxy 伺服器取得資料。
- **使用者名稱／密碼**<br>
  設定需要使用者驗證的快取伺服器之使用者名稱與密碼。可以留空。

### 網路連線詢問

- **未連線至網路時**<br>
  僅適用於撥接連線環境；勾選後會監視連線狀態，自動控制網路連線。<br>
  請勿在其他環境中使用。
- **在以下時段內一律**<br>
  開啟後，會禁止在指定時段內自動連線至網路，例如在電話優惠時段以外的時間自動取得線上新聞。<br>
  但如果您自行指示取得線上新聞，或人格指示檢查郵件，仍會顯示對話方塊確認是否連線。

### 時鐘校正

指定執行 NTP 時間同步時使用的 SNTP/HTTP 伺服器。<br>
不特別指定、保留 \[RANDOM\] 設定也能運作，因此除非有無法正常運作等原因，否則建議保持不變。

- **SNTP 伺服器 / HTTP 伺服器**<br>
  選擇 NTP 時間同步使用的伺服器類型。<br>
  使用 HTTP 同步時間的精度不太高，請僅在防火牆內部等無法使用 SNTP 的情況下使用。
- **自動執行時鐘校正**<br>
  以指定的時間間隔自動執行時鐘校正。間隔以小時為單位設定。<br>
  使用啟用 UAC 的管理員帳戶一般方式啟動 SSP 時，無法選擇此項。使用標準使用者帳戶時，每次校正時鐘都可能出現確認畫面（UAC）。即使關閉此設定，人格執行 NTP 時間同步時也可能出現確認畫面。詳情請參閱「[關於 SSPH（SSP Helper）](../about/ssph.md#uacの確認画面が出るとき)」。

## 下方按鈕

- **說明**<br>
  開啟偏好設定對話方塊中目前設定頁面的說明（也就是本頁）。<br>
  對話方塊右上角的「？」符號也有相同功能。
- **關閉**<br>
  關閉偏好設定對話方塊。<br>
  對話方塊右上角的「×」符號也有相同功能。
