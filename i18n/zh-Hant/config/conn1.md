# 設定：連線(1)

本頁說明在右鍵選單的「設定」子選單中，選擇「偏好設定」後開啟的對話方塊裡，「連線(1)」頁面的內容。

本頁可設定網路連線相關項目。

通常不需要特別設定此區域，但如果要從防火牆內部的電腦執行線上更新等作業，有時就需要進行設定。

!!! tip "ヒント"

    此處也有一些如今幾乎看不到的連線環境設定項目，請感受一下歷史的痕跡。

## 各項目說明

### 一般

- **使用的網路通訊協定**<br>
  設定 IPv4、IPv6 的使用方式。<br>
  通常維持\[Auto\]即可。<br>
  IPv4=>IPv6、IPv6=>IPv4 會分別依照前者=>後者的順序嘗試名稱解析等作業。
- **在 SSL/TLS 通訊中驗證伺服器憑證**<br>
  通常請保持啟用。只有在與支援 SSL 等功能的伺服器通訊時發生問題，才請暫時停用。<br>
  另外，郵件檢查器(POP3S)等可[另外設定](pop.md)，不必在此處設定。

### Proxy 伺服器設定

- **自動使用 Windows 設定**<br>
  使用 InternetExplorer 的設定作為 Proxy 設定。<br>
  如果不清楚設定內容，建議一律勾選此選項。
- **透過 Proxy 伺服器連線**<br>
  如果知道 Proxy 伺服器資訊，請在下方欄位輸入 Proxy 伺服器名稱與連接埠號碼，再勾選此選項，線上新聞感應器等就會透過 Proxy 伺服器取得資料。
- **使用者名稱／密碼**<br>
  設定需要使用者驗證的快取伺服器之使用者名稱與密碼。留空即可。

### 網路連線詢問

- **未連線至網際網路時**<br>
  只有在撥接環境中，勾選後才會監控連線狀態並自動控制網路連線。<br>
  請勿在其他環境中使用。
- **以下時間範圍內一律**<br>
  啟用後，在指定的時間範圍內，會禁止自動連線至網路，例如在電話費優惠時段以外執行線上新聞感應等作業。<br>
  不過，如果您自行要求執行線上新聞感應，或人格要求檢查郵件，系統會顯示對話方塊，詢問是否連線。

### 時鐘同步

指定時鐘同步時使用的 SNTP/HTTP 伺服器。<br>
不指定伺服器、維持\[RANDOM\]設定也可以正常運作，因此除非遇到無法正常運作等問題，建議維持原設定。

- **SNTP 伺服器 / HTTP 伺服器**<br>
  選擇時鐘同步使用的伺服器類型。<br>
  使用 HTTP 進行時鐘同步的精確度不高。只有在防火牆內部等無法使用 SNTP 的情況下，才請使用此功能。
- **自動執行時鐘同步**<br>
  依指定的時間間隔自動執行時鐘同步。間隔可用小時為單位設定。

## 下方按鈕

- **說明**<br>
  開啟偏好設定對話方塊中目前設定頁面的說明（也就是本頁）。<br>
  對話方塊右上角的「？」圖示也有相同功能。
- **關閉**<br>
  關閉偏好設定對話方塊。<br>
  對話方塊右上角的「×」圖示也有相同功能。
