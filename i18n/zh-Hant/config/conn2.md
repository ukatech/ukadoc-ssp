# 設定：連線(2)

本頁說明透過右鍵選單的「設定」子選單中「偏好設定」項目開啟的對話方塊裡，「連線(2)」頁面的內容。

本頁可設定網路連線相關選項。

## 各項目說明

### 線上新聞

- **自動檢查**<br>
  若要定時自動檢查線上新聞，請開啟此選項。間隔可按分鐘設定。
- **手動執行線上新聞時更新自動巡查起始位置**<br>
  在自動檢查功能中，將下次執行的線上新聞設為手動執行項目的下一項。<br>
  關閉此功能時，每次都會從上到下依序巡查。
- **指定更新時播放的音效**<br>
  指定檢查線上新聞發現更新時要播放的音效。　

### SSTP 通訊

設定 SSP 接收 SSTP 所使用的連接埠。<br>
清單中 IPv4 和 IPv6 至少有一種啟用的連接埠，會用來監聽 SSTP。<br>
預設情況下，9801 和 9821 連接埠的 IPv4、IPv6 均為 Local（僅限此電腦內部），11000 連接埠則為停用。

清單左欄是連接埠號碼，右欄是狀態。狀態會顯示以下內容。

- 接收設定類型（Local、Global、Custom）。停用的連接埠會顯示「Disabled」。
- 監聽失敗時，會在「Error:」（部分失敗時為「Partial:」）後面顯示原因。原因包括「invalid address」（位址格式不正確）、「port in use」（連接埠已被其他程式使用）、「address not available」（此電腦沒有該位址）、「no address in range」（沒有符合範圍的位址）等。
- 監聽的 IP 版本（如 `[IPv4+IPv6]`），以及類型為 Custom 時指定的位址。

最左側的圖示會依接收設定類型（Global、Local、Custom）區分，也會依監聽成功、部分成功或失敗而改變。停用的連接埠有專用圖示。

- **新增...**<br>
  新增連接埠。會開啟 [SSTP 連接埠設定](#sstpポートの設定)對話方塊。
- **刪除**<br>
  刪除清單中選取的連接埠。
- **編輯...**<br>
  變更清單中選取的連接埠設定。連按兩下清單中的連接埠也有相同效果。
- **按右鍵**→**重試監聽（Retry Listen）**<br>
  這是在清單中的連接埠上按右鍵後顯示的選單，可重新監聽該連接埠。<br>
  可用於重試監聽失敗的連接埠，或在此電腦的位址因 DHCP 等原因變更後，重新取得以範圍（CIDR）指定之連接埠的監聽位址。

使用啟動選項 `--sstp-listen` 啟動時，清單僅供檢視，無法新增、刪除或編輯（僅可使用重試監聽）。

!!! tip "ヒント"
    選擇 Global，或在自訂設定中指定 Local 以外的位址時，也會接收來自其他電腦的 SSTP。請僅在可信任的網路中使用。<br>
    自 2.9.40 起，在 Global 連接埠上，與 SSTP 使用相同連接埠接收的 HTTP 請求（所有路徑，包括測試頁面、MCP、對 `/api/sstp/v1` 的 POST 等透過 HTTP 傳送的 SSTP），只允許來自本機（`127.0.0.1` 和 `::1`）及 LAN（此電腦網路介面卡所配置的網路範圍內，包含同一鏈路上的 `fe80::/10` 和 `169.254.0.0/16`）的連線。其他來源（網際網路端）會收到 `403`。自訂連接埠則依指定的位址設定運作，不限制連線來源。一般 SSTP（不使用 HTTP 的 SSTP）不受此限制。

- **記錄 SSTP 日誌**<br>
  將 SSTP 通訊收到的腳本和事件內容寫入名為 `log\SSTP.log` 的檔案。<br>
  有些人格會使用此日誌來改變談話內容，請視需要開啟。<br>
  點擊後會顯示指定日誌最大 KB 數的畫面。請輸入要設定的日誌大小上限。
- **讓未啟動的人格也顯示為已啟動**<br>
  為了讓其他支援 SSTP 的軟體使用，會將資訊寫入特定區域，讓未啟動的人格看起來也像已啟動。<br>
  若不啟用此設定，「盡可能由指定人格播放」可能無法運作。
- **不因附帶選項的 SSTP 而封鎖**<br>
  通常收到附帶選項的 SSTP 時，為了將所選選項傳回傳送端，在選擇選項之前，即使收到其他 SSTP 也不會播放。<br>
  這是規格上的問題，但若因選項而封鎖會造成困擾（例如播放 SSTP Bottle 時），可開啟此選項來改變行為。<br>
  但如此一來，以會傳回選項為前提進行處理的工具將無法運作，請務必謹慎使用。
- **完全停用人格內的 SSTP 篩選處理**<br>
  某些人格可能設定為完全阻擋外部 SSTP，或忽略不含特定指定內容的 SSTP，因此不會說出 SSTP 的內容。<br>
  開啟此功能可停用所有這類設定，但這會無視作者防止角色形象走樣的意願，請仔細考量後再啟用。
- **啟動人格**<br>
  指定 SSTP 通訊中收到啟動特定人格的指示時要採取的動作。<br>
  一般設定為僅在透過 SSP 即時通訊收到指示時啟動\[僅即時通訊\[SSTP/1.5\]\]。<br>
  效能較低的電腦強烈建議選擇「一律不啟動」。<br>
  效能較充裕的電腦選擇「盡可能由指定人格播放」會更熱鬧（但也會變得較不穩定）。
- **啟動後的處理**<br>
  指定依照上述設定暫時啟動的人格要在何時關閉。
- **暫時啟動人格的最大數量**<br>
  指定透過 SSTP 暫時啟動的人格數量上限。<br>
  超過此數量時，會依序關閉較早啟動的人格。
- **暫時啟動人格的最短啟動間隔**<br>
  指定透過 SSTP 暫時啟動人格的間隔。<br>
  若一次收到大量要求，在距離前一個要求未達此處設定的秒數時，會回傳 409 Conflict，且不會啟動人格。<br>
  此設定僅在必須暫時啟動人格時適用。若無須啟動，則會立即接受要求。

### SSTP 連接埠設定

這是透過 SSTP 通訊的「新增...」「編輯...」開啟的對話方塊。每個連接埠可設定下列項目。

- **連接埠號碼**<br>
  要監聽的連接埠號碼。請指定 1〜65535。<br>
  不能使用與其他連接埠相同的號碼。<br>
  在 2.9.39 以前，若兩者都是自訂設定，且指定的位址不重疊，就能並列使用相同號碼。從 2.9.40 起，即使都是自訂設定，也不能使用相同號碼（因為自訂設定也會監聽迴路位址，詳見下文）。如果先前的設定中有多個相同號碼的自訂設定，只會載入最先記載的 1 筆。
- **IPv4・IPv6**<br>
  要監聽的 IP 版本。如果兩者都取消勾選，該連接埠就會停用，不再監聽。
- **接收設定**<br>
  選擇要接受來自哪些來源的 SSTP。

  - **本機（僅限此電腦）**<br>
    只接受來自此電腦內部（127.0.0.1 和 ::1）的 SSTP。這是預設設定。
  - **全域（全部允許）**<br>
    監聽所有位址，也接受來自其他電腦的 SSTP。
  - **自訂**<br>
    監聽指定的位址。只有選擇自訂時，才能在下方的位址欄位中輸入。<br>
    從 2.9.40 起，如果位址欄位不包含迴路位址（`127.0.0.1` 和 `::1`），勾選的 IPv4・IPv6 版本也會自動監聽迴路位址（不會顯示在位址欄位中，也不需要自行加入）。這是為了讓本機透過 `localhost` 傳送的通訊能夠連入。如果指定的範圍已包含迴路位址，例如 `0.0.0.0`、`::` 或 `127.0.0.0/8`，則不會額外加入。

    - 請以數字位址指定（不能使用主機名稱）。可用逗號分隔，指定多個位址。例如：`192.168.0.5, ::1`
    - 也可以像 `192.168.192.0/24` 這樣指定範圍（CIDR）。指定範圍後，會監聽目前指派給此電腦、且位於該範圍內的所有位址。即使在 DHCP 會變更位址的環境中，只要指定範圍，重新啟動 SSP，或在清單上按右鍵選擇「Retry Listen」（重新嘗試監聽）重新監聽，就能監聽新位址。<br>
      `127.0.0.0/8` 屬於迴路位址。當前綴長度為位址的最大值（IPv4 為 32、IPv6 為 128）時，等同於單一位址。
    - 只有勾選指定的位址所屬版本（IPv4・IPv6）時，才會使用該位址。例如，若未勾選 IPv4，就不會使用 IPv4 位址。
    - 即使指定的位址格式不正確、位址不存在於此電腦上，或指定的範圍不包含此電腦的任何位址，設定仍會儲存。此時監聽會失敗，清單中會顯示錯誤。如果格式不正確，則包括迴路位址在內，所有位址都不會監聽。
    - 如果指定的位址都無法使用（例如與勾選的版本不符），就只會監聽迴路位址，清單中會顯示「Partial: no usable protocol」。
- **此電腦的網路**<br>
  這是自訂位址欄位下方的唯讀欄位。會以逗號分隔的 CIDR 格式，顯示目前指派給此電腦的位址所屬網路，例如 `192.168.192.0/24, 2001:db8:1::/64`。若無法得知前綴長度，則只顯示位址。<br>
  可以選取並複製，直接貼到位址欄位中。

## 下方的按鈕

- **說明**<br>
  開啟偏好設定對話方塊中目前設定頁面的說明（也就是本頁）。<br>
  對話方塊右上角的「？」符號也有相同功能。
- **關閉**<br>
  關閉偏好設定對話方塊。<br>
  對話方塊右上角的「×」符號也有相同功能。
