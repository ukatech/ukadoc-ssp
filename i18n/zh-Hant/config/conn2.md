# 設定：連線(2)

本頁說明從右鍵選單的「設定」子選單中選擇「偏好設定」後開啟的對話框中，「連線(2)」頁面的內容。

此頁面可設定網路連線相關選項。

## 各項目說明

### 線上新聞

- **自動檢查**<br>
  若要定期自動檢查線上新聞，請開啟此選項。間隔可以分鐘為單位設定。
- **手動執行線上新聞時更新自動巡覽的起始位置**<br>
  使用自動檢查功能時，將下次執行的線上新聞設為手動執行項目的下一項。<br>
  若停用此功能，每次都會從最上方開始依序巡覽。
- **指定更新時播放的音效**<br>
  指定檢查線上新聞時發現更新所要播放的音效。　

### SSTP 通訊

設定 SSP 接收 SSTP 的連接埠。<br>
清單中的連接埠只要啟用了 IPv4 或 IPv6 的至少一種，就會用來監聽 SSTP。<br>
預設情況下，9801 和 9821 連接埠的 IPv4、IPv6 均為 Local（僅限本機），11000 連接埠則為停用。

清單左欄是連接埠號碼，右欄是狀態。狀態會顯示下列內容。

- 接收設定類型（Local、Global、Custom）。停用的連接埠會顯示「Disabled」。
- 監聽失敗時，會在「Error:」（部分失敗時為「Partial:」）後顯示原因，例如「invalid address」（位址格式不正確）、「port in use」（連接埠已被其他程式使用）、「address not available」（此電腦沒有該位址）、「no address in range」（沒有符合範圍的位址）等。
- 監聽的 IP 版本（例如 `[IPv4+IPv6]`），以及選擇 Custom 時指定的位址。

最左側的圖示也會依接收設定類型（Global、Local、Custom）及監聽成功、部分成功或失敗而變化。停用的連接埠則有專用圖示。

- **新增...**<br>
  新增連接埠。會開啟 [SSTP 連接埠設定](#sstpポートの設定)對話框。
- **刪除**<br>
  刪除清單中選取的連接埠。
- **編輯...**<br>
  變更清單中選取的連接埠設定。也可以按兩下清單中的連接埠執行相同操作。
- **按右鍵**→**Retry Listen**<br>
  這是對清單中的連接埠按右鍵後顯示的選單項目，可重新監聽該連接埠。<br>
  可用於重試監聽失敗的連接埠，或在此電腦的位址因 DHCP 等原因變更後，重新取得以範圍（CIDR）指定之連接埠的監聽位址。

使用啟動選項 `--sstp-listen` 啟動時，清單僅供檢視，無法新增、刪除或編輯（只有 Retry Listen 可以使用）。

!!! tip "ヒント"
    若指定 Global，或以 Custom 指定 Local 以外的位址，也會接收來自其他電腦的 SSTP。請僅在可信任的網路中使用。

- **記錄 SSTP 日誌**<br>
  將透過 SSTP 通訊收到的腳本及事件內容寫入名為 `log\SSTP.log` 的檔案。<br>
  有些人格會利用此日誌變更談話內容，請視需要開啟。<br>
  按一下後會顯示指定日誌大小上限（KB）的畫面。請輸入日誌大小上限的數值。
- **讓未啟動的人格也顯示為已啟動**<br>
  為了讓其他支援 SSTP 的軟體認為未啟動的人格也已啟動，會在特定區域寫入相關資訊。<br>
  若未啟用此設定，「盡可能以指定人格播放」可能無法運作。
- **不因帶有選項的 SSTP 而封鎖**<br>
  通常收到帶有選項的 SSTP 時，為了將所選選項回傳給傳送端，在選擇選項之前，即使收到其他 SSTP 也不會播放。<br>
  這是規格上的限制；若選項造成的封鎖會帶來不便（例如播放 SSTP Bottle），可以開啟此選項來變更行為。<br>
  但在此情況下，假設一定會收到選項回傳的工具將無法運作，使用時請特別注意。
- **完全停用人格內的 SSTP 篩選處理**<br>
  某些人格設定為完全封鎖外部 SSTP，或忽略不符合特定條件的 SSTP，因此可能不會說出 SSTP 的內容。<br>
  開啟此功能可以停用所有這類限制，但這會忽視作者為避免角色形象走樣的意圖，請充分考量後再啟用。
- **啟動人格**<br>
  指定 SSTP 通訊中收到啟動特定人格的指示時，應採取的動作。<br>
  預設僅會依 SSP 即時通訊傳來的指示啟動人格\[僅限即時通訊\[SSTP/1.5\]\]。<br>
  效能較低的電腦強烈建議選擇「完全不啟動」。<br>
  效能充足的電腦選擇「盡可能以指定人格播放」會更熱鬧（但也可能變得不穩定）。
- **啟動後的處理**<br>
  指定關閉由上述設定暫時啟動的人格的時機。
- **暫時啟動人格的數量上限**<br>
  指定透過 SSTP 暫時啟動的人格數量上限。<br>
  超過此數量時，會從先前啟動的人格開始依序關閉。
- **暫時啟動人格的最短啟動間隔**<br>
  指定透過 SSTP 暫時啟動人格的間隔。<br>
  一次收到大量要求時，若距離前一個要求尚未經過此處設定的秒數，便會回傳 409 Conflict，不會啟動人格。<br>
  此設定僅在必須暫時啟動人格時適用。若不需要啟動，則會立即接受要求。

### SSTP 連接埠設定

這是透過 SSTP 通訊的「新增...」「編輯...」開啟的對話框。可針對單一連接埠設定下列項目。

- **連接埠號碼**<br>
  要監聽的連接埠號碼，請指定 1〜65535。<br>
  不能使用與其他連接埠相同的號碼。不過，使用 Custom 且指定的位址不重複時，可以並列使用相同號碼。
- **IPv4・IPv6**<br>
  要監聽的 IP 版本。取消勾選兩者後，該連接埠就會停用（不進行監聽）。
- **接收設定**<br>
  選擇要接收來自哪些來源的 SSTP。

  - **Local (僅限本機)**<br>
    僅接收來自此電腦內部（127.0.0.1 和 ::1）的 SSTP。這是預設設定。
  - **Global (全部允許)**<br>
    監聽所有位址，也會接收來自其他電腦的 SSTP。
  - **自訂**<br>
    僅監聽指定的位址。下方的位址欄位只有選擇自訂時才能輸入。

    - 請以數字位址指定（不能使用主機名稱）。可以逗號分隔來指定多個位址。例：`192.168.0.5, ::1`
    - 也可以像 `192.168.192.0/24` 這樣指定範圍（CIDR）。指定範圍後，會監聽目前指派給此電腦的位址中，所有位於該範圍內的位址。即使在位址會因 DHCP 而變更的環境中，只要指定範圍並重新監聽（重新啟動 SSP，或在清單中按右鍵選擇「Retry Listen」），就能使用新位址。<br>
      `127.0.0.0/8` 屬於迴路位址。前綴長度為該位址的最大值（IPv4 為 32、IPv6 為 128）時，與單一位址相同。
    - 只有勾選了指定地址的版本（IPv4・IPv6），才會使用該位址。例如，未勾選 IPv4 時，就不會使用 IPv4 位址。
    - 即使指定格式不正確的位址、此電腦沒有的位址，或不包含此電腦位址的範圍，設定仍會儲存。此時監聽會失敗，清單中會顯示錯誤。
- **此電腦的網路**<br>
  這是自訂位址欄位下方無法輸入的欄位。會以逗號分隔的 CIDR 格式顯示目前指派給此電腦的位址所屬網路，例如 `192.168.192.0/24, 2001:db8:1::/64`。無法得知範圍長度時，僅顯示位址。<br>
  可以選取並複製，直接貼到位址欄位。

## 下方按鈕

- **說明**<br>
  開啟偏好設定對話框中目前設定頁面的說明（也就是本頁）。<br>

- **關閉**<br>
  關閉偏好設定對話框。<br>
  對話框右上角的「×」標記也有相同作用。
