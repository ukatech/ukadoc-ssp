# 設定：連線(2)

本頁說明從右鍵選單的「設定」子選單中選擇「偏好設定」所開啟的對話視窗內，「連線(2)」頁面的設定。

本頁可設定網路連線相關選項。

## 各項目說明

### 線上新聞

- **自動檢查**<br>
  若要定期自動執行線上新聞檢查，請開啟此選項。間隔可依分鐘設定。
- **手動執行線上新聞時更新自動巡覽起始位置**<br>
  使用自動檢查功能時，將下次執行的線上新聞設為手動執行項目的下一項。<br>
  若關閉此功能，每次都會從上方依序巡覽。
- **指定更新時播放的音效**<br>
  指定線上新聞檢查發現更新時播放的音效。

### SSTP 通訊

設定 SSP 接收 SSTP 所使用的連接埠。<br>
清單中至少啟用 IPv4 或 IPv6 其中一種的連接埠，會用於監聽 SSTP。<br>
預設情況下，9801 和 9821 連接埠的 IPv4、IPv6 均為 Local（僅限此電腦內部），11000 連接埠則為停用。

清單左欄為連接埠號碼，右欄為狀態。狀態包含以下內容。

- 接收設定類型（Local、Global、Custom）。停用的連接埠會顯示「Disabled」。
- 監聽失敗時，會在「Error:」（僅部分失敗時為「Partial:」）之後顯示原因。原因包括「invalid address」（位址格式不正確）、「port in use」（連接埠已被其他程式使用）、「address not available」（此電腦沒有該位址）、「no address in range」（沒有符合範圍的位址）等。
- 監聽的 IP 版本（如 `[IPv4+IPv6]`），以及選擇 Custom 時指定的位址。

最左側的圖示會依接收設定類型（Global、Local、Custom）區分，也會依監聽成功、部分成功或失敗而改變。停用的連接埠有專用圖示。

- **新增...**<br>
  新增連接埠。會開啟 [SSTP 連接埠設定](#sstpポートの設定)對話視窗。
- **刪除**<br>
  刪除清單中選取的連接埠。
- **編輯...**<br>
  變更清單中選取的連接埠設定。連按兩下清單中的連接埠也有相同效果。
- **按右鍵**→**Retry Listen**<br>
  在清單中的連接埠上按右鍵即可顯示此選單。此選項會重新監聽該連接埠。<br>
  可用於重新嘗試監聽失敗的連接埠，或在此電腦的位址因 DHCP 等原因變更後，重新取得以範圍（CIDR）指定的連接埠所監聽的位址。

使用啟動選項 `--sstp-listen` 啟動時，清單僅供顯示，無法新增、刪除或編輯（只能使用 Retry Listen）。

!!! tip "ヒント"
    選擇 Global，或在自訂設定中指定 Local 以外的位址時，也會接收來自其他電腦的 SSTP。請僅在可信任的網路中使用。

- **記錄 SSTP 日誌**<br>
  將透過 SSTP 通訊接收的腳本及事件內容寫入名為 `log\SSTP.log` 的檔案。<br>
  有些人格會利用此日誌改變談話內容，請視需要開啟。<br>
  點選後會顯示指定日誌大小上限（KB）的畫面。請輸入要設定為日誌大小上限的數值。
- **讓未啟動的人格看起來也像已啟動**<br>
  為了讓其他支援 SSTP 的軟體將未啟動的人格視為已啟動，會將相關資訊寫入特定區域。<br>
  若不啟用此設定，「盡可能由指定人格播放」可能無法運作。
- **有選項的 SSTP 不進行封鎖**<br>
  通常收到帶有選項的 SSTP 時，為了將所選選項回傳給傳送端，在選擇選項之前，即使收到其他 SSTP 也不會播放。<br>
  這是規格上的問題，但若選項造成的封鎖會帶來困擾（例如播放 SSTP Bottle 時），可開啟此選項以改變行為。<br>
  但在此情況下，以會回傳選項為前提運作的工具將無法使用，請務必留意。
- **完全停用人格內的 SSTP 過濾處理**<br>
  某些人格設有完全封鎖外部 SSTP，或忽略未含特定指定內容的 SSTP 等設定，因此可能不會說出 SSTP 的內容。<br>
  開啟此功能可停用所有這類設定，但這會忽略作者避免角色形象被破壞的意願，請充分考量後再啟用。
- **啟動人格**<br>
  指定透過 SSTP 通訊收到啟動特定人格的指示時的動作。<br>
  預設僅根據透過 SSP 即時通訊發出的指示啟動\[僅限即時通訊\[SSTP/1.5\]\]。<br>
  強烈建議效能較低的電腦選擇「一律不啟動」。<br>
  效能較充裕的電腦可選擇「盡可能由指定人格播放」，讓畫面更熱鬧（但也可能變得不穩定）。
- **啟動後的處理**<br>
  指定依上述設定暫時啟動的人格何時關閉。
- **暫時啟動人格的數量上限**<br>
  指定透過 SSTP 暫時啟動的人格數量上限。<br>
  超過此數量時，會從較早啟動的人格開始依序關閉。
- **暫時啟動人格的最短啟動間隔**<br>
  指定透過 SSTP 暫時啟動人格的間隔。<br>
  一次收到大量要求時，若距離前一個要求尚未經過此處設定的秒數，會回傳 409 Conflict，且不會啟動人格。<br>
  此設定僅在必須暫時啟動人格時適用。若無須啟動，則會立即接受要求。

### SSTP 連接埠設定

這是從 SSTP 通訊的「新增...」或「編輯...」開啟的對話視窗。可針對單一連接埠設定以下項目。

- **連接埠號碼**<br>
  要監聽的連接埠號碼。請指定 1〜65535。<br>
  不能使用與其他連接埠相同的號碼。不過，若兩者都使用自訂設定，且指定的位址不重複，就可以使用相同的號碼。
- **IPv4・IPv6**<br>
  要監聽的 IP 版本。若取消勾選兩者，該連接埠將停用，不會進行監聽。
- **接收設定**<br>
  選擇要接收來自何處的 SSTP。

  - **Local（僅限電腦內部）**<br>
    僅接收來自此電腦內部（127.0.0.1 和 ::1）的 SSTP。這是預設設定。
  - **Global（全部允許）**<br>
    監聽所有位址。也會接收來自其他電腦的 SSTP。
  - **自訂**<br>
    僅監聽指定的位址。下方的位址欄位只有選擇自訂時才能輸入。

    - 請以數字位址指定（不能使用主機名稱）。可用逗號分隔指定多個位址。例如：`192.168.0.5, ::1`
    - 也可以用 `192.168.192.0/24` 這類範圍（CIDR）指定。指定範圍時，會監聽目前分配給此電腦且位於該範圍內的所有位址。即使在位址會透過 DHCP 變更的環境中，只要以範圍指定，重新啟動 SSP，或在清單中按右鍵選擇「Retry Listen」重新監聽，即可監聽新位址。<br>
      `127.0.0.0/8` 對應迴路位址。前綴長度為位址的最大長度（IPv4 為 32、IPv6 為 128）時，等同於單一位址。
    - 只有勾選指定的位址所屬版本（IPv4、IPv6）時，才會使用該位址。例如，未勾選 IPv4 時，不會使用 IPv4 位址。
    - 即使指定格式不正確的位址、此電腦沒有的位址，或不包含任何此電腦位址的範圍，設定仍會儲存。此時監聽會失敗，並在清單中顯示錯誤。
- **此電腦的網路**<br>
  這是自訂位址欄位下方的唯讀欄位。目前分配給此電腦的位址所屬網路會以逗號分隔的 CIDR 顯示，例如 `192.168.192.0/24, 2001:db8:1::/64`。若無法得知前綴長度，則只顯示位址。<br>
  可以選取並複製，再直接貼到位址欄位。

## 下方的按鈕

- **說明**<br>
  開啟偏好設定對話視窗中目前設定頁面的說明（也就是本頁）。<br>
  對話視窗右上角的「？」圖示也有相同作用。
- **關閉**<br>
  關閉偏好設定對話視窗。<br>
  對話視窗右上角的「×」圖示也有相同作用。
