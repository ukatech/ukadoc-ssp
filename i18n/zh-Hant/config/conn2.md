# 設定：連線(2)

本頁說明在右鍵選單的「設定」子選單中，選擇「偏好設定」後開啟的對話方塊裡，「連線(2)」頁面的內容。

本頁可設定網路連線相關項目。

## 各項目說明

### 線上新聞

- **自動檢查**<br>
  如果想要定期自動執行線上新聞感應，請啟用此選項。間隔可用分鐘為單位設定。
- **手動執行線上新聞感應時更新自動巡覽的起始位置**<br>
  使用自動檢查功能時，將下次執行的線上新聞設定為手動執行項目的下一個項目。<br>
  如果停用此功能，每次都會從最上方開始依序巡覽。
- **指定更新時播放的音效**<br>
  指定透過線上新聞感應找到更新時要播放的音效。

### SSTP 通訊

設定 SSP 接收 SSTP 的連接埠。<br>
系統會使用列在此處且已啟用的連接埠。<br>
※若電腦有多個 IP 位址，系統會在所有 IP 位址上等待接收。

- **記錄 SSTP 日誌**<br>
  將 SSTP 通訊接收的腳本或事件內容寫入 `log\SSTP.log` 檔案。<br>
  有些人格會使用此日誌變更談話內容，請視需要啟用此選項。<br>
  點選後會顯示設定日誌最大 KB 數的畫面。請輸入要設定的日誌大小上限。
- **讓未啟動的人格看起來像是已啟動**<br>
  為了讓其他支援 SSTP 的軟體使用，將資訊寫入特定區域，讓未啟動的人格看起來像是已啟動。<br>
  如果未設定此選項，「盡可能以指定人格播放」可能無法運作。
- **有選項的 SSTP 不會阻擋其他 SSTP**<br>
  一般而言，收到帶有選項的 SSTP 時，為了將選擇的選項傳回寄件者，在選擇選項之前，即使收到其他 SSTP 也不會播放。<br>
  這是規格上的限制；如果不希望選項造成阻擋（例如播放 SSTP Bottle），啟用此選項即可變更行為。<br>
  不過，假如某些工具預期會收到傳回的選項，這些工具將無法運作，請務必謹慎使用。
- **完全停用 SSTP 的人格內部篩選處理**<br>
  有些人格會設定為完全阻擋外部 SSTP，或忽略特定指定以外的 SSTP，因此不會回應 SSTP。<br>
  啟用此功能即可停用所有這類設定，但這也等於忽視作者為避免角色形象崩壞而設下的限制，請充分考慮並謹慎啟用。
- **啟動人格**<br>
  指定透過 SSTP 通訊收到啟動特定人格的指示時要採取的動作。<br>
  一般設定為僅透過 SSP 即時通訊收到指示時才啟動\[僅限訊息程式\[SSTP/1.5\]\]。<br>
  強烈建議效能較低的電腦選擇「完全不啟動」。<br>
  效能充裕的電腦可以選擇「盡可能以指定人格播放」，畫面會更熱鬧（但也會更不穩定）。
- **啟動後的處理**<br>
  指定何時關閉透過上述設定暫時啟動的人格。
- **暫時啟動人格的數量上限**<br>
  指定透過 SSTP 暫時啟動的人格數量上限。<br>
  超過此數量時，系統會依序關閉較早啟動的人格。
- **暫時啟動人格的最短啟動間隔**<br>
  指定透過 SSTP 暫時啟動人格的間隔。<br>
  如果短時間內收到大量要求，只有在距離前一個要求已經過此處設定的秒數後才會啟動人格，否則會回覆 409 Conflict。<br>
  另外，只有在必須暫時啟動人格時才會套用此設定；若不需要暫時啟動，系統會立即接受要求。

## 下方按鈕

- **說明**<br>
  開啟偏好設定對話方塊中目前設定頁面的說明（也就是本頁）。<br>
  對話方塊右上角的「？」圖示也有相同功能。
- **關閉**<br>
  關閉偏好設定對話方塊。<br>
  對話方塊右上角的「×」圖示也有相同功能。
