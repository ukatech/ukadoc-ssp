# 設定：語音辨識／語音合成

本頁說明如何使用右鍵選單「設定」子選單中的「偏好設定」開啟對話方塊，並介紹其中的「語音辨識／語音合成」頁面。

本頁可設定 SSP 的語音辨識與語音合成功能。

功能的使用方法請參閱「[語音辨識](../functions/speech-recognition.md)」和「[語音合成](../functions/speech-synthesis.md)」頁面。

!!! tip "ヒント"

    如果電腦無法使用語音辨識或語音合成，各自群組中的項目會呈現灰色，無法選取。<br>
    各項目的「(System Default)」表示使用 Windows 設定中選取的項目。通常維持原樣即可。

## 各項目說明

### 語音辨識

請選取「功能→語音辨識」選單，開啟辨識面板後使用。

!!! tip "ヒント"

    變更此欄的設定後，會立即套用至已開啟的辨識面板。不需要重新啟動 SSP。

- **辨識引擎**<br>
  變更語音辨識引擎。選取「(System Default)」時，會使用語音辨識控制台中選取的項目。<br>
  如果電腦安裝了多個辨識引擎，請選擇適合您所說語言的引擎。
- **設定檔**<br>
  切換用來提高辨識準確度的學習資料。選取「(System Default)」時，會使用語音辨識控制台中選取的項目。<br>
  如果想依不同使用者切換訓練結果，請使用此選項。
- **辨識引擎設定、麥克風設定、訓練**<br>
  是否可設定各項目，取決於辨識引擎。通常這些項目都會停用。<br>
  若項目可用，按下後會開啟辨識引擎提供的設定畫面。在「麥克風設定」中可調整麥克風音量；在「訓練」中可讓引擎學習您的說話習慣，以提高辨識準確度。
- **音訊輸入來源**<br>
  切換音訊輸入來源，例如麥克風插孔或耳機麥克風。選取「(System Default)」時，會使用語音辨識控制台中選取的項目。<br>
  只有在所選輸入來源提供專用設定畫面時，才能按下右側的「設定...」。

### 語音合成

請開啟「功能→語音合成」選單後使用。

!!! tip "ヒント"

    變更此欄的設定後，會從下一次朗讀開始套用。不需要重新啟動 SSP。

- **`\0`（主要角色）**<br>
  設定主要角色（`\0`）的語音。您可以選擇語音、調整音高，並使用設定按鈕進行詳細設定。
- **`\1`（次要角色）**<br>
  設定次要角色（`\1`）的語音。您可以選擇語音（也可以與 `\0` 或 `\2` 使用相同語音）、調整音高，並使用設定按鈕進行詳細設定。
- **`\2`～（其他角色）**<br>
  設定 `\2` 之後的額外角色語音。您可以選擇語音（也可以與 `\0` 或 `\1` 使用相同語音）、調整音高，並使用設定按鈕進行詳細設定。
- **選擇語音**<br>
  清單中會列出 Windows 內建的語音，以及用來使用外部語音合成服務的「LocalAPI-0〜9」和「CloudAPI-0〜9」欄位。<br>
  選取「LocalAPI-」或「CloudAPI-」欄位後，請按右側的「設定...」設定連線目的地等資訊，再開始使用。<br>
  只有在 Windows 語音提供專用設定畫面時，才能按下「設定...」。
- **音高**<br>
  設定聲音的高低。可在 -10〜10 的範圍內選擇（0 為基準）。數字越大，聲音越高。<br>
  初始值為 `\0` 的 0、`\1` 的 +5（稍高），以及 `\2`～的 -5（稍低）。
- **音訊輸出目的地**<br>
  切換音訊輸出目的地，例如喇叭或耳機插孔。您可以使用設定按鈕進行詳細設定。
- **說話速度**<br>
  調整語音合成的朗讀速度。使用滑桿可從「慢」調整至「快」。請以標準位置為基準進行調整。<br>
  此設定適用於所有角色。
- **音量**<br>
  調整語音合成的音量。使用滑桿可設定為 0% 至 100%。初始值為 100%。<br>
  此設定適用於所有角色。
- **配合語音合成的播放進度等待腳本播放**<br>
  配合語音合成的朗讀速度同步調整腳本的顯示時機。<br>
  關閉時，對話方塊中的文字會以平常的速度播放，語音則會追上文字。開啟時，會等待語音追上後才繼續播放人格，因此語音和文字之間的落差會縮小（但如果語音合成耗時，人格的動作也會變慢）。此選項預設為關閉。

## 語音合成詳細設定對話方塊（右側的設定按鈕）

在「LocalAPI-」或「CloudAPI-」欄位按下「設定...」後，會開啟此對話方塊。請選擇要使用的軟體或服務類型，並輸入必要項目。<br>
除了使用雲端語音合成時所需的 API 金鑰外，其餘項目都可以省略。請只輸入必要資訊，其他欄位留白即可。所選類型不會使用的項目會呈現灰色，無法輸入。

- **類型**<br>
  選擇要使用的語音合成軟體或服務。在 LocalAPI 欄位中可選擇本機軟體，在 CloudAPI 欄位中則可選擇雲端服務。
- **語音 ID／風格 ID／瀏覽...**<br>
  指定要使用的語音。按下「瀏覽...」後，會從連線目的地的軟體取得語音清單，您可以參考名稱進行選擇。如果知道 ID，也可以直接輸入。<br>
  若使用 LocalAPI，「瀏覽...」只有在連線目的地的軟體已啟動時才能顯示清單（否則會發出蜂鳴聲）。請先啟動軟體再按下按鈕。<br>
  Aivis Cloud API 和 OpenAI TTS 的「瀏覽...」不會取得清單，而是會在瀏覽器中開啟列有語音清單的網頁。
- **主機名稱／IP、連接埠號碼**<br>
  在 LocalAPI 中，指定執行連線目的地軟體的電腦。如果軟體在同一台電腦上執行，留白即可。
- **API 金鑰**<br>
  用來連線至雲端服務的金鑰。請從服務的管理畫面取得金鑰後貼上。

### LocalAPI

- **VOICEVOX,VOICEVOX Nemo,SHAREVOX,AivisSpeech**<br>
  按下瀏覽按鈕後，可參考角色名稱選擇語音 ID。如果知道 ID，也可以直接輸入。<br>
  如果軟體在同一台電腦上執行，主機名稱和連接埠號碼留白即可。
- **COEIROINK v2**<br>
  按下瀏覽按鈕後，可參考角色名稱選擇語音 ID 和風格 ID。如果知道 ID，也可以直接輸入。<br>
  風格 ID 請輸入風格名稱（例如「れいせい」）。如果知道 ID，也可以輸入 ID。<br>
  如果軟體在同一台電腦上執行，主機名稱和連接埠號碼留白即可。
- **Style-BERT-VITS2**<br>
  按下瀏覽按鈕後，可參考角色名稱選擇語音 ID 和風格 ID。如果知道 ID，也可以直接輸入。<br>
  風格 ID 請輸入風格名稱。如果知道 ID，也可以輸入 ID。<br>
  如果軟體在同一台電腦上執行，主機名稱和連接埠號碼留白即可。<br>
  請啟動 Server.bat(`server_fastapi.py`)。
- **OpenAI TTS - Local（相容本機 API）**<br>
  語音 ID 請輸入 Text-to-speech AI 模型的名稱，例如「irodori-tts」。<br>
  風格 ID 請依照相容伺服器的規格輸入。例如使用 Irodori-TTS-Server 時，請輸入放在 voices 資料夾中的參考語音 wav 檔名（不含副檔名）。<br>
  如果軟體在同一台電腦上執行，主機名稱留白即可。連接埠號碼則需依各服務設定。例如使用 Irodori-TTS-Server 時，請輸入 8088。

### CloudAPI

- **Aivis Cloud API**<br>
  語音 ID 請複製並輸入「模型 UUID」。注意！不是說話者 UUID。<br>
  風格 ID 列在語音的詳細資訊頁面中。<br>
  建議將音高設為 0。據說設定其他數值會降低合成速度。<br>
  您可以從[此儀表板](https://hub.aivis-project.com/cloud-api/dashboard)取得 API 金鑰，請將金鑰貼到金鑰欄位。
- **OpenAI TTS - Cloud（雲端 API 或相容服務）**<br>
  語音 ID 請輸入 Text-to-speech AI 模型的名稱，例如「gpt-4o-mini-tts」或「tts-1」。<br>
  風格 ID 請輸入[此文件的「Voice options」章節](https://developers.openai.com/api/docs/guides/text-to-speech#voice-options)中所列的名稱。例如：「marin」、「cedar」。<br>
  您可以從[此儀表板](https://platform.openai.com/account/api-keys)取得 API 金鑰，請將金鑰貼到金鑰欄位。<br>
  使用相容服務時，請設定主機名稱。使用 OpenAI 的 Text-to-speech 時，留白即可。

## 下方的按鈕

- **說明**<br>
  開啟「偏好設定」對話方塊中目前設定頁面的說明（也就是本頁）。<br>
  對話方塊右上角的「？」符號也有相同功能。
- **關閉**<br>
  關閉「偏好設定」對話方塊。<br>
  對話方塊右上角的「×」符號也有相同功能。
