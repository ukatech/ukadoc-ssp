# 設定：郵件

本頁說明在右鍵選單的「設定」子選單中，選擇「偏好設定」開啟的對話方塊裡「郵件」頁面的內容。

本頁可設定郵件檢查功能。

此功能可檢查是否有郵件送達 SSP。

## 各項目說明

- **也取得郵件標頭（也取得主旨等資訊）**<br>
  也會取得郵件標頭，讓人格能解析郵件標頭（例如標題）。<br>
  如果不希望將標頭交給人格，請關閉此選項。
- **以新郵件數量通知郵件件數**<br>
  一般來說，人格應該會告訴您「有 ×× 封郵件」，但這個數字是伺服器上保留的郵件數量，不是新郵件的數量。<br>
  啟用此設定後，人格會改為說出新郵件的數量，而不是伺服器上的郵件數量。
- **只有收到新郵件時才顯示訊息**<br>
  只有收到新郵件時，人格才會告訴您有郵件送達。

### 指定收到郵件時播放的音效

收到新郵件時，會播放在此設定的音訊檔案。按下「瀏覽...」按鈕可選擇檔案，按下「無」按鈕可清除音效設定，按下「播放」按鈕可確認設定的音效。

### 帳戶設定

若要新增帳戶，請按下「新增...」按鈕；若要刪除帳戶，請從下方清單中選取帳戶，再按下「刪除」按鈕。<br>
若要修改設定，請按下「變更...」按鈕。按下「複製」按鈕即可複製現有設定並建立新項目。

- **帳戶名稱**<br>
  請取一個方便自己辨識的名稱。此名稱會出現在郵件檢查選單中。
- **類型**<br>
  支援 XOAUTH2-POP3/APOP/一般 POP3、XOAUTH2-IMAP4/IMAP4、NNTP。<br>
  請參閱網路服務供應商或其他郵件服務的使用說明來進行設定。<br>
  通常可使用 POP3 或 APOP 連線。<br>
  XOAUTH2-POP3/XOAUTH2-IMAP4 是所謂的「新式驗證」等驗證方式。<br>
  使用此功能時，請在使用者 ID 欄位輸入「電子郵件地址」，並在密碼欄位輸入「存取權杖」。<br>
  存取權杖（Bearer token）的取得方式，請參閱各服務提供給開發者的說明文件。
- **伺服器**<br>
  請輸入存放您郵件的 POP 伺服器位址。<br>
  網路服務供應商提供的文件通常會列出「POP 伺服器位址」之類的項目，請將該位址照抄填入（使用半形字元）。<br>
  只有 NNTP 可使用特殊格式，例如 nntp.example.com/`fj.*`；斜線後方可填入群組名稱（或含有萬用字元的模式）
- **連接埠號碼**<br>
  通常維持預設值即可。<br>
  只有在指定了特別的連接埠號碼時才需要變更。
- **使用者 ID／密碼**<br>
  請輸入您的郵件使用者 ID 和密碼。<br>
  請注意，這組帳號密碼通常與連線至網際網路時使用的使用者名稱和密碼不同。<br>
  使用 XOAUTH2 系列功能時，請分別改填電子郵件地址和存取權杖。<br>
  連線至不需要驗證的 NNTP 伺服器時，請先填入 guest/guest。
- **使用 SSL/TLS 連線至伺服器**<br>
  連線至郵件伺服器時，會使用 SSL/TLS 加密以保護資訊。<br>
  通常不需要設定也能連線，但有些服務（例如 GMail）可能必須設定此選項。
- **驗證 SSL/TLS 伺服器憑證**<br>
  這是上述 SSL/TLS 功能的進階設定。通常請保持開啟。<br>
  部分免費服務等可能需要關閉此選項，否則會發生通訊錯誤。
- **自動檢查**<br>
  每隔指定時間自動檢查是否有郵件送達。<br>
  請勿設定過短的時間間隔。

## 下方按鈕

- **說明**<br>
  開啟偏好設定對話方塊中目前設定頁面的說明（也就是本頁）。<br>
  對話方塊右上角的「？」圖示也有相同功能。
- **關閉**<br>
  關閉偏好設定對話方塊。<br>
  對話方塊右上角的「×」圖示也有相同功能。
