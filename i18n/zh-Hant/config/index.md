# 設定

本頁說明[右鍵選單](../howto/rclick.md)中「設定」子選單的各個項目。

另外，項目名稱可能會因人格而異（位置不會改變）。<br>
如果覺得難以理解，可以在偏好設定的「[人格(1)](ghost.md)」中關閉人格定義的選單顯示。

## 各項目說明

### 偏好設定

開啟 SSP 的偏好設定對話方塊。<br>
設定依類別分成多個頁面。<br>
⇒各項目的詳細說明，請參閱下列各頁面。

- [人格(1)](ghost.md)
- [人格(2)](ghost2.md)
- [資料夾](folder.md)
- [顯示](disp.md)
- [談話/對話方塊](talk.md)
- [語音辨識/合成](dictation.md)
- [連線(1)](conn1.md)
- [連線(2)](conn2.md)
- [POP](pop.md)

- [IM](im.md)

- [開發/其他](dev.md)

### 各人格的設定

開啟可分別為各個人格設定項目的對話方塊。<br>
⇒詳情請參閱[詳細說明頁面](eachghost.md)。

### 視窗模式

切換是否將人格集中顯示在同一個視窗中的「視窗模式」。<br>
可從「關」、「所有人格」（將所有人格集中在同一個視窗）、「每個人格各自一個視窗」三種模式中選擇。<br>
⇒詳情請參閱「[視窗模式](../functions/windowmode.md)」頁面。

### 啟用 Proxy 伺服器

用來啟用或停用已設定的 Proxy 伺服器的簡易開關。<br>
可在偏好設定的「[連線(1)](conn1.md)」中進行 Proxy 伺服器的詳細設定；此項目與該頁面的核取方塊功能相同。

### 字元編碼設定

指定讀取人格內各個檔案時使用的字元編碼。<br>
通常會自動判別，因此不需要設定；但在非日文版 Windows 等環境中使用時，或許能派上用場。

### 由人格決定談話時機

基本上保持開啟（已勾選）即可。<br>
在執行舊版人格等情況下，關閉此選項後，有時人格就會自行開始談話。

### 舊版規格支援

基本上保持關閉（未勾選）即可。<br>
在執行舊版人格等情況下，開啟此選項後，有時人格就會開始談話。　<br>
相反地，如果出現行為異常的情況，也可能是此選項已開啟，請試著將它關閉。
