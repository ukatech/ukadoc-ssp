# 開發者說明：腳本記錄

本頁說明**腳本記錄**。

此外，也會說明可從腳本記錄左下方切換的**錯誤記錄**。

## 腳本記錄

人格收到的 Sakura Script 會在內部保存指定筆數。<br>
在腳本記錄中，您可以檢視、儲存這些內部保存的腳本，或讓人格再說一次。

### （左下方）腳本

這是用來切換至[錯誤記錄](#エラーログ)的下拉式選單。

### 記錄筆數

設定要在內部保存的記錄筆數。

### 按鈕

對清單中選取的列等項目執行下列操作。

- **清除**<br>
  刪除清單中的所有內容。
- **複製**<br>
  將選取的腳本複製到剪貼簿。<br>
  您可以貼到文字檔等地方，用於檢查。
- **儲存**<br>
  開啟儲存對話方塊，將記錄以 csv 格式輸出至指定位置。
- **執行**<br>
  讓人格重新執行選取的記錄。

## 錯誤記錄

顯示 SSP 執行期間發生的錯誤記錄。<br>
請確認錯誤內容，並將其作為排除問題時的參考。

### 錯誤等級

清單最左側的圖示，以及錯誤訊息開頭的詞語，代表錯誤等級。<br>
大致上有以下含意。

- **![](../assets/screenshots/dev/scriptlog/4.png)嚴重錯誤**<br>
  發生重大錯誤。可能導致無法啟動或停止運作等結果。<br>
  需要立即修正。
- **![](../assets/screenshots/dev/scriptlog/3.png)錯誤**<br>
  發生錯誤。例如部分無法修正的檔案內容遭到略過，導致運作結果不如預期。<br>
  若要正常運作，需要進行修正。
- **![](../assets/screenshots/dev/scriptlog/2.png)警告**<br>
  檔案內容等有輕微錯誤，但經 SSP 內部修正後，（大概）仍可正常運作。<br>
  為了與其他 baseware 相容，也為了避免 SSP 規格變更後發生「明明什麼都沒做卻突然不能用了」等情況，請盡可能修正。
- **![](../assets/screenshots/dev/scriptlog/1.png)注意**<br>
  偵測到可能有某種錯誤的潛在風險或危險性。
- **![](../assets/screenshots/dev/scriptlog/0.png)資訊**<br>
  提供系統開發者參考的資訊。基本上不必特別在意。

### （左下方）錯誤

這是用來切換至[腳本記錄](#スクリプトログ)的下拉式選單。

### 記錄筆數

設定要在內部保存的記錄筆數。

### 按鈕

對清單中選取的列等項目執行下列操作。

- **複製**<br>
  將選取的錯誤內容複製到剪貼簿。<br>
  您可以貼到文字檔等地方，用於檢查。
- **儲存**<br>
  開啟儲存對話方塊，將記錄以 csv 格式輸出至指定位置。
