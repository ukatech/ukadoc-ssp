# Information

![Information submenu](../assets/screenshots/about/information/0.png)<br>
This page explains the items in the “Information” submenu of the [right-click menu](../howto/rclick.md).

The item names may vary depending on the ghost, but their positions do not.<br>
If you find them confusing, you can turn off the display of ghost-defined menu items in Preferences under “[Ghost (1)](../config/ghost.md).”

## Item descriptions

### About SSP

Displays information such as the SSP version, operating environment, and development environment.<br>
This may also be useful when you need to copy and submit information, such as when reporting a bug.

### About the character

![Emily/phase4.5 readme.txt](../assets/screenshots/about/information/2.png)<br>
Opens the readme for the ghost you are using.<br>
You can also switch the selection at the bottom left to view the readme for the shell or balloon you are using.

### Manual

Opens the SSP help (the page you’re reading now).

### AI graph

![AI graph for Traffic☆Train](../assets/screenshots/about/information/3.png)<br>
Displays information set for each ghost as a radar chart (the image shows the chart for Traffic☆Train).<br>
Nothing is displayed if no information has been set.

### Usage statistics

![Usage statistics](../assets/screenshots/about/information/4.png)<br>
Opens the “Usage graph.”<br>
Displays a list of ghosts you have used in the past, showing their usage time and number of launches, as well as a pie chart showing their usage proportions.<br>
You can also check the number of ghosts installed and the number of ghosts you have launched.<br>
If the history spans multiple pages, use the button at the top right to turn the pages.<br>
You can also save a screenshot of the Usage graph in PNG or WebP (lossless) format using the button next to the × at the top left.

### Submit system information

Writes a dump file of the system while it is running.<br>
Submitting it together with a bug report may be helpful.
