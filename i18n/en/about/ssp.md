# SSP Basic Information

Please also read the “readme.txt” included with SSP.

## Supported Environments

- **OS:**<br>
  Windows 2000 or later, or a Wine-compatible environment equivalent to the above
- **CPU:**<br>
  A CPU powerful enough to run the above OS
- **Memory:**<br>
  Approximately 64 MB of free memory
