# Glossary

## Ghost

Character data, or the part that makes up its pseudo-AI.<br>
The ghost is the part that governs the character’s “personality,” enabling it to respond in various ways and have conversations—in other words, its “heart” or “soul.”<br>
Of course, a “soul” alone cannot take shape, so the term usually refers to something packaged with a “shell” as a set, ready to use.<br>
Depending on the context, the term can also be used in a vague, genre-like sense, much like “Ukagaka,” described below.

## Shell

The data for a ghost’s standing illustration.<br>
It is the visible part that governs how the character is displayed. While this is less true nowadays, historically there have been many male developers, so many shells depict women (\^\_^;). There are also shells depicting men, animals, and non-living things, as well as “Moeless” shells intended simply for use as information tools.<br>
You can use multiple shells with a ghost and switch between them from the “Shell” menu.

## Balloon

In short, a “speech bubble.” It is a small window for displaying a ghost’s conversations.<br>
Like shells, balloons come in many different designs and are widely available for easy installation.

## Network update

A feature that detects changes to files that make up a ghost or other content, one file at a time over the Internet, then downloads and overwrites only the updated files.<br>
This saves users the trouble of repeatedly visiting distribution sites to check for updates, downloading a complete archive when one is available, and installing it over the existing content.<br>
In addition to ghosts, SSP provides this feature for shells, balloons, headlines, and plugins.<br>
You can update ghosts from the [right-click menu](../howto/rclick.md). Depending on your [Preferences](../config/ghost.md), you can also update shells and balloons from the right-click menu. You can update all of these, as well as other content, from [Explorer](../functions/explorer/index.md).

## Headline

A feature that automatically retrieves update information from specific sites and displays it as a list.<br>
The headline feature can be extended with plugins. To make a plugin available, **drag** its package onto the currently displayed ghost, or extract it into the headline folder and restart SSP.<br>
There is also a feature that automatically checks for headlines.

## Sakura side/Uningyu side

In the days when characters were called “Fake XX,” and in the default ghost for “Nani ka,” the main character was called Sakura and the secondary character was called Unyuu. These terms are remnants of those names.<br>
In “Emily,” SSP’s default ghost, the cat-eared woman is the “Sakura side,” and Teddy, the mysterious creature, is the “Unyuu side.”<br>
The terms `\h` side/`\u` side, `\0` side/`\1` side, `\p0` side/`\p1` side, main character/secondary character, and main character/partner all mean the same thing.

## SHIORI

The name of a system used to create a “ghost.”<br>
It is usually provided as a Windows DLL, but is designed to be operating-system independent.

## MAKOTO

A mechanism for replacing certain words in text received from a ghost or through SSTP communication.<br>
It can be used to change the character’s way of speaking, such as by changing word endings.<br>
It is also usually provided as a Windows DLL, but is designed to be operating-system independent.<br>
Some implementations take this idea further and play music or provide special features.

## SERIKO

Shell animation.<br>
In SSP and Ukagaka, this term may refer to the specifications for shell animation.

## MAYUNA

The shell dress-up mechanism.<br>
In SSP and Ukagaka, dress-up is implemented as a type of SERIKO (animation).

## Sakura Script

A string used by ghosts and SSTP, decorated with tags that represent commands for controlling a character’s expressions, opening specific URLs, and displaying text or images in a balloon.

## Surface

Also called a “surface.”<br>
A part or element that corresponds to a single “frame” in a shell or in content containing images, such as a balloon.<br>
In shells, each surface corresponds to a character expression. Dress-up and animation are also represented by combining or sequencing surfaces.

## SSTP

Short for Sakura Script Transfer Protocol. It is a mechanism for sending and receiving Sakura Script over a network.<br>
It seems to be called “poison radio waves,” too……(\^\_^;)

## Ukagaka

Pronounced “Ukagaka.”<br>
Originally, it was one type of application called a desktop mascot.<br>
Today, however, the term is also used vaguely to refer to the genre or community surrounding character data called “ghosts,” including those that run only on compatible applications such as SSP.

## Baseware

A general term for the software “Ukagaka” and its compatible applications. SSP is one of these applications.<br>
The term comes from the fact that this software provides the environment that ghosts run on.<br>
As mentioned above, the term “Ukagaka” now has a broad and ambiguous meaning, so “MATERIA” is generally used when referring specifically to Ukagaka as baseware.
