# Shortcut List

SSP assigns shortcut keys to frequently used features.

Features marked <strong>【開発】</strong> below are unavailable unless “Enable developer features” is ON in Preferences → “[General](../config/ippan.md)”.

| Feature | Shortcut |
|---|---|
| Backlog | Ctrl - B (Backlog) |
| Calendar | Ctrl - D |
| Development palette | <strong>【開発】</strong>Ctrl - Shift - D (Development) |
| Explorer | Ctrl - E (Explorer) |
| Search in Explorer and similar windows | Ctrl - F (Find) |
| Minimize | Ctrl - I / Ctrl - Shift - Return\[works without focus\] |
| Close balloon | Ctrl - Shift - Delete\[works without focus\] |
| Keep temporarily launched ghost | Ctrl - K (Keep) |
| Script log | <strong>【開発】</strong>Ctrl - L (Log) |
| SSP Messenger | Ctrl - M (Messenger) |
| Open file | Ctrl - O (Open) |
| Select folder | Ctrl - F |
| Exit all | Ctrl - Q (Quit) |
| Enter script | <strong>【開発】</strong>Ctrl - S (Script) / Ctrl - Shift - Insert |
| Surface test | <strong>【開発】</strong>Ctrl - T (Test) |
| Network update | Ctrl - U (Update) |
| Address bar | Ctrl - Shift - U (URL) |
| Reset balloon position | Ctrl - Shift - F10 |
| Reset shell position | Ctrl - Shift - F12 |
| Exit | Ctrl - W / Ctrl - F4 |
