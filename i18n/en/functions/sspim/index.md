# SSP messenger

SSP users can exchange messages with one another, or with [IP Messenger](http://ipmsg.org/) if configured.<br>
※However, SSP does not support encryption added in IP Messenger Ver2 or file transfers.

If you only need to send messages one way, you can send a script to a machine that can receive SSTP. You can think of this as entering a script on another machine.

To use it:

・[Add a recipient](addto.md)<br>
then

・[Send a message](sendto.md)<br>
That is all.

For detailed instructions, see the linked pages.
