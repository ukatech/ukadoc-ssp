# SSP messenger: Sending a message

Select a recipient from the list of registered users at the top of the dialog, write a message in Sakura Script format in the message field, and send it.

You can select multiple recipients and send a message to several people at once.

## Check

Click the Check button to make sure the script is correct.<br>

Click this button to send the message.
