# Settings

This page explains each item in the “Settings” submenu of the [right-click menu](../howto/rclick.md).

Note that item names may vary depending on the ghost (their positions do not).<br>
If you find them difficult to understand, you can turn off the display of the ghost definition menu in “[Ghost (1)](ghost.md)” under Preferences.

### Ghost preferences

Opens a dialog for settings you can configure individually for each ghost.<br>
⇒For details, see the [detailed page](eachghost.md).

### Window mode

Switches between “Window mode,” which displays all ghosts together in a single window.<br>
Choose from three options: “Off,” “All ghosts” (all ghosts together in one window), and “Per ghost” (one window per ghost).<br>
⇒For details, see the “[Window mode](../functions/windowmode.md)” page.

### Enable proxy server

A simple switch for enabling or disabling the configured proxy server.<br>
You can configure the proxy server in “[Connection (1)](conn1.md)” under Preferences. This item does the same thing as the checkbox there.

### Character encoding

Specifies the character encoding used to read files inside ghosts.<br>
Usually, the encoding is detected automatically, so you do not need to set this. However, this setting may be useful when using SSP on a version of Windows other than the Japanese version.

### Let the ghost decide when to talk

You can usually leave this ON (checked).<br>
Turning it OFF may make older ghosts talk automatically.　

### Legacy compatibility

You can usually leave this OFF (unchecked).<br>
Turning it ON may make older ghosts talk.<br>
Conversely, if something is behaving strangely, this may be ON. Try turning it OFF.
