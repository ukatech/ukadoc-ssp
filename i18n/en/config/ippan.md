# Settings: General

This page explains the “General” page of the dialog opened by selecting “Preferences” in the “Settings” submenu of the right-click menu.

This page contains settings that apply to SSP as a whole.

## Item descriptions

- **Automatically check whether SSP has been updated**<br>
  Automatically runs the SSP update check. If the checkbox is gray or shown as a horizontal bar, SSP asks whether to install an update when one is available. If checked, the update is downloaded automatically and SSP is replaced with the new version when it starts next time.
- **Associate files with SSP**<br>
  Associates files such as NAR (Nanika ARchive = package files for ghosts, shells, and other items) with SSP, so you can install them by double-clicking them while SSP is running.<br>
  This option can usually be ON without causing any problems. Turn it OFF if you want to use SSP alongside other Ukagaka-compatible software, or if you do not want SSP to modify the registry. It is OFF by default.
- **Always show the uninstall menu**<br>
  Normally, the menu is controlled by the ghost's settings. Turn this ON to always show a button for uninstalling the ghost.
- **Always show the taskbar tray icon**<br>
  If this is unchecked, the taskbar tray icon is shown only when the ghost is minimized.<br>
  Unless you have a problem such as limited system resources, it is recommended to leave this ON.
- **Show the README after installation**<br>
  Displays the ghost's documentation when installation is complete.
- **Register hotkeys**<br>
  Sets whether to register hotkeys starting with Ctrl-Shift that are always active.<br>
  Disable this option if they conflict with other software.
- **Show the transparent status window**<br>
  Displays a MATERIA (Ukagaka)-style status window at startup.<br>
  This feature originally started as an April Fools' joke in 2015.
- **Scan for viruses \[Windows 10 and later\]**<br>
  Scans new data for viruses before placing it during a network update or installation. If anything suspicious is detected, the installation or update immediately fails with an error.<br>
  This feature is available only on Windows 10 and later.
- **Enable developer features \[Use with caution!\]**<br>
  Enables features for ghost developers, such as removing certain locks and displaying errors.<br>
  Using these features incorrectly may cause ghost features to malfunction or reveal internal information, resulting in serious spoilers.<br>
  Keep this OFF in normal use.

### Dark mode

Displays dialogs and other items in dark mode (a dark-colored theme).

- <strong>Automatic (OS setting)</strong>: Switches dark mode according to the OS settings. This option is usually fine.
- **Always dark**: Always displays and operates in dark mode.
- **Always light**: Always displays and operates in normal mode.

### Sensor/location access

Sets whether SSP can use information from sensors built into your PC (mainly ambient light and acceleration sensors on laptops and tablets) and location information (such as GPS or Wi-Fi triangulation).<br>
SSP does not leak this information, for example by sending it externally.

- <strong>Enabled (OS setting)</strong>: Uses all sensors and location information according to the OS settings.
- **Except location information**: Uses sensor information other than location information.
- **Disable all**: Does not use any sensors or location information.

### Tablet mode

When tablet mode is enabled, the spacing in the right-click menu increases and SSP behaves in other ways suited to tablets.

- <strong>Automatic (OS setting)</strong>: Switches tablet mode according to the OS settings. This option is usually fine.
- **Always enabled**: Always displays and operates in tablet mode.
- **Always disabled**: Always displays and operates in normal mode.

### User information

Setting your name, preferred form of address, birthday, and gender may have benefits with ghosts that support this feature.

This information is used only to notify ghosts of your user information or to process scripts.

## Buttons at the bottom

- **Help**<br>
  Opens the help page for the current page of the Preferences dialog (that is, this page).<br>
  The “?” icon at the top right of the dialog does the same thing.
- **Close**<br>
  Closes the Preferences dialog.<br>
  The “×” icon at the top right of the dialog does the same thing.
