# Settings: Internationalization

This page explains the “Internationalization” page of the dialog opened by selecting “Preferences” in the “Settings” submenu of the right-click menu.

This page lets you configure settings related to internationalization.

These settings control the internationalization of displayed text.

## Description of each setting

### Override menu font / Override balloon font

Changes the fonts used in menus and balloons.<br>
This can help reduce garbled text when using SSP on a version of Windows other than the Japanese version. You can also use it simply to display text in a different font.

- **Select**<br>
  Opens the font selection dialog, where you can choose the font to use for display.
- **Default**<br>
  Restores the default settings.

### Default character encoding

Change this setting if you encounter garbled text due to character encoding issues, such as when launching a Japanese ghost in an environment that is not running a Japanese OS.<br>
Normally, leave all settings set to Default. SSP tries to detect the character encoding automatically whenever possible.

- **Text definitions**<br>
  Specifies the character encoding for text definition files such as descript.txt, install.txt, and surfaces.txt.
- **File I/O**<br>
  Specifies the character encoding used for file input and output, such as during network updates and ZIP extraction.
- **readme**<br>
  Specifies the character encoding for the readme.txt file.
- **SHIORI**<br>
  Specifies the character encoding used to communicate with SHIORI (AI).
- **MAKOTO**<br>
  Specifies the character encoding used to communicate with MAKOTO plugins.
- **PIRO (OLD)**<br>
  Specifies the character encoding used to communicate with old PIRO plugins.
- **SCRIPT (OLD)**<br>
  Specifies the character encoding used by the old script processing system.<br>
  Starting with version 2.8.86, this setting also applies when loading news definitions (news.txt), in addition to legacy script definition files such as script.txt.

## Buttons at the bottom

- **Help**<br>
  Opens the help page for the current page in Preferences (that is, this page).<br>
  The “?” button in the upper-right corner of the dialog does the same.
- **Close**<br>
  Closes the Preferences dialog.<br>
  The “×” button in the upper-right corner of the dialog does the same.
