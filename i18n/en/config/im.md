# Settings: IM

This page explains the “IM” page of the dialog opened by selecting “Preferences” in the “Settings” submenu of the right-click menu.

These settings control SSP’s own instant messaging feature, which uses SSTP or IP Messenger.

## Description of each setting

- **Name**<br>
  Enter the name you use for instant messaging, such as your handle.　
- **Group**<br>
  The group name used for instant messaging.
- **Do not translate when using SSTP**<br>
  When sending Sakura Script over SSTP, this bypasses the mechanism called “translate,” which converts characters inside the ghost, and plays the Sakura Script directly. You usually do not need to check this option.
- **Clear message dialog after sending**<br>
  Clears the text from the message input box after sending a message.
- **Use IP Messenger compatibility mode**<br>
  Enables sending and receiving messages using IP Messenger.
- **Port number**<br>
  Sets the port number used by IP Messenger.<br>
  You usually do not need to change this setting.　
- **Dial-up connection**<br>
  Turn this on if you want to use IP Messenger in an environment where broadcasts cannot get through. You can usually leave this turned off.

### Specify broadcast/multicast destinations

Specifies the IP addresses to which you want to send messages such as login and logout notifications.<br>
Normally, specify a “broadcast address” or “multicast address,” which can send messages to all machines on the same network block (segment).

The default setting is 255.255.255.255. If this works, you do not need to change it.

## Buttons at the bottom

- **Help**<br>
  Opens the help page for the current page in Preferences (that is, this page).<br>
  The “?” button in the upper-right corner of the dialog does the same.
- **Close**<br>
  Closes the Preferences dialog.<br>
  The “×” button in the upper-right corner of the dialog does the same.
