# Basic usage: Starting SSP

## Getting started

There is a program called “SSP.EXE” in the folder where you extracted SSP.<br>
Run it to start SSP.<br>
That’s all there is to it. Easy, right?

Once a “ghost” and a “balloon” appear on your desktop, SSP has started.<br>
The ghost included right after installation is “Emily/Phase4.5.” Enjoy spending time with her.

### Create a shortcut

Opening the extraction folder and double-clicking the program every time is inefficient, so it’s a good idea to create a shortcut.

If your version of Windows includes the Quick Launch feature, you can create a new toolbar and put the shortcut there.<br>
(For instructions on creating shortcuts and toolbars, see Windows Help or the Windows manual.)

### Start SSP when your computer starts

Once you add various external data, you’ll probably want SSP to run all the time (that’s a promise!).<br>
In that case, set it to start when your computer starts.<br>
This is easy if you have an external tool for it, but you can do it without one.<br>
Follow these steps to create a shortcut.

- Open a File Explorer window and click the address bar
- Type shell:statup and press Enter
- Create a shortcut in the File Explorer window that appears

## Startup settings

In Preferences, you can choose which ghost SSP starts with:

- Start with a random ghost
- Start with the ghost that was active the last time SSP was closed
- Open Explorer immediately after startup and choose a ghost

⇒　For details, see the page “[Ghost (1)](../config/ghost.md).”
