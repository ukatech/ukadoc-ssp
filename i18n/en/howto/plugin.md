# Basic usage: Plugins

SSP normally comes with several features, such as Calendar, but you can extend its functionality further with plugins.<br>
There are several plugins available, including ones for freeing memory and monitoring battery status, so give them a try.

## Adding a plugin

Plugins are distributed in the same way as “shells” and “ghosts.”<br>
Simply **drop** the downloaded file onto a character. If the contents are intact, the plugin will be ready to use right away.

## Configuring and running a plugin

The menu that appears when you right-click a character has a “Plugins” item.<br>
All installed plugins are listed here.<br>
Select one to open its settings screen or run its features.
