# Basic usage: Right-click menu

**Right-click** a character to open the right-click menu (owner-drawn menu).<br>
Most SSP operations are performed through this menu.

The right-click menu generally differs between the main character (Emily, or Emiri in Emily/Phase4.5) and subcharacters (Teddy and Emilio in Emily/Phase4.5). The subcharacter menu omits some items.<br>
Items marked <strong>【サブ】</strong> in the explanations on this page are also displayed in subcharacters' menus.

You can also display the main character's right-click menu by **right-clicking** the taskbar icon.<br>
Even if the main character and subcharacters all disappear off-screen, don't panic.

!!! tip "ヒント"

    ![Emily/Phase4.5 menu](../assets/screenshots/howto/rclick/1.png)<br>
    *Menu item names may vary depending on the ghost.* (The image shows the Emily/Phase4.5 menu.)<br>
    If you find the menu difficult to understand, you can turn off the ghost-defined menu display under 「[Ghost (1)](../config/ghost.md)」 in Preferences.

### 1,Recommended【サブ】

A collection of links to sites and ghost download pages recommended by the ghost (or its author).<br>
Select an item from the menu to open the site in your browser.<br>
You can change which browser is used under 「[External applications](../config/extprog.md)」 in Preferences.

### 2,Portal sites

![Emily/Phase4.5 recommended menu](../assets/screenshots/howto/rclick/2.png)<br>
A collection of links to related sites, such as those of ghost and shell authors, and to portal sites.<br>
Select an item from the menu to open the site in your browser.<br>
You can change which browser is used under 「[External applications](../config/extprog.md)」 in Preferences.

### 3,Network update

Updates the ghost over the network to the latest version.<br>
This option is unavailable for ghosts that do not support network updates.

### 4,Uninstall

Uninstalls the ghost.<br>
A confirmation dialog appears after you select this option, so don't worry if you select it by mistake.<br>
![Emily/Phase4.5 recommended menu](../assets/screenshots/howto/rclick/5.png)

### 5,RSS/Headline

Select an installed headline sensor to retrieve information.

### 6,Plugins

Runs an installed plugin.<br>
The functionality varies by plugin.

### 7,Check mail

Checks your mail according to the settings under 「[POP](../config/pop.md)」 in Preferences.<br>
You can change which mail client is used under 「[External applications](../config/extprog.md)」 in Preferences.

### 8,Shell scale

![Shell scale submenu](../assets/screenshots/howto/rclick/4.png){ width="353" }<br>
Enlarges or shrinks the character's image (shell).

### 9,Features

Opens Calendar, SSP IM, and other features.<br>
⇒For details, see the 「[Features](../functions/index.md)」 page.

### 10,Settings

Provides dialogs for configuring SSP and ghosts, as well as quick switches for some settings.<br>
⇒For details, see the 「[Settings](../config/index.md)」 page.

### 11,Change ghost

Replaces the current ghost with another ghost.<br>
If you select the current ghost, it reloads.

### 12,Call another ghost

Displays another ghost while leaving the current ghost as it is.<br>
This feature lets you have multiple ghosts standing at the same time.

### 13,Shell

Changes the shell in use to another shell installed for the current ghost.

### 14,Dressup【サブ】

This option is available for shells that support Dressup.<br>
You can switch between the outfits available for that character.

### 15,Balloon

Changes the balloon (speech bubble) used by the current ghost.

### 16,Recently used

![Recently used submenu](../assets/screenshots/howto/rclick/3.png)<br>
Shows the history of ghosts, balloons, headlines, and plugins you have run.<br>
You can run recently used items again from this menu.

### 17,Information

Displays information about SSP and the current ghost.<br>
⇒For details, see the 「[Information](../about/information.md)」 page.

### 18,Minimize

Minimizes the ghost.<br>
To restore it, **double-click** the icon in the system tray.

### 19,Language

Changes the language used by SSP.<br>
The change takes effect after you restart SSP.<br>
※This does not translate ghost dialogue.

### 20,Exit【サブ】

If multiple ghosts are running, closes only the ghost whose menu you opened.<br>
SSP also exits when you close the last ghost.

### 21,Exit all【サブ】

Closes all ghosts and exits SSP.<br>
If your startup settings are configured to restore ghosts on exit, all ghosts will start the next time you start SSP.<br>
You can change the startup settings under 「[Ghost (1)](../config/ghost.md)」 in Preferences.
