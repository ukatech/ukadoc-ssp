# Basic usage: Adding content

## Let's add some content

![Original ghost menu](../assets/screenshots/howto/add/2.png)<br>
As shown in the figure, the ghost (character data) included with SSP right after installation is usually only “Emily/Phase4.5.”<br>
Emily/Phase4.5 also has one set of master shell (character artwork).<br>
There are also two balloons (speech bubbles): “SSP Default+” and “balloon for Emily/P4.”<br>
You can add ghosts, balloons, shells, and other content.

## The basics of adding content

![Package drag and drop](../assets/screenshots/howto/add/0.png)![Example of a response during installation](../assets/screenshots/howto/add/1.png)<br>
To add content, **drop** the downloaded (or otherwise obtained) package file onto the running SSP.<br>
In most cases, you can install content regardless of which ghost is currently displayed.<br>
Sometimes there is additional content made specifically for a particular ghost. In that case, the ghost should let you know when you drop it.

After adding content, check that it installed successfully by opening the menu for switching that type of content.<br>
![Ghost menu after installation](../assets/screenshots/howto/add/3.png)

### About package files

Content packages are generally distributed as files with the .nar extension, commonly called **NAR files**.<br>
If “Associate files with SSP” is checked under “[General](../config/ippan.md)” in Preferences, you can also install a NAR file by double-clicking it.

In fact, a NAR file is just a ZIP archive with a different file extension.<br>
You can open it with standard archive software after changing its extension back to .zip, for example.<br>
You can also install it manually by placing the extracted files in the folder for that type of content (see “[Folders](../config/folder.md)” in Preferences).<br>
However, if you do this while SSP is running, the changes will not take effect until you restart SSP.

SSP can also install content from ZIP or LZH files (even if they do not have the .nar extension) when you drop them, as long as they contain supported content.

## Notes on each type of content

### Adding ghosts

Many ghosts are distributed online.<br>
Most are listed on search sites such as “GHOST TOWN,” which is also included in the [links collection](../about/links.md) in this help, so try looking there for ghosts you might like.

After adding a ghost, switch to it from “Change ghost” in the right-click menu.<br>
If you have enough screen space, or use multiple monitors, you can have multiple ghosts on screen using “Call ghost.”<br>
Sometimes multiple ghosts on screen at once even talk to each other...?

### Adding balloons

Balloons are also widely distributed online, just like ghosts.<br>
When looking for balloons, you can also use search sites such as “BALLOON TOWN” in the [links collection](../about/links.md).

After installing a balloon, change it from the right-click menu to change the speech bubble the ghost uses.<br>
Balloon selections are remembered separately for each ghost. You cannot change the balloons for multiple ghosts all at once.

### Adding shells

A single ghost can have multiple “shells.”<br>
Switching shells creates an effect like changing clothes or transforming.

Many shells are made for a specific ghost.<br>
If a shell was not made for the ghost you drop it onto, a message will appear and it will not install.<br>
Some shells do not specify a particular ghost, but even then, you need to install them separately for each ghost if you want to use them with multiple ghosts.

After installation, try switching shells from the right-click menu.<br>
Besides changing the ghost’s appearance, a shell may also have invisible differences, such as which areas respond to mouse actions.

As mentioned above, shells are often made for a specific ghost, so it seems that sites for searching for shells, like those for ghosts and balloons, are not easy to create.<br>
Instead, information about shells is usually collected on the ghost’s distribution page.<br>
When you download a ghost, check whether any additional shells are available as well.

## Adding other content

There are several other types of content you can add.

Examples include [headline sensors](headline.md), which retrieve updates from specific websites, and [plugins](plugin.md), which add features to SSP.<br>
Some ghosts also have dedicated additional files called “supplements.”<br>
These can contain a variety of things, such as optional, what-if-style conversations or features that are not part of the ghost’s original content.

The installation method is the same in all these cases: drop the content onto the ghost, for example, to install it.
