# Basic usage: RSS/Headlines

This feature lets ghosts read out summaries (headlines) of websites on the internet.

Several headline sensors are included with SSP by default, and you can add more. <br>
There are sensors for well-known sites and others that announce updates to personal websites, so give them a try.

SSP also supports reading RSS feeds aloud. <br>
For sites that support RSS, using RSS is recommended.

## Checking headlines/RSS

Automatic updates are turned off the first time you start SSP. <br>
To change the automatic update interval or enable automatic updates, configure this in [Connection (2)](../config/conn2.md) under Preferences.

In either case, you can specify a particular headline or RSS feed to retrieve. <br>
Select one from “RSS/Headlines” in the [right-click menu](rclick.md).

## Adding a headline sensor

Headline sensors are distributed just like “shells” and “ghosts.” <br>
**Drop** the downloaded file onto a ghost. If the contents are intact, it will be ready to use right away.

## Adding RSS

SSP supports feed formats called “RSS” and “Atom,” which notify you about updates to websites, blogs, and similar sites. <br>
The supported formats are as follows.

- RSS 0.9x / 2.0
- RSS 1.0
- Atom 0.3 / 1.0

You can add feeds to SSP in any of the following ways.

- Drag and drop an icon labeled RSS or Atom from a website onto the character
- Drag and drop the URL of a site that supports RSS directly onto the character from the address bar or a link (automatic detection = RSS Auto Discovery)
- Enter the URL by pasting it into the “Address bar,” which you can open from “Functions” in the right-click menu

Depending on how each site is set up, all of these methods should give you almost the same result.
