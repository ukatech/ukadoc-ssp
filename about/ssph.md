# SSPH（SSP Helper）について

SSPのフォルダやWindowsの画面で見慣れない `SSPH.exe` を見かけて、不安になった方へ。<br>
SSPをインストールしたフォルダの `data\SSPH.exe` は、SSPの作業を手伝う補助プログラム「SSPH」です。SSP本体（`ssp.exe`）に付属するSSPの一部で、名前は **SSP Helper** の略です。

SSPHはSSP本体などから頼まれたときだけ起動し、作業が終わるとすぐに終了します。ふだんは動いていません。<br>
Windowsのユーザーアカウント制御（UAC）の確認画面に「SSP Helper」や「SSPH.exe」が出て戸惑った場合は、「[UACの確認画面が出るとき](#uacの確認画面が出るとき)」をご覧ください。

## SSPHとは

- **ファイルの場所**<br>
  `(SSPのフォルダ)\data\SSPH.exe` です。
- **ファイルのプロパティ**<br>
  「詳細」タブで、ファイルの説明が「SSP Helper」、製品名が「SSPH」、会社名が「SSP BUGTRAQ」になっています。
- **起動のしかた**<br>
  作業の内容を指定して、SSP本体、インストーラ、Windowsの「インストールされているアプリ」からの削除操作が起動します。自分で起動するものではありません。引数なしで起動しても、何もせずに終了します。
- **表示するもの**<br>
  作業によって、インストール画面、進行状況のウィンドウ、確認のメッセージを出します。それ以外は何も表示しません。
- **通信**<br>
  SSPH自身が通信するのは、インストーラで言語パックのダウンロードを選んだときだけです。言語パックの配布先（GitHub）から取得します。

## SSPHがすること

| 場面 | SSPHの仕事 | SSPHによるUACの確認画面 |
|---|---|---|
| 時刻合わせ | パソコンの時計をサーバの時刻に書き換える | 出ることがあります |
| SSPのインストール | インストール画面を出し、SSPのファイルをインストール先へコピーする | 出ません |
| SSP本体の更新 | SSPの終了を待ち、ダウンロードした更新を上書きして、SSPを再起動する | 出ません |
| ゴーストの更新先の取得 | ゴーストの更新先（`homeurl`）を調べる | 出ません |
| SSPのアンインストール | SSPのフォルダと登録情報を削除する | 出ません |

SSPH.exe自体は管理者権限を要求しない設定（`asInvoker`）で作られています。表の「出ることがあります」は、時刻合わせのときに限って、SSP本体がSSPHを管理者権限で起動するようWindowsに頼むことを指します。

## UACの確認画面が出るとき

パソコンの時計を書き換えるには、Windowsの管理者権限が必要です。デバイスへの変更を許可するかを尋ねるUACの確認画面にSSPHが出てくるのは、この時刻合わせのときだけです。

### 出る場面

- 右クリックメニューの「機能→時刻合わせ」で、ゴーストが時計を修正するときです。メニューを選んだだけでは出ません。サーバへの問い合わせが終わり、ゴーストが実際に時計を修正する段階で出ます。
- ゴーストが自分から時刻合わせを始めたときです。ゴーストはさくらスクリプトの `\![executesntp]` で時刻サーバに問い合わせられます。接続できると `OnSNTPCompare` イベントが通知され、ゴーストはそのスクリプトに `\6` を入れて時計を修正できます。メニューを選んでいなくても、ゴーストの話の途中で確認画面が出ることがあるのは、このためです。
- 本体設定の「時計合わせを自動実行」をオンにしているときです。指定した時間ごとに時計の修正が行われ、そのたびに確認画面が出ることがあります。UACが有効な管理者アカウントでSSPをふつうに起動しているときは、この設定を選べません（下の「出ないとき」をご覧ください）。

### 画面の見かた

確認画面にはプログラム名として「SSP Helper」または「SSPH.exe」が出ます。SSPH.exeにはデジタル署名が付いていないため、発行元は「不明」です。細かな見た目はWindowsのバージョンで違います。

発行元が「不明」と出るだけでは、本物かどうかはわかりません。画面の「詳細を表示」から、次の点を確かめてください。

- プログラムの場所がお使いのSSPのフォルダの `data\SSPH.exe` であること
- 引数が `time` で始まっていること（時刻合わせの合図です）

詳細の見え方もWindowsのバージョンによって異なります。心当たりのないファイルが表示されたときは、「いいえ」を選んでください。

### 「はい」「いいえ」を選ぶと

- **はい**<br>
  SSPHがパソコンの時計を、サーバから得た時刻に書き換えて終了します。確認画面を開いていた間の経過時間も足して合わせます。SSPHがするのは時計の書き換えだけです。
- **いいえ**<br>
  時計は変わりません。SSPのほかの動作には影響しません。<br>
  ただし、ゴーストには「時計を修正した」ことが通知されます（`OnSNTPCorrect` イベント）。そのため、実際には時計が変わっていなくても、ゴーストは修正したかのように話すことがあります。

### 出ないとき

- SSPを管理者として実行しているときです。SSP本体が自分で時計を書き換えるので、SSPHは使われず、確認画面も出ません。
- UACが有効な管理者アカウントで、SSPをふつうに起動しているときです。「時計合わせを自動実行」はグレーになって選べず、自動で確認画面が出ることはありません。ただし、メニューやゴーストからの時刻合わせでは、上のとおり確認画面が出ます。
- 管理者権限のない標準ユーザーのときです。「時計合わせを自動実行」を選べます。時計を修正するたびに、管理者のパスワードを求める画面が出ることがあります。

### 確認画面を出したくないとき

- 時刻合わせを使わないでください。最近のWindowsは時計を自動で合わせてくれます。
- 「時計合わせを自動実行」は、オフにしておくのがおすすめです。ただし、オフにしていても、ゴーストが時刻合わせを行うときは確認画面が出ることがあります。
- 確認画面を避けるためだけに、SSPを管理者として実行するのは、おすすめしません。SSPと、そこで動くゴーストの全部が、管理者権限で動くことになるためです。

!!! tip "ヒント"

    ここで説明した以外の作業（インストール、本体更新、ゴーストの更新先の取得、アンインストール）では、SSPHが原因でUACの確認画面が出ることはありません。<br>
    これらの作業中に確認画面が出たときは、「詳細を表示」で、起動しようとしているファイルを確かめてください。心当たりのないファイルなら、「いいえ」を選んでください。

## 各作業の詳しい動作

### SSPのインストール

SSPのインストーラ（自己展開形式のexe）を実行すると、展開されたファイルの中の `data\SSPH.exe` が、インストール画面を出します。インストーラを起動した直後の「SSPをインストールしますか？」という確認は、自己展開部が出すもので、SSPHの画面ではありません。

- **インストール先**<br>
  ファイルの関連付けに登録されているSSPがあれば、そのSSPのフォルダが最初に入っています。ない場合は `%LOCALAPPDATA%\Programs\SSP` です。
- **選べる項目**<br>
  スタートメニューへのショートカット、ファイルの関連付け、デスクトップへのショートカット、言語パックのダウンロードです。最初はスタートメニューと関連付けがオン、デスクトップはオフです。言語パックは、お使いの言語に合うものがあるときにオンになっています。
- **UAC保護対象のフォルダ**<br>
  `Program Files` や `Windows` フォルダの下は、書き込みに管理者権限が必要なため、インストール先に選べません。別のフォルダ（例：`C:\Users\ユーザー名\SSP`）を選んでください。
- **SSP以外のファイルがあるフォルダ**<br>
  ファイルがすでにあって、`ssp.exe` と `data\SSPH.exe` がないフォルダを選ぶと、確認の画面が出ます。アンインストールのときに、フォルダの中の全データが削除されるためです。

インストールが終わると、SSPを起動します。

### SSP本体の更新

SSPの更新を適用するのは、ダウンロードを終えた直後か、あらかじめダウンロードして保留してあった更新を、次にSSPを起動したときです。このとき、SSP本体は `data\SSPH.exe` を `data\SSPH2.exe` としてコピーして起動し、自分は終了します。SSPが動いたままでは本体を上書きできないので、`SSPH2.exe` はSSPの終了を待ってから作業を始めます。

`SSPH2.exe` は「SSPを更新中...」のウィンドウを出し、ダウンロードした更新を上書きで展開します。次にダウンロードしたファイルを削除してSSPを再起動し、再起動したSSPが `SSPH2.exe` を削除します。

更新の手順は「[本体のバージョンアップ](../howto/verup.md)」をご覧ください。

### ゴーストの更新先の取得

SSPがゴーストの更新先（`homeurl`）を知る必要があるとき、SSPHに調べてもらうことがあります。SSPHは次のように調べます。

1. ゴーストの `ghost\master` フォルダの中にある辞書ファイルなどを読んで、`homeurl` の記述を探します。
2. 見つからないときは、ゴーストのSHIORIを一時的に読み込み、`homeurl` のresourceを取得します。

SSP本体とは別のプロセスで行い、待つのは最長2分です。この間にダイアログが開いても、自動で閉じます。<br>
SSPHを起動している間、SSP本体はゴーストのフォルダにある実行ファイル（`perl` `php` `lisp` で始まるものを除く）の名前を一時的に変えます（例：`xxx.exe` を `xxx_exe` に）。この間、これらの実行ファイルは起動できなくなります。SSPHが終わると、元の名前に戻します。

### SSPのアンインストール

ファイルの関連付けをオンにしているとき、Windowsの「インストールされているアプリ」（「プログラムと機能」）に「SSP」が登録されます。ここから削除すると、SSPHがアンインストールを行います。

1. SSPが起動していると、先に終了するよう案内して、何もせずに終わります。
2. 「ゴーストなど全てのデータが削除されます」という確認画面を出します。「はい」を選ぶと、先へ進みます。
3. SSPのフォルダの中にあるSSPH自身は削除できないため、自分のコピーを一時フォルダ（`%TEMP%\SSPHUninstall.exe`）に作って起動します。
4. コピーがショートカットとファイルの関連付けなどの登録を消し、SSPのフォルダの中をすべて削除します（進行状況のウィンドウが出ます）。
5. 最後に、完了のメッセージを出します。

SSPのフォルダがドライブの直下（`C:\` など）のときは、ドライブの中身を消してしまわないよう、何も削除しません。<br>
SSPのフォルダの中はゴーストのデータやバックアップも含めてすべて削除されます。残したいものはあらかじめ別の場所へ移してください。

`SSPHUninstall.exe` は、Windowsの再起動時に削除されるよう予約されます。予約できなかったときは、一時フォルダに残ることがあります。残っていたら、削除して構いません。

## 本物かどうかの確かめ方

SSPに関係のあるSSPHは、次の3つの名前だけです。

- `SSPH.exe`：SSPのフォルダの `data` フォルダにあります。インストーラの実行中は、展開された一時フォルダの `data` フォルダにあるものが動きます。
- `SSPH2.exe`：本体の更新中だけ、同じ `data` フォルダにできます。
- `SSPHUninstall.exe`：アンインストール中に、Windowsの一時フォルダにできます。

これ以外の名前や場所のSSPHは、SSPのものではない可能性があります。また、プロパティの表示は書き換えられるので、場所を優先して確かめてください。<br>
不安なときは[SSP BUGTRAQ](ssp.md#ssp-bugtraq)から入手したSSPの `data\SSPH.exe` と、お手元のファイルを比べてみてください。
