# 設定

このページでは、[右クリックメニュー](../howto/rclick.md)の「設定」のサブメニューからの各項目について解説しています。

なお、項目名はゴーストによって異なる場合があります（位置は変わりません）。<br>
分かり難いと感じた時は、本体設定の「[ゴースト(1)](ghost.md)」からゴースト定義のメニュー表示をオフにできます。

## 各項目の解説

### 本体設定

SSPの本体設定ダイアログを開きます。<br>
設定はカテゴリーごとに複数のページに分かれています。<br>

### ゴーストごとの設定

ゴーストごとに個別に行える設定のダイアログを開きます。<br>
⇒詳しくは[詳細ページ](eachghost.md)をご覧ください。

### ウインドウモード

ゴーストを1枚のウインドウの中にまとめて表示する「ウインドウモード」の切り替えです。<br>
「切」「全ゴースト」（全ゴーストをまとめて1枚）「ゴーストごと」（ゴーストごとに1枚）の3つから選びます。<br>
⇒詳しくは「[ウインドウモード](../functions/windowmode.md)」のページをご覧ください。

### プロキシサーバを有効にする

設定されたプロキシサーバを有効にするかどうかの簡易スイッチです。<br>
プロキシサーバの詳細設定は本体設定の「[接続(1)](conn1.md)」で行う事ができ、またこの項目はそこにあるチェックボックスによる切り替えと同じものです。

### 文字コード設定

ゴースト内部の各ファイルの読み込みに利用する文字コードを指定します。<br>
通常は自動的に認識するので設定する必要はありませんが、日本語版Windows以外で使用する際などに役立つかもしれません。

### 話すタイミングをゴーストまかせ

基本的にはON（チェックあり）でかまいません。<br>
旧いゴーストを動かす場合などにOFFにすると勝手に喋ってくれるようになることがあります。　

### 旧仕様サポート

基本的にはOFF（チェックなし）でかまいません。<br>
旧いゴーストを動かす場合などにONにすると喋ってくれるようになることがあります。　<br>
逆に、何か挙動がおかしい場合はONになっているかもしれません。OFFにしてみてください。
