# 設定：配信

このページでは右クリックメニューの「設定」サブメニューにある項目「本体設定」で開くダイアログの、「配信」ページについて解説しています。

動画配信等の補助ツールとしてゴーストを使用する際の設定を行います。配信ソフトでのキャプチャや音声連動機能を利用する場合に設定してください。

## 各項目の解説

- **キャラクターを配信ツールでキャプチャしやすくする**<br>
  ゴーストのキャラクターウィンドウを、OBSなどの配信ツールでキャプチャしやすい状態にします。<br>
  ウィンドウの表示方法を変更し、配信ソフトのウィンドウキャプチャで認識されやすくなります。
- **バルーンも配信ツールでキャプチャしやすくする**<br>
  ゴーストのバルーン（会話の吹き出し）を、配信ツールでキャプチャしやすい状態にします。<br>
  バルーンも配信画面に含めたい場合にONにしてください。
- **音声検出時に自動で口パクする**<br>
  マイクからの音声入力を検出して、ゴーストが自動的に口パクモーションを行うようになります。<br>
  配信時に音声に合わせてキャラクターが口を動かすようになり、より自然な表現が可能になります。
- **音声入力選択**<br>
  口パク機能で使用する音声入力デバイス（マイク）を選択します。<br>
  システムで利用可能な音声入力デバイスの一覧から、使用するマイクを選んでください。
- **音声レベル**<br>
  口パク機能の感度を調整します。<br>
  音声レベルバーで現在の入力音量を確認しながら、適切な感度に調整してください。<br>
  感度が高すぎると環境音でも口パクし、低すぎると声に反応しなくなります。
- **ゴーストを1枚のウインドウの中に表示する**<br>
  ゴーストをデスクトップの上に直接置くのではなく、1枚のウインドウの中に閉じ込めて表示します（ウインドウモード）。<br>
  ウインドウごとキャプチャできるようになり、デスクトップ全体にも影響を及ぼさなくなります。<br>
  ⇒詳しくは「[ウインドウモード](../functions/windowmode.md)」のページをご覧ください。
- **全ゴーストをまとめて1枚／ゴーストごとに1枚**<br>
  ウインドウの持ち方を選びます。<br>
  「全ゴーストをまとめて1枚」は起動中のゴーストすべてを1枚のウインドウの中に並べます（初期値）。<br>
  「ゴーストごとに1枚」はゴースト1体につきウインドウを1枚ずつ用意します。

!!! tip "ヒント"

    ウインドウモードは[右クリックメニュー](../howto/rclick.md)の「設定」や、ウインドウ自身の「操作」メニューからも切り替えられます。<br>
    ゴーストの読み込み中は切り替えられず、チェックの表示が元に戻ります。

## 使用上の注意

!!! tip "ヒント"

    配信ツール向けの設定を有効にすると、通常の使用時とウィンドウの動作が変わる場合があります。<br>
    配信を行わない場合は設定をOFFにしておくことをお勧めします。

!!! tip "ヒント"

    音声検出機能を使用する際は、使用するマイクとその他のアプリケーションとの競合にご注意ください。<br>
    一部の配信ソフトや音声ソフトと同時使用する場合、音声デバイスへのアクセスで問題が生じる可能性があります。

!!! tip "ヒント"

    OBS Studioの設定は「ウインドウキャプチャ」内の「キャプチャ方法：Windows 10（1903以降）」を選択してください。<br>
    他のキャプチャ方法では正しくキャプチャできません。<br>
    ウインドウ単体でキャプチャできるので、特別なプラグインは必要ありません。

## 下部のボタン

- **ヘルプ**<br>
  本体設定ダイアログの、設定中のページのヘルプ（つまりこのページ）を開きます。<br>
  ダイアログ右上の「？」マークも同様です。
- **閉じる**<br>
  本体設定ダイアログを閉じます。<br>
  ダイアログ右上の「×」マークも同様です。
