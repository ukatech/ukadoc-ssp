# 設定：表示

このページでは右クリックメニューの「設定」サブメニューにある項目「本体設定」で開くダイアログの、「表示」ページについて解説しています。

このページでは画面表示まわりの設定を行います。

## 各項目の解説

- **カーソルを変更しない（次のゴースト読み込みから有効）**<br>
  ON状態では、マウスカーソル付きバルーンであっても、カーソルを変更しないようにします。<br>
  バルーンによりマウスカーソルが変更されるのが嫌な場合は、ONにしてお使いください。
- **デスクトップ下端オフセット（通常は0で問題ありません）**<br>
  デスクトップ下端から何ドットずらすかを指定します。<br>
  「タスクバーを自動的に隠す」設定時に、タスクバーの裏に隠れてしまわないように設定する使い方などがあります。
- **メニュー幅を背景画像に合わせる**<br>
  通常、メニューの幅はメニュー項目の幅の分だけ表示されていますが、これをゴースト付属のメニュー画像の幅に合わせます。<br>
  これにより、ゴーストメニュー画像の全体が見えるようになります。
- **メニュー選択中にプレビュー画像を表示する**<br>
  右クリックメニューでゴースト切換え・呼び出し・シェル切換え・バルーン切換え等のメニューの選択中に、対応している場合はプレビュー画像(thumbnail.png)を表示します。<br>
  \[—\]状態ではメニューのみ、\[✓\]状態ではそれに加えてエクスプローラ上でマウスを止めるホバー状態でもプレビュー画像を表示します。
- **メニューの縦方向の余白設定（標準2）**<br>
  右クリックメニューの行ごとの余白を設定します。<br>
  Windowsのメニューと同じ間隔は2ですが、必要に応じて見やすくするために変更すると良いでしょう。
- **一部のメニューを階層化する**<br>
  [設定：フォルダ](folder.md)で複数フォルダの読み込みを設定した場合に、これをONにするとメニューがフォルダごとに分けられます。<br>
  ゴースト・バルーン等、フォルダ設定可能なすべてのメニューに適用されます。<br>
  多くのゴーストをインストールしており、整理して表示したい場合に使うと良いでしょう。
- **ゴースト・バルーンメニューの最大文字数（5-255）**<br>
  一部の名前の長いゴーストを表示するために、メニューで画面が埋め尽くされてしまう場合の対策用です。ここで設定した文字数を超える場合、後ろに"..."がついて省略表示となります。<br>
  画面が狭い人は少なめに設定しておくと良いでしょう。
- **最近使ったものメニューの最大記録数（2-255）**<br>
  「最近使ったもの」に残す履歴の数です。この回数より前に起動/使用した項目は消えていきます。
- **Flip3D中でも表示する（Vista以上）**<br>
  Filp3Dでウインドウを切り替えている間もキャラクター＋バルーンを表示したままにします。いつでもキャラクターを表示しておきたい場合に使用して下さい。
- **タスクバーにキャラクターウインドウを表示**<br>
  通常キャラクターが表示されるウインドウはタスクバーに表示されませんが、Windows 7以降などで、ジャンプリストやプレビューを使いたい場合に、表示しておきたい場合があります。<br>
  その時に、このオプションを有効にすると、上記機能が使えるようになります。
- **フルスクリーンのアプリが起動した時に最小化**<br>
  ゲームなどフルスクリーン表示するアプリケーションを起動した時に、自動的にゴーストを最小化表示します。
- **全ての仮想デスクトップにキャラクターウインドウ表示（Win10以降）**<br>
  Windows 10以降の新機能である仮想デスクトップ機能の切替状況に関係なく、すべての仮想デスクトップ上で表示します。
- **キャラクターをクリックするとキャラ以外のウインドウも手前に出る**<br>
  エクスプローラーやログウィンドウなど、特定のキャラクター表示に所属しないウインドウも、クリック時に一緒に手前に出てきます。<br>
  ウインドウが裏にまわって行方不明になりやすいので、通常はONのまま使用してください。
- **高DPI対応 \[SSPの再起動が必要\]**<br>
  高DPI環境でのSSPの表示を改善します。この設定を変更した場合、SSPの再起動が必要です。
- **画面外のウインドウを自動で画面内に移動する**<br>
  モニタ解像度が変化したり、モニタの電源が切れたり、前回起動時のモニタの構成が違ったりした時に、使えるモニタの範囲内に自動でシェルの位置を動かします。<br>
  この設定を切ることで、マルチモニタ環境での諸問題が解決する可能性がありますが、画面外に出た際に手動で位置リセットしないといけなくなります。

### 半透明ウィンドウ

"Layered Window"とも呼ばれる、Windows 2000以降で登場した半透明ウインドウを実現する機能を使う設定です。<br>
使用可能な場合は標準で有効になっています。

- **クロスフェーダを使う**<br>
  キャラクターの表情が切り替わったり、バルーン等の表示・非表示が切り替わる際に、じわじわと切り替わってゆくフェードイン・フェードアウト的な効果を使います。
- **ドラッグ中に透明度を上げる**<br>
  キャラクターのウインドウをドラッグ中に、下にあるものが見えやすいように、不透明度を下げて裏側が見えるようにします。
- **（本体/バルーン/カレンダーの透明度設定）**<br>
  それぞれのウインドウの透明度をスライダーを動かして調節します。

## 下部のボタン

- **ヘルプ**<br>
  本体設定ダイアログの、設定中のページのヘルプ（つまりこのページ）を開きます。<br>
  ダイアログ右上の「？」マークも同様です。
- **閉じる**<br>
  本体設定ダイアログを閉じます。<br>
  ダイアログ右上の「×」マークも同様です。
