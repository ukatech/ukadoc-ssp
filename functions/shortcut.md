# ショートカット一覧

SSPでは、よく使われる機能にショートカットキーが割り当てられています。

以下<strong>【開発】</strong>とあるものは、本体設定「[一般](../config/ippan.md)」の「開発者用機能を有効にする」がONになっていない場合は使えません。

| 機能 | ショートカット |
|---|---|
| バックログ | Ctrl - B (Backlog) |
| カレンダー | Ctrl - D |
| 開発用パレット | <strong>【開発】</strong>Ctrl - Shift - D (Development) |
| エクスプローラ | Ctrl - E (Explorer) |
| エクスプローラ等での検索 | Ctrl - F (Find) |
| 最小化 | Ctrl - I / Ctrl - Shift - Return\[フォーカス無し可\] |
| バルーンを閉じる | Ctrl - Shift - Delete\[フォーカス無し可\] |
| 一時起動ゴーストを保持 | Ctrl - K (Keep) |
| スクリプトログ | <strong>【開発】</strong>Ctrl - L (Log) |
| SSP Messenger | Ctrl - M (Messenger) |
| ファイルを開く | Ctrl - O (Open) |
| フォルダを選択する | Ctrl - F |
| 全て終了 | Ctrl - Q (Quit) |
| スクリプト入力 | <strong>【開発】</strong>Ctrl - S (Script) / Ctrl - Shift - Insert |
| サーフィステスト | <strong>【開発】</strong>Ctrl - T (Test) |
| ネットワーク更新 | Ctrl - U (Update) |
| アドレスバー | Ctrl - Shift - U (URL) |
| バルーン位置初期化 | Ctrl - Shift - F10 |
| シェル位置初期化 | Ctrl - Shift - F12 |
| 終了 | Ctrl - W / Ctrl - F4 |
